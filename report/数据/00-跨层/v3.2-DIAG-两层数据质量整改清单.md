# v3.2 期货分钟数据质量整改清单（raw + 二级数据）

**本文档合并两轮排查，并首次做了两层数据的逐合约对账。**

| | 第一层：raw | 第二层：二级数据 |
|---|---|---|
| 交付物 | `future_pricemin{YYYYMMDD}.txt` 日频文件 | `all_symbol_min_full_main_close_k_1.pkl` 单体文件 |
| 内容 | 通联 1 分钟原始行情 | 主力连续序列 + 复权因子 |
| 覆盖 | **全市场全合约**，六个交易所 | **79 个品种的主力连续**，每品种每时点只有 1 根 |
| 规模 | 3,989 个文件，2010-01-04 ~ 2026-08-11 | 6,628 万行，2010-01-04 ~ 2026-07-29 |
| 独有字段 | `vwap`、`value`（成交额） | `K`（复权因子）、`contract`、`underlying_symbol` |

二级数据是 raw 的下级产物，但**由数据端单独交付**，含 raw 里没有的主力合约判定与复权因子，因此需要单独整改，不能假定"修好 raw 就好了"。

**文档结构**：
- **第一部分** — raw 层的问题（9 项），源头缺陷，修好后两层同时受益
- **第二部分** — 二级数据层的问题（7 项），raw 正常或 raw 无此字段，必须单独修
- **第三部分** — 已排查、确认无问题的项（完整性存档），证明排查是全面的，并标出**哪些看着像问题但其实是真实市场行为，请勿修改**

---

## 0.1 两层数字不一致时怎么读

同一个问题在两层会给出不同的数字，**这是口径差，不是两次扫描打架**。二级数据只保留主力合约，raw 是全合约，**换算基准约为 1 : 12 ~ 1 : 18**（每品种活跃合约数）。例如节前夜盘伪造：raw 2,488,070 根 ÷ 二级 141,377 根 = **17.6**，正好落在基准区间内。

两层是**独立验证，不是互相校对**：raw 侧用 awk 全量单遍扫 3,989 个文件，二级侧用 pandas 全量扫 6,628 万行，两条互不共享代码的链路对同一现象给出同向结论，是可信度加成而不是重复劳动。

**一个可复算的自证例子**：v3.0 说节后竞价错标影响 **11 个**跨午夜品种，v3.1 说 **12 个**。差的那一个是**氧化铝 AO** —— 而 AO 恰好是 9 个在二级数据里止于 2024-04-22 的截断品种之一（见 S-1），被排除在 v3.0 的分析池外，所以 v3.0 看不到它。**一个问题（截断）直接造成了另一个问题的漏报**，两条互相印证。

本文档用四个符号标注跨层关系：

| 符号 | 含义 |
|---|---|
| `=` | **同源** —— 两层同一问题，数字差异符合口径换算基准 |
| `↑` | **二级层更差** —— 二级比 raw 多一层缺陷，是二级加工环节自己引入的 |
| `✗` | **不传导** —— raw 有、二级没有（字段不存在或已被下游消化） |
| `↔` | **跨层互补** —— raw 缺、二级有，或反之 |

# 第一部分 raw 层的问题

## P0-1 有夜盘的品种缺 09:00 日盘集合竞价 `=`

**案例**
```
RB2305  2023-01-03  日盘首根直接是 09:01，无 09:00        <- 现状
RB2205  2022-01-04  09:00  O=H=L=C=4302  vol=4643        <- 旧格式期同类日，09:00 正常存在
```
2023-05-26 之后，有夜盘的 (品种×交易日) 组合 38,030 个，**有 09:00 的恰好为 0**。

**范围**

raw 全市场口径下，2023-05-26 起有夜盘的品种共 **53 个**：

| 交易所 | 品种数 | 是否受 2023-05-26 新规约束 | 品种 |
|---|---|---|---|
| 上期所 | 18 | **是** | AG AL AO AU BR BU CU FU HC NI OP PB RB RU SN SP SS ZN |
| 大商所 | 17 | **是** | A B C CS EB EG I J JM L M P PG PP RR V Y |
| 能源中心 | 4 | **是** | BC LU NR SC |
| 郑商所 | 14 | **否** | CF CY FG MA OI PF PR PX RM SA SH SR TA ZC |

受约束的 **39 个品种 × 718 个交易日 = 27,436 个组合，有 09:00 的组合数为 0**。

**二级数据侧的表现**
```
raw   全市场全合约 · 2023-05-26 起 · 39 个品种受约束，0 个有 09:00
二级  79 品种主力连续 · 同期 · v3.0 报告记为 48 个品种
关系  = 同源。48 是 79 品种池口径且把郑商所 13 个品种一并算了进去；
      以 raw 的 39 个为准，见 0.2 更正表第 1 条。
```

**整改要求**
1. 对上期所 / 能源中心 / 大商所的全部有夜盘品种，自 **2023-05-26** 起补齐 09:00 集合竞价 K 线（08:59–09:00 撮合结果）。
2. 该根必须 `O=H=L=C`，`volume` = 竞价撮合量；**不得并入 09:01**。
3. **郑商所排除** —— 其同期只开了 08:55–08:59 撤单窗口，无日盘竞价撮合，没有 09:00 是正确的。
4. 2023-05-26 之前不追溯。

**验收**：三家有夜盘品种 09:00 存在率 = 100%、平 K 线率 = 100%；09:00 收盘价 = 交易所公布的日盘竞价成交价；09:01 成交量补数前后不变；郑商所 09:00 数仍为 0。

## P0-2 节假日前后的夜盘被 padding 成零成交 K 线 `=`

**案例**
```
CU2603  2026-01-05（元旦后首日，周一）
  TDATE=20260102(周五)  21:00–23:59  76,873 根  vol 全 0  价格恒为 98380（= 2025-12-31 收盘）
  TDATE=20260103(周六)  00:00–02:30  11,896 根  vol 全 0
  真正的上一交易日是 2025-12-31（周三），日盘真实开盘价 99380
```
即「上一交易日 = 日历日 −1，周一 −3」的工作日/周末规则被当成了交易日历。

**范围**
- 上期所 16 个品种 / 1,016,858 根，大商所 17 / 671,740，郑商所 14 / 499,785，能源中心 4 / 299,687；累计 **2,488,070 根**
- 中金所、广期所无夜盘，不受影响
- **新格式期节后首日 24/24 全部中招**；旧格式期 86 个节后首日只有 2 个（2014-01-02、2020-01-02 两个元旦）
- 全部 24 天：2022-10-10、2023-01-03、01-30、04-06、05-04、10-09、2024-01-02、02-19、04-08、05-06、06-11、09-18、10-08、2025-01-02、02-05、04-07、05-06、06-03、10-09、2026-01-05、02-24、04-07、05-06、06-22

**二级数据侧的表现**
```
raw   全市场全合约 · 2,488,070 根 / 1,515 组
二级  79 品种主力连续 · 141,377 根 / 946 组
关系  = 同源。比值 17.6，落在口径换算基准 12~18 内，是同一个填充逻辑在
      两种投影下的计数，不是两次扫描结果不一致。
```

**整改要求**
1. 「上一交易日」改回查**交易日历**，停用 weekday/weekend 回退。
2. 交易所公告取消夜盘的时段**不生成任何 K 线** —— 不是把成交量填 0，是这段数据根本不该存在。
3. 修复后**回溯重跑 2022-09-22 至今全部文件**，不是只修增量。

**验收**：节后首日文件中不存在「`TDATE ≠ CLEARINGDAY` 且整段成交量为 0」的时段；节后首日 K 线根数等于「仅日盘」根数（螺纹 226 根，含 09:00 竞价，而非现在的 346 根）；`TDATE` 取值只能是 `{CLEARINGDAY, 上一个有效交易日}`。

> **⚠ 勿误删**：普通交易日里个别品种整夜零成交，raw 侧 1,342 组 / 1,782,745 根（二级侧 1,509 组 / 282,565 根），集中在动力煤 ZC、豆二 B、棉纱 CY。**那是真实的无人交易，不是伪造。** 区别很清楚：padding 是**全市场**整段为 0，僵尸是**个别品种**为 0。明细见 `明细/02c_普通交易日整夜零成交_非伪造.csv`。

## P0-3 节后 01:00 / 02:30 那根带成交量的 K 线 = 被错标的日盘集合竞价 `=`

**案例**
```
AG2506  2025-05-06（劳动节后首日）
  02:29  8182  8182  8182  8182  vol=0        <- padding，= 前收盘
  02:30  8156  8156  8156  8156  vol=12226    <- 平 K 线 + 大成交量
  09:01  8158  8207  8158  8205  vol=14998    <- 日盘开盘 8158
```
02:30 的 8156 距日盘开盘仅 2 点（0.02%），距 padding 价 8182 有 26 点。

**范围**：12 个跨午夜品种
- 夜盘收于 **02:30**：上期所 AG、AU；能源中心 SC
- 夜盘收于 **01:00**：上期所 AL、**AO**、CU、NI、PB、SN、SS、ZN；能源中心 BC
- **周一特例（数据直接丢失，不是错标）**：13 个交易日盘前无任何带量 bar ——
  2015-09-28、2022-10-10、2023-01-30、2023-10-09、2024-02-19、2024-04-08、2024-05-06、2025-04-07、2026-01-05、2026-06-22（周一），
  2014-01-02、2020-01-02（周四，元旦 TDATE 错位），2013-07-05（夜盘上线首日）

**二级数据侧的表现**
```
raw   全市场全合约 · 12 个品种 · 726 个可比样本，571 个（78.7%）更接近日盘开盘价
                   距日盘开盘价偏离中位 0.063%，距 padding 价 0.663%
二级  79 品种主力连续 · 11 个品种 · 143 个样本，133 个（93.0%）更接近日盘开盘价
                   距日盘开盘价偏离中位 0.030%，距前收盘 0.552%
关系  = 同源，结论方向完全一致。品种数差 1 个（AO），因为 AO 在二级数据里
      止于 2024-04-22（见 S-1），被排除在分析池外。样本数差是主力合约与
      全合约的口径差；二级侧比例更高，是因为主力合约的竞价成交更集中、噪声更小。
```

**整改要求**
1. 该根时间戳**改标为 09:00**，与 P0-1 的补数合并处理。
2. 周一情形不得丢弃 —— 修好 P0-2 的 `TDATE` 计算后该分支自动消失。
3. 修复后节后首日的 01:00 / 02:30 应不存在该根，或该根成交量为 0。

**验收**：节后首日 12 个跨午夜品种的 01:00 / 02:30 成交量 = 0；同日 09:00 存在且成交量等于原先错标的量；全市场「盘前带量 bar 数」与「该日夜盘是否真实存在」严格一致。

## P0-4 郑商所的集合竞价 K 线不是平 K 线 `=` 【需书面答复】

**案例**（2026-07-10 夜盘，同一时刻四所对照）
```
郑商所 TA2609  21:00  O=5670 H=5670 L=5666 C=5666  vol=9067   <- 带振幅
郑商所 FG2609  21:00  O=956  H=958  L=956  C=958   vol=6309   <- 带振幅
上期所 RB2610  21:00  O=H=L=C=3091                 vol=1165   <- 标准平 K 线
大商所 M2609   21:00  O=H=L=C=3043                 vol=4515   <- 标准平 K 线
```
21:00 平 K 线比例：上期所 / 大商所 / 能源中心**精确 1.000**，郑商所常年 **0.30–0.40**。
辅证：21:00 那根的成交量占夜盘总量，郑商所 **1.455%**，其余所 0.376%–0.662%（2.2–3.9 倍）。

**已排除的两种替代解释**
1. **不是时间标签整体错位**：10:15–10:30 小节休前后，郑商所与其他所同样是「有 10:15、无 10:16–10:30、下一根是 10:31」。
2. **不是成交清淡**：郑商所竞价那根的成交量占比反而是全市场最高的。

**范围**：郑商所全部品种，**全历史**（09:00 自 2010 年、21:00 自 2015 年夜盘上线起），与 2022-09-22 换版无关。
逐品种 21:00 平 K 线比例：OI 0.295、SR 0.299、CF 0.321、TA 0.336、PX 0.347、PF 0.348、RM 0.355、PR 0.370、SH 0.384、MA 0.386、ZC 0.394、CY 0.446、SA 0.449、FG 0.458。

**二级数据侧的表现**
```
raw   全市场全合约 · 21:00 平 K 线比例 0.30–0.40
二级  79 品种主力连续 · 同一指标 0.1951
关系  = 同源。主力合约最活跃，其 21:00 那根最容易混进开盘后的连续成交，
      平 K 线比例因此更低；raw 的全合约样本含大量清淡合约，那些合约的
      21:00 只有竞价成交，所以是平 K 线。两个数字测的不是同一批样本。
```

**整改要求**

## P1-9 一段无成交之后的第一笔成交，OHLC 被写成 0 `=` （本版新查出）

**案例**
```
EG2408 乙二醇 @ 2024-04-12（大商所）
  20240411 21:00  O=4485 H=4485 L=4485 C=4485  vol=0  oi=582     <- 正常（夜盘竞价后的无成交延续）
  20240411 21:01  O=0    H=0    L=0    C=0     vol=2  oi=580     <- 该合约夜盘的第一笔成交
                              value=89750  vwap=4487.5              量、额、均价全对，只有 OHLC 是 0
  20240411 21:02 ~ 20240412 09:06   OHLC 全 0，vol=0              <- close=0 被「沿用上一价」一路复制
  20240412 09:07  O=4496 H=4496 L=4496 C=4496  vol=1             <- 直到下一笔成交才复位
```

**这不是「无成交的分钟被填 0」，而是「首笔成交的 OHLC 没写进去，再被复制放大」。** 两者的整改动作完全不同。

**根因（已在全历史上逐块验证）**：零价块的起点恒等于**该合约在该交易时段的第一笔成交**。全历史 **8,497 个块，命中 8,497 个，命中率 100.000%**（夜盘 6,717/6,717、日盘 1,780/1,780，2015–2026 逐年均为 1.0000，无一例外）。

**两种形态**，区别在于 `close` 是否也是 0 —— 这决定会不会传染：

| 形态 | 字段 | 是否传染 | 根数 | 独立故障数 | 年份 |
|---|---|---|---|---|---|
| **A** | 四价全为 0 | **会**（`close=0` 被逐分钟复制） | **436,274** | **8,497 个块** | 2015 至今，2024 年为峰值 |
| **B** | 只有 `open` 与 `low` 为 0，`high`/`close` 正常 | 不会 | **2,483** | 2,483 根孤立坏根 | 2015–2022，2022 年后消失 |

形态 B 的字段形态高度规整：**`low = 0` 在 2,483 根里 100% 成立**，`open = 0` 占 2,482 根，`close` 从不为 0。指向 `open` 未初始化（=0）、`low` 取 `min()` 时把这个 0 带了进去，而 `high` 取 `max()`、`close` 取最后一笔，因此不受影响。其中 85.2% 同样发生在「上一根无成交、间隔后的第一笔成交」上，与形态 A 同源。

**发生条件 —— 不是随机，有三层硬边界**

拿全市场「某合约某交易时段的第一笔成交」共 **2,320,979 次**作分母，逐层收缩：

| ① | 全部时段首笔成交 | 2,320,979 | 9,972 | 0.43% |

| | └ 2010–2014（对照组） | **75,731** | **0** | **0** |
| ④ | **该合约在该时段的第一根 bar 上没有成交** | **309,607** | **9,851** | **3.18%** |
| | └ 夜盘：21:00 集合竞价那根就有成交（对照组） | **111,281** | **0** | **0** |

**怎么补这批数据 —— 逐 bar 规则**

`明细/P1-9a_零价K线块明细.csv` 已经把每个块的 `prev_close`（无成交 bar 应填的值）与 `seed_vwap`（种子 bar 应填的值）逐行列好，可直接作为修复输入。

| bar 类型 | 根数 | 占比 | 修复方法 | 精度 |
|---|---|---|---|---|
| 块内 `volume = 0` | **423,142** | **97.0%** | 填该块的 `prev_close`（块前最后一个有效收盘价），`O=H=L=C=prev_close` | **精确** —— 这些分钟本来就没有成交，正确值就是沿用上一价，与其他交易所的处理一致 |
| 块内 `volume > 0` 且该分钟只有一个成交价 | 13,132 根中的大部分 | 3.0% 的大部分 | `O=H=L=C=vwap`，并用 `value = volume × vwap × 合约乘数` 反向校验 | **精确** |
| 块内 `volume > 0` 且该分钟有多个成交价 | 少数 | — | vwap 只是均价，**必须从逐笔或快照重取真实四价** | 需回源 |

**99.67% 的块（8,469 / 8,497）有可用的 `prev_close`**；只有 **28 个块**从该合约当日第一根 bar 就开始，需要取前一交易日收盘价。

## S-7 复权因子 K 的构造口径与跨版本可复现性 【需书面答复】

## 3.5 已确认属市场事实 —— **请勿当作错误修正**

以下现象在数据里看着像缺陷，但都是真实的市场行为或交易所规则变更。**修掉它们等于损坏数据。**

| 现象 | 事实 |
|---|---|
| **每日 K 线根数在 226 / 241 / 256 / 346 / 376 / 466 / 556 之间跳** | 对应真实规则变更：2013-07 ~ 2014-12 夜盘分批引入（黄金白银最早，其后有色、油脂、化工）→ 2016 年上期所黑色系夜盘由 01:00 缩到 23:00 → 2019 年大商所由 23:30 缩到 23:00。池内 38/59 个品种的每日 bar 数在历史上出现过一种以上取值 |
| **2020-02-09 ~ 05-03 全市场没有夜盘** | 疫情期间夜盘停摆，数据记录完全正确（有夜盘品种比例精确为 0.000，5 月 10 日起分批恢复） |
| **夜盘收盘时间按品种分三档** | 23:00 / 01:00 / 02:30 是真实的品种差异，不是漏填 |
| **换月处裸价格不连续** | 主力连续的固有性质，用复权价即可消除 |
| **复权价与今天的真实价差很多倍** | 后复权锚在上市首约的必然结果（铁矿石 8.63 倍、天然橡胶 0.18 倍）。绝对价格逻辑应使用未复权价 |
| **合约乘数在历史上变过** | FB 500→10（2019）、MA 50→10（2015）、PB 25→5（2013）、OI 5→10（2013）、RU 5→10（2012）等，均为交易所规则变更 |
| **整日最高价 = 最低价** | 全库 176 组。要区分两种：碳酸锂 2023-12-08 成交 17,613 手是**真实封板**；胶合板 / 线材那些成交 1–2 手的是**没人交易**。用当日成交量即可分开 |
| **普通交易日里个别品种整夜零成交** | raw 侧 1,342 组 / 1,782,745 根，集中在动力煤、豆二、棉纱。**真实的无人交易**，与 P0-2 的 padding 性质完全不同 |
| **上市初期整日没有一手成交** | 豆二 487 天、硅铁 213 天、锰硅 194 天、棉纱 43 天。是流动性事实，不是数据缺失 |
| **集合竞价那根 bar 时间跨度为零、成交量偏高** | 全库 404,649 根，成交量中位数是普通 bar 的 1.27 倍。这是竞价机制本身的性质 |
| **主力连续的 volume 不等于品种总成交** | 它只是当时主力合约的量 |

## A 口径说明

**raw 的两套表头**，以 2022-09-22 为界，全历史只有这两套：

```
<= 20220921   TAB 分隔，14 列，第 5 列是 Offset
   CLEARINGDAY TDATE CONTRACTID MARKET Offset bartime close open high low volume value vwap OPENINTS

>= 20220922   逗号分隔，13 列，无 Offset
   CLEARINGDAY TDATE CONTRACTID MARKET bartime close open high low volume value vwap OPENINTS
```

**raw 的夜盘归属规则**：文件 `future_pricemin{D}.txt` 的 `CLEARINGDAY` 恒为 `D`，内含

| 段 | TDATE | bartime |
|---|---|---|
| 夜盘（上一日晚间） | `D-1`（周一取 `D-3`） | 21:00 – 23:59 |
| 跨午夜段 | `D`（周一取 `D-2`） | 00:00 – 02:30 |
| 日盘 | `D` | 09:00 / 09:01 – 15:15 |

`TDATE` 即该根 bar 的**日历日**。这条规则本身是对的，问题出在「上一交易日」是怎么算出来的（P0-2）。
