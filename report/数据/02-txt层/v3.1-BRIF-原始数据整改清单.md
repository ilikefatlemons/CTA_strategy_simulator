## P0-1 有夜盘的品种缺 09:00 日盘集合竞价

**案例**
```
RB2305  2023-01-03  日盘首根直接是 09:01，无 09:00        <- 现状
RB2205  2022-01-04  09:00  O=H=L=C=4302  vol=4643        <- 旧格式期同类日，09:00 正常存在
```
2023-05-26 之后，有夜盘的 (品种×交易日) 组合 38,030 个，**有 09:00 的恰好为 0**。

**范围**
- 上期所 18：AG AL AO AU BR BU CU FU HC NI OP PB RB RU SN SP SS ZN
- 大商所 17：A B C CS EB EG I J JM L M P PG PP RR V Y
- 能源中心 4：BC LU NR SC
- 2023-05-26 起 718 个交易日，27,436 个 (品种×交易日) 组合

**整改要求**
1. 对上述三家的全部有夜盘品种，自 2023-05-26 起补齐 09:00 集合竞价 K 线（08:59–09:00 撮合结果）。
2. 该根必须 `O=H=L=C`，`volume` = 竞价撮合量；**不得并入 09:01**。
3. **郑商所排除** —— 其同期只开了 08:55–08:59 撤单窗口，无日盘竞价撮合，没有 09:00 是正确的。
4. 2023-05-26 之前不追溯。

**验收**：三家有夜盘品种 09:00 存在率 = 100%、平 K 线率 = 100%；09:00 收盘价 = 交易所公布的日盘竞价成交价；09:01 成交量补数前后不变；郑商所 09:00 数仍为 0。

## P0-2 节假日前后的夜盘被 padding 成零成交 K 线

**案例**
```
CU2603  2026-01-05（元旦后首日，周一）
  TDATE=20260102(周五)  21:00–23:59  76,873 根  vol 全 0  价格恒为 98380（= 2025-12-31 收盘）
  TDATE=20260103(周六)  00:00–02:30  11,896 根  vol 全 0
  真正的上一交易日是 2025-12-31（周三），日盘真实开盘价 99380
```
即「上一交易日 = 日历日 −1，周一 −3」的工作日/周末规则被当成了交易日历。

**范围**
- 上期所 16 个品种 / 1,016,858 根，大商所 17 / 671,740，郑商所 14 / 499,785，能源中心 4 / 299,687；累计 **2,488,070 根**（另有 00:00–02:30 段，单日如 2025-05-06 再加 11,908 根）
- 中金所、广期所无夜盘，不受影响
- **新格式期节后首日 24/24 全部中招**；旧格式期 86 个节后首日只有 2 个（2014-01-02、2020-01-02 两个元旦）
- 全部 24 天：2022-10-10、2023-01-03、01-30、04-06、05-04、10-09、2024-01-02、02-19、04-08、05-06、06-11、09-18、10-08、2025-01-02、02-05、04-07、05-06、06-03、10-09、2026-01-05、02-24、04-07、05-06、06-22

**整改要求**
1. 「上一交易日」改回查**交易日历**，停用 weekday/weekend 回退。
2. 交易所公告取消夜盘的时段**不生成任何 K 线** —— 不是把成交量填 0，是这段数据根本不该存在。
3. 修复后**回溯重跑 2022-09-22 至今全部文件**，不是只修增量。

**验收**：节后首日文件中不存在「`TDATE ≠ CLEARINGDAY` 且整段成交量为 0」的时段；节后首日 K 线根数等于「仅日盘」根数（螺纹 226 根，含 09:00 竞价，而非现在的 346 根）；`TDATE` 取值只能是 `{CLEARINGDAY, 上一个有效交易日}`。

> **勿误删**：普通交易日里个别品种整夜零成交共 1,342 组 / 1,782,745 根（动力煤 ZC 910 组、豆二 B 318 组、棉纱 CY 52 组），那是**真实的无人交易**，不是伪造。区别：padding 是全市场整段为 0，僵尸是个别品种为 0。

## P0-3 节后 01:00 / 02:30 那根带成交量的 K 线 = 被错标的日盘集合竞价

**案例**
```
AG2506  2025-05-06（劳动节后首日）
  02:29  8182  8182  8182  8182  vol=0        <- padding，= 前收盘
  02:30  8156  8156  8156  8156  vol=12226    <- 平 K 线 + 大成交量
  09:01  8158  8207  8158  8205  vol=14998    <- 日盘开盘 8158
```
02:30 的 8156 距日盘开盘仅 2 点（0.02%），距 padding 价 8182 有 26 点。全历史 726 个可比样本中 **571 个（78.7%）更接近当日日盘开盘价**；偏离中位数 0.063% vs 0.663%。

**范围**：12 个跨午夜品种
- 夜盘收于 **02:30**：上期所 AG、AU；能源中心 SC
- 夜盘收于 **01:00**：上期所 AL、AO、CU、NI、PB、SN、SS、ZN；能源中心 BC
- **周一特例（数据直接丢失，不是错标）**：13 个交易日盘前无任何带量 bar ——
  2015-09-28、2022-10-10、2023-01-30、2023-10-09、2024-02-19、2024-04-08、2024-05-06、2025-04-07、2026-01-05、2026-06-22（周一），
  2014-01-02、2020-01-02（周四，元旦 TDATE 错位），2013-07-05（夜盘上线首日）

**整改要求**
1. 该根时间戳**改标为 09:00**，与 P0-1 的补数合并处理。
2. 周一情形不得丢弃 —— 修好 P0-2 的 `TDATE` 计算后该分支自动消失。
3. 修复后节后首日的 01:00 / 02:30 应不存在该根，或该根成交量为 0。

**验收**：节后首日 12 个跨午夜品种的 01:00 / 02:30 成交量 = 0；同日 09:00 存在且成交量等于原先错标的量；全市场「盘前带量 bar 数」与「该日夜盘是否真实存在」严格一致。

## **P0-4 郑商所的集合竞价 K 线不是平 K 线

**案例**（2026-07-10 夜盘，同一时刻四所对照）
```
郑商所 TA2609  21:00  O=5670 H=5670 L=5666 C=5666  vol=9067   <- 带振幅
郑商所 FG2609  21:00  O=956  H=958  L=956  C=958   vol=6309   <- 带振幅
上期所 RB2610  21:00  O=H=L=C=3091                 vol=1165   <- 标准平 K 线
大商所 M2609   21:00  O=H=L=C=3043                 vol=4515   <- 标准平 K 线
```
21:00 平 K 线比例：上期所 / 大商所 / 能源中心**精确 1.000**，郑商所常年 **0.30–0.40**。
辅证：21:00 那根的成交量占夜盘总量，郑商所 **1.455%**，其余所 0.376%–0.662%（2.2–3.9 倍）。
已排除「时间标签整体错位」：10:15–10:30 小节休前后结构各所一致。

**范围**：郑商所全部品种，**全历史**（09:00 自 2010 年、21:00 自 2015 年夜盘上线起），与 2022-09-22 换版无关。
逐品种 21:00 平 K 线比例：OI 0.295、SR 0.299、CF 0.321、TA 0.336、PX 0.347、PF 0.348、RM 0.355、PR 0.370、SH 0.384、MA 0.386、ZC 0.394、CY 0.446、SA 0.449、FG 0.458。

**整改要求**
1. 核对郑商所分钟 K 线的**时间区间定义**（左闭右开 / 左开右闭），确认 21:00 与 09:00 这一根是否把竞价成交与开市后第一批连续交易成交并进了同一根。
2. 若确认合并，把竞价成交**单独切成一根**，与其他四家对齐。
3. 若确认是郑商所行情源本身的口径、数据端无法拆分，请**书面明确告知** —— 给出结论比留着不确定更有价值，我方会据此对郑商所做特殊处理。

**验收**：郑商所 21:00 / 09:00 平 K 线比例达到 1.000；21:00 成交量占夜盘总量回落到 0.4%–0.7%；21:00 收盘价 = 交易所公布的夜盘竞价成交价。

  20231229   74,453 根  21:00–23:59  vol=0      <- 节前被取消的夜盘

## **P1-7 成交额被「凑整万元」，产生负成交额与失真 vwap

**案例**
```
FG2504  2024-08-27 15:00  O=1332 H=1332 L=1329 C=1329  vol=1  value=34940  vwap=1747
   玻璃 20 吨/手，1 手 × 1329 = 26,580 元，多出的 8,360 是塞值；vwap 比真实价高 31%
FG2504  2024-08-27 09:01  vol=0  value=-8640        <- 负成交额

CY2505  2024-08-27  真实成交额合计 1,113,350
   09:01 塞 −8,775、15:00 塞 +5,425  ->  全日 1,110,000 = 111.0000 万元（整数万元）
```
2024-08-27 当日：郑商所 **162 个有成交额的合约，162 个全日成交额都是整万元**；其余五所 497 个合约里只有 1 个。

**范围**：郑商所全部品种。整万元比例 **2010–2014 约 0.003（正常）→ 2015 跳到 0.297 → 2016–2019 约 0.49 → 2020 起 0.999+**；其余五所常年 0.002–0.02。
- 负 `value`：郑商所 **145,887 根**（上期所 20、能源中心 1、其余为 0）
- `vwap` 落在该根 `[low, high]` 之外（>1%）：郑商所 **104,081 根**，最大偏离 1751 倍。FG 13,403 / MA 10,436 / SA 9,520 / TA 9,464 / RM 8,192 / SR 5,677 / CF 4,995 / UR 4,607
- **这一条比负成交额更危险**：塞值并进有成交的 bar 时 `value` 仍为正，用 `value<0` 的过滤器抓不到

**整改要求**
1. **不要用日总额倒挤分钟成交额**。分钟成交额应直接来自分钟行情，日汇总另行提供；两者不一致时保留原始值并单独标记，不要靠塞值抹平。
2. 若上游确实只有万元精度的日成交额，请明确告知该字段的真实精度；但**不得因此产生负值，也不得让 `vwap` 脱离 `[low, high]`**。

**验收**：全库 `value < 0` 行数 = 0；`volume>0` 且 `vwap` 越界（>1%）行数 = 0；郑商所整万元比例回落到 < 5%。

## **P1-8 天然橡胶 RU 的 vwap 用错合约乘数

**案例**
```
RU1005  2010-01-04 09:01  O=24605 H=24745 L=24605 C=24700  vol=4958  value=612416150  vwap=12352.08
   按当时真实的 5 吨/手：612,416,150 ÷ (4,958 × 5) = 24,705  ✓ 与价格一致
   按 2012-08 之后的 10 吨/手：÷ (4,958 × 10) = 12,352      <- 正是文件里的 vwap
```
问题在**合约层面**：2012-07-02 同日，RU1207（5 吨/手）`vwap/close = 0.50`，RU1208 / RU1303（10 吨/手）= 1.00。最后一个 5 吨/手合约 RU1207 于 2012-07-16 到期，问题随之消失。

**范围**：上期所 RU，2010-01-04 ~ 2012-07-16，共 **422,297 根**（2010 年占该品种 42.4%、2011 年 29.3%、2012 年 5.2%，2013 年起为 0）。`value` 与 OHLC 都是对的，**只有 `vwap` 这一列错**。
其他调整过交易单位的品种（FB 500→10、MA、OI、PB）`vwap/close` 中位数均为 1.000，**只有 RU 一个**。

**整改要求**
1. 重算 RU 在该区间内 5 吨/手合约的 `vwap`：`value ÷ (volume × 该合约当时的交易单位)`。
2. 检查其他历史上调整过交易单位的品种，确认 `vwap` 用的是**合约生效时点的**乘数，而不是当前值。

**验收**：RU 全历史 `vwap` 越界行数 = 0；`value ÷ (volume × vwap)` 反推乘数，RU1207 及更早 = 5，RU1208 及以后 = 10。
