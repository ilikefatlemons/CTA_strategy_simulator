# 大周期过滤-2h双均线粘性多空

## 一 职责

用 2h 的价格与双均线排列，把市场**二分**成多头环境或空头环境，且**永不落进中间态**。

## 二 输入契约

2h 上「截至 bar i-1 已收盘」的那一根（见 [[已收盘]]）的收盘价、MA21、MA55。均线在整条 2h 序列上连续滚动，不分段重置。

## 三 判定规则

```
读 c = 已收盘下标2h[i]
若 c < 0 或 MA55[c] 为 NaN：      大周期状态 = 未定      （暖机）
否则：
    若 收盘[c] > MA21[c] > MA55[c]：   大周期状态 ← 多
    否则若 MA55[c] > MA21[c] > 收盘[c]：大周期状态 ← 空
    否则：                              保持上一个状态     ← 粘性
```

真值表：

| 收盘 / MA21 / MA55 的相对位置 | 新状态 |
|---|---|
| 收盘 > MA21 > MA55 | **多** |
| MA55 > MA21 > 收盘 | **空** |
| MA21 > 收盘 > MA55（回踩快线） | 保持 |
| 收盘 > MA55 > MA21（快线在下、价在上） | 保持 |
| 任意两者相等 | 保持 |
| 暖机期，一次干净排列都没出现过 | 未定 |

三元严格不等，不许有等号。见 [[多头排列]]。

## 四 输出契约

- `大周期状态 ∈ {多, 空, 未定}`。**`未定` 只在暖机期出现**，一旦出现过一次干净排列就再也回不去
- `状态刚切换`：这一根是不是切换点。**它触发全量重置**

## 五 参数与开关

| 参数 | 默认 | 含义 | 改了会怎样 |
|---|---|---|---|
| `大周期_周期` | `2h` | 定方向用哪个周期 | 换 `1d` 就是 [[大周期过滤-1d双均线粘性多空]]，天然消掉横截面不一致但方向变得很慢。换更低周期会让方向一天变好几次，趋势门和回调探测器落到同一个时间尺度上——82 案 D1 点名的失败模式 |
| `大周期_快线` | `21` | 快均线 | — |
| `大周期_慢线` | `55` | 慢均线 | 在 2h 上覆盖 **6.9~13.8 个交易日**，随品种夜盘档位而变，见第八节 |
| `大周期_价格取值` | `已收盘的2h收盘价` | 排列里的「价格」取什么 | 换实时 1m 价，状态会在一根 2h 内部反复抖动。**而每次抖动都会清空回调武装**——重置语义随之失效 |
| `大周期_粘性` | `开` | 排列混乱时是否保持上一状态 | 关掉变成三态（[[大周期过滤-2h三线严格排列带中性态]]），中性期间不开仓 |

## 六 无未来函数

只读 `已收盘下标2h[i]` 指向的那一根，触及的最新 bar 是 **i-1**。粘性用的是本模块自己上一根的输出，不读任何未来数据。

## 七 与其他模块位的耦合

- **依赖**：[[已收盘判定-按开盘时刻二分查找]]、[[指标滚动口径-连续滚动不分段重置]]
- **我供给方向**：[[位-回调确认]]、[[位-入场确认合成]]（三条腿都按这个方向解释）、[[位-反手]]
- **我重置**：状态切换时重置 [[回调确认-30m快线在慢线之下]] 的武装、入场状态、[[冷静期-三连止损冻结到2h翻转]] 的止损连击与冻结。**但不平仓**
- **我解冻**：[[冷静期-三连止损冻结到2h翻转]] 的释放条件就是我翻转

## 八 这个模块自身的代价

**同一个 MA55 在不同品种上不是同一段时间。** 2h 每交易日的根数随夜盘档位从 4（无夜盘）到 8（AU/AG/SC）不等：

| | 无夜盘 | 至 23:00 | 至 01:00 | 至 02:30 |
|---|---|---|---|---|
| MA55 覆盖 | 13.8 交易日 | 9.2 | 7.9 | 6.9 |

2 倍极差，而且这是**分箱造的，不是市场造的**。逐品种统计时会以「无夜盘品种趋势更稳」的形式渗进结果。根因和补救在 [[周期-2h]]。

**第二条：粘性让状态切换很稀有。** 均线纠缠时不切换，所以切换只发生在「从一种干净排列直接翻到另一种干净排列」的时刻。这是设计意图（方向永远存在，不会有「不知道看多看空」的空窗），但它有一个连带后果——[[反手-反向信号成立时同价反手]] 因此变得罕见。详见 [[回调策略]] 缺陷二。

**第三条：滞后一整根 2h。** 一个 09:30 就翻转的品种，要等到 11:30 那根收盘、下一根 1m 开盘才改标签。这是「不读未来」的价钱，不能优化掉。

## 九 同位候选与退化关系

- [[大周期过滤-2h三线严格排列带中性态]] —— `大周期_粘性 = 关` **就退化成它**（只差一个开关）
- [[大周期过滤-1d双均线粘性多空]] —— `大周期_周期 = 1d`，同样是参数点
- [[大周期过滤-2h均线斜率]] —— 不是退化，是另一条底层逻辑

## 十 测试钩子

- 排列混乱的那些根，输出与上一根**逐位相同**（粘性生效）
- `未定` 只出现在序列开头一段连续区间里，一旦离开就不再返回
- 构造精确相等的临界数据（快线 == 慢线），必须判为「保持」而不是切换
- `大周期_粘性 = 关` 时输出必须**发生变化**（抓哑火）
- 逐品种统计状态切换次数，按夜盘档位分四层报告，**报 n**——用来量化第八节那条横截面不一致有多大
