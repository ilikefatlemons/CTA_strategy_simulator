# 回调确认-30m快线在慢线之下

## 一 职责

确认**在大周期方向的反方向上，30m 出现过一段有结构的回调**——不是一根影线，是快线真的跌到慢线下面去了。

## 二 输入契约

30m 上「截至 bar i-1 已收盘」那一根的 MA21、MA55，加上 [[大周期过滤-2h双均线粘性多空]] 给的方向。

## 三 判定规则

```
读 c = 已收盘下标30m[i]，d = 大周期状态

回调条件成立 ⟺  d == 多 且 MA21[c] < MA55[c]
              或 d == 空 且 MA21[c] > MA55[c]

若 回调条件成立：      武装时刻 ← c            ← 每次为真都刷新（近期窗口）
已武装 ⟺ 武装时刻存在 且 c − 武装时刻 ≤ 回调_武装有效期
```

**只比两根均线，不含价格。** 这与 [[大周期过滤-2h双均线粘性多空]] 的三元排列不同，是刻意的：回调的判据是趋势结构，价格在哪里由入场那三条腿去管。

## 四 输出契约

- `已武装 ∈ {真, 假}`
- `武装时刻`：最近一次条件为真的 30m 下标。**[[止损-30m回调低点下方一段ATR]] 要用它回溯回调段的极值**

## 五 参数与开关

| 参数 | 默认 | 含义 | 改了会怎样 |
|---|---|---|---|
| `回调_周期` | `30m` | 在哪个周期认回调 | 与 `大周期_周期` 的比值决定「回调」相对「趋势」有多大。2h:30m = 4:1 |
| `回调_快线` | `21` | 快均线 | 与大周期同参是刻意的——同一套形状换个尺度看 |
| `回调_慢线` | `55` | 慢均线 | — |
| `回调_武装方式` | `近期窗口` | 条件为真后怎么记住 | 换 `一次性闩锁`：只有第一次为真才武装，之后持续为真也不刷新。窗口式更宽松，且不需要判断「哪一次才算第一次」 |
| `回调_武装有效期` | `16根30m` | 武装多久过期 | 见第八节——这个「16 根」在不同品种上是 0.8 到 2 个交易日 |
| `回调_要求严格早于入场` | `关` | 是否强制回调与入场至少隔一根 30m | 打开会让右侧速度下降最多 30 分钟。**注意这与现引擎相反**：`src/rules/pullback_entry.py:46` 的老逻辑里确认那一根永不入场，由 `tests/test_pullback_v3_entry_gate.py:139` 钉死 |

## 六 无未来函数

只读 `已收盘下标30m[i]` 指向的那一根，触及的最新 bar 是 **i-1**。`武装时刻` 是本模块自己的历史输出。

## 七 与其他模块位的耦合

- **依赖**：[[大周期过滤-2h双均线粘性多空]] 给方向
- **被重置**：大周期状态切换时武装立即清空
- **我供给**：[[入场确认合成-三腿同时成立]]（没武装就不许入场）、[[止损-30m回调低点下方一段ATR]]（`武装时刻` 是回溯极值的起点）
- **被消耗**：入场成交后武装清空

## 八 这个模块自身的代价

**「16 根 30m」在不同品种上不是同一段时间。** 30m 每交易日的根数：无夜盘 8、至 23:00 是 12、至 01:00 是 16、至 02:30 是 19。于是有效期是 **2.0 / 1.3 / 1.0 / 0.8 个交易日**，2.4 倍极差。和 [[周期-2h]] 那条同源。

**第二条：武装是「近期窗口」而不是「事件」，所以它不要求回调已经结束。** 30m 的均线关系滞后，5m 转多的时候 30m 往往还是快线在下——本模块此时仍然为真。这正是设计意图（回调 + 右侧），但它意味着**「回调」和「反转」在时间上可以完全重叠**，本模块并不验证「回调真的走完了」。

**第三条：不含价格。** `MA21 < MA55` 在一段长期下跌后的横盘里也成立——价格可能已经离两根均线很远、正在筑底而非回调。区分这两者要靠 [[位-入场确认合成]] 那三条腿，本模块不管。

## 九 同位候选与退化关系

- [[回调确认-30m完整空头排列]] —— 加上 `收盘 < MA21` 这一条就变成它。**是严格的子集**：本模块为真是它为真的必要条件
- [[回调确认-30m价在快线之下]] —— 换一条判据，不是子集关系
- [[回调确认-30m回撤幅度按ATR计]] —— 价位型而非状态型，判别测试见 `docs/04-参考资料/v3.0-ENUM-回调再入场策略编目.md` §0.4

## 十 测试钩子

- 大周期状态切换的那一根，`已武装` 必须变假
- 入场成交后 `已武装` 必须变假
- 超过 `回调_武装有效期` 后 `已武装` 自动变假
- 条件持续为真时，`武装时刻` 每根都刷新（近期窗口生效）
- 逐品种统计武装次数与「武装后成功入场」的比例，按夜盘档位分四层，**报 n**
