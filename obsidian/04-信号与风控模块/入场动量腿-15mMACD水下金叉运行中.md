# 入场动量腿-15mMACD水下金叉运行中

## 一 职责

确认**动量拐点刚刚发生过，且是从超卖区发生的**——区分「从坑里爬出来」和「上涨途中又加了一把火」。

## 二 输入契约

15m 上「截至 bar i-1 已收盘」那一根的 DIF 和 DEA。

- `DIF = EMA12 − EMA26`
- `DEA = EMA9(DIF)`
- 全部用 `ewm(span=..., adjust=False)`

## 三 判定规则

**写成「运行态」而不是「金叉事件」。** 这是本模块最关键的设计选择，理由见第八节。

```
读 c = 已收盘下标15m[i]

若 c < 入场动量腿_最少可用根数：  动量腿 = 假     ← 硬守卫，见下
当前处于「多头运行段」 ⟺ DIF[c] > DEA[c]
该运行段的起点 s      = 使 DIF > DEA 连续成立的最早那一根
段起点在水下         ⟺ DIF[s] < 0 且 DEA[s] < 0
段龄                 = c − s

动量腿(多) ⟺ DIF[c] > DEA[c] 且 段起点在水下 且 段龄 ≤ 运行段最大年龄
动量腿(空) ⟺ DIF[c] < DEA[c] 且 段起点在水上（两线均 > 0） 且 段龄 ≤ 运行段最大年龄
```

真值表（多头方向）：

| DIF vs DEA | 段起点位置 | 段龄 | 动量腿 |
|---|---|---|---|
| DIF > DEA | 两线均 < 0 | ≤ 8 | **真** |
| DIF > DEA | 两线均 < 0 | > 8 | 假（拐点太旧） |
| DIF > DEA | 起点在水上 | 任意 | 假（上涨中继，不是回升） |
| DIF ≤ DEA | — | — | 假 |
| c < 35 | — | — | 假（预热不足） |

## 四 输出契约

`动量腿 ∈ {真, 假}`，在给定方向上。

## 五 参数与开关

| 参数 | 默认 | 含义 | 改了会怎样 |
|---|---|---|---|
| `入场动量腿_周期` | `15m` | 算 MACD 的周期 | — |
| `入场动量腿_MACD参数` | `12/26/9` | 快/慢/信号 | 标准值。改了必须连同任何回测结果一起声明 |
| `入场动量腿_水下判据` | `金叉那根两线都在零轴下` | 「水下」的定义 | 换 `只看DEA在零轴下` 放宽（金叉时 DIF 可能已在零上）；换 `不限位置` 就退化成 [[入场动量腿-15mMACD任意位置金叉]] |
| `入场动量腿_运行段最大年龄` | `8根15m` | 拐点多久还算数 | 两小时。**调到无限就变成纯状态**：一次水下金叉能授权此后整段上涨里的任何时刻入场 |
| `入场动量腿_最少可用根数` | `35` | 前多少根不可用 | `= 慢线26 + 信号线9`，与 `src/rules/entry.py:8` 的 `min_bars` 同口径。**不能省**，见第八节 |

## 六 无未来函数

只读 `已收盘下标15m[i]` 指向的那一根及更早。**运行段起点 `s` 是往回找的**，不是往前看——`s ≤ c` 恒成立。触及 **i-1**。

## 八 这个模块自身的代价

**其一：为什么必须写成运行态。** 如果写成「金叉事件」（只有交叉那一根为真），就要求 [[入场快腿-5m价在双均线之上]] 和它**恰好在同一根 1m 上同时为真**。5m 排列翻转和 15m 金叉是两个独立事件，同根重合的概率极低——与门下这等于永不入场。运行段 + 年龄上限是同一件事的可行写法。

**其二：`ewm(adjust=False)` 永远不返回 NaN。** 指数加权无限记忆，第一根之后就有数字，前几十根是垃圾但**看不出来**——不像 `rolling(n).mean()` 会老实给 NaN。`入场动量腿_最少可用根数` 是唯一挡住它的东西，省掉就会在窗口开头产生一批凭空的信号。

**其三：EMA 跨时段连续滚动。** 夜盘第一根的 DIF 带着白盘的记忆（[[指标滚动口径-连续滚动不分段重置]]）。对 EMA 这个问题比对 MA 更重——MA 的记忆有限（21 根就忘了），EMA 的记忆无限。

**其四：「运行段起点」这个概念在多空之间不对称。** 多头要求起点两线在零轴下，空头要求两线在零轴上。零轴附近来回穿的震荡行情里，两边都容易触发，且触发的是同一段行情。

## 十 测试钩子

- 前 35 根 `动量腿` 恒假，即使 DIF > DEA
- 构造一段「水上金叉」的数据，`动量腿` 必须为假
- 构造一段「水下金叉后第 9 根」，`动量腿` 必须为假（年龄上限生效）
- 运行段起点 `s` 恒满足 `s ≤ c`（往回找，不往前看）
- 逐前缀比对 DIF/DEA 与 `src/indicators.py:16` 的 `macd()` 输出一致
