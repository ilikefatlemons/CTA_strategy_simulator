# 止盈-ATR解锁后追踪

## 一 职责

**先锁后追。** 浮盈不够时完全不管止盈，让价格波动扫不出去；够了之后挂一条只进不退的追踪线。

## 二 输入契约

- [[MFE最大浮盈]]：入场以来最有利的价位，**截至 i-1**
- [[止损-30m回调低点下方一段ATR]] 给的 `入场ATR`（冻结）和 `初始止损价`

## 三 判定规则

多头（空头镜像）：

```
浮盈 = 最高浮盈价 − 入场价                      ← 最高浮盈价截至 i-1

若 未解锁：
    有效止损 = 初始止损                          ← 只有止损和到期能出场
    （解锁判定在第 6 步做，见下）
若 已解锁：
    追踪线   = 最高浮盈价 − 止盈_追踪回撤 × 入场ATR
    有效止损 = max(初始止损, 追踪线)             ← 单调不降

解锁判定（在极值折入的同一步，即出场测试之后）：
    已解锁 ← 已解锁 或 (浮盈 ≥ 止盈_解锁阈值 × 入场ATR)
```

**解锁是不可逆的**——一旦解锁就不会退回锁定状态。

## 四 输出契约

- `已解锁 ∈ {真, 假}`
- `追踪线`（未解锁时不存在）
- `有效止损`，**单调不降**
- 由追踪线造成的出场，理由是 `追踪止盈`

## 五 参数与开关

| 参数 | 默认 | 含义 | 改了会怎样 |
|---|---|---|---|
| `止盈_解锁阈值` | `1.5倍ATR` | 浮盈到多少才开始管止盈 | **这就是「锁」**。调到 0 等于一入场就挂追踪止盈，回调途中的正常波动会把仓位扫掉 |
| `止盈_追踪回撤` | `1.0倍ATR` | 从最高浮盈回撤多少离场 | 与解锁阈值的差就是最小锁定收益，见下 |
| `止盈_ATR入场冻结` | `开` | ATR 冻结还是实时 | 冻结使追踪线**单调不降**。换实时会重演现有吊灯的毛病：`tests/test_pullback_v3_backtest.py:106` 记着它在 ATR 上升而极值不变时会**后退** |

### 一个恒等式

```
止盈_解锁阈值 − 止盈_追踪回撤 = 1.5 − 1.0 = 0.5倍ATR   ← 最小锁定收益
```

解锁那一刻浮盈至少 1.5 ATR，追踪线在 `最高浮盈 − 1.0 ATR`，所以**追踪线在解锁瞬间就已在入场价上方 0.5 ATR**。

推论：在 `成本_每仓基点 = 0` 下，**`追踪止盈` 出场必然是盈利单**。这不是巧合，[[冷静期-三连止损冻结到2h翻转]] 的「连续止损」计数口径靠它才自洽——所有非止损出场里，只有 `到期` 可能是亏的。

改这两个参数时必须一起想：让差值 ≤ 0，上面那条推论就失效，冷静期的语义跟着变。

## 六 无未来函数

**追踪线用的是截至 i-1 的最高浮盈价。** 本根的极值在第 6 步才折进去，只影响 i+1。

反过来（先折入再测本根）等于假设知道本根最高价先于最低价出现——盘中次序引擎不可能知道。这是全库最危险的一步，见 [[MFE最大浮盈]] 和 [[求值顺序与无未来函数审计]] 不变量其二。

`入场ATR` 是入场时冻结的常数。

## 七 与其他模块位的耦合

- **依赖**：[[止损-30m回调低点下方一段ATR]] 给地板和冻结 ATR、[[MFE最大浮盈]]
- **我供给**：[[成交口径-入场开盘价出场线价带跳空补价]] 的出场线
- **我影响**：[[冷静期-三连止损冻结到2h翻转]] —— `追踪止盈` 出场清零止损连击

## 八 这个模块自身的代价

**其一：锁定期是裸的。** 浮盈 0 到 1.5 ATR 这一段完全没有止盈保护。一笔涨到 1.4 ATR 然后全部回吐、最终止损出场的交易，会被记成一次纯亏——但它其实一度接近盈利。「锁」换来的是不被扫，代价就是这个。

**其二：冻结的 ATR 会过时。** 允许跨时段持有（[[持仓时长-跨时段持有加最长上限]]），一笔仓能活好几天。波动率在这期间可能翻倍，而追踪线还在用入场那一刻的 ATR——**波动放大时追踪线相对太紧，波动收缩时太松**。这是「单调不降」这个好性质的直接代价，两者不可兼得。

**其三：单一出口。** 不分批、无固定目标。一笔大行情全靠追踪线收尾，必然回吐最后 1 个 ATR；而分批止盈（[[止盈-2R减半后吊灯]]）能锁一部分。这是自觉的选择，不是遗漏。

## 九 同位候选与退化关系

- [[止盈-固定R倍目标]] —— `止盈_追踪回撤 = 0` 时本模块**退化成「到最高点就走」**，不完全等价但很接近
- [[止盈-2R减半后吊灯]] —— 现引擎在用的。换过去后一仓变两腿，[[位-成本口径]] 的「每仓一次 vs 每腿一次」不再等价
- [[止盈-快线跌破即离场]] —— `src/rules/take_profit.py` 的 docstring 记着为什么没选它：均线滞后，等它跌破利润已回吐一截

## 十 测试钩子

- **追踪线单调不降**（这是冻结 ATR 的直接推论，也是与现有吊灯最大的区别）
- `有效止损` 恒 ≥ `初始止损`
- 未解锁时不存在追踪线，出场理由只可能是 `止损` / `到期` / `窗口末根` / `反手`
- `成本_每仓基点 = 0` 时，**所有 `追踪止盈` 出场的毛收益恒 > 0**（第五节那条恒等式的机械验证）
- 解锁不可逆：解锁后浮盈回落，`已解锁` 仍为真
- **埋点**：解锁率（多少比例的仓位活到解锁），**报 n**
