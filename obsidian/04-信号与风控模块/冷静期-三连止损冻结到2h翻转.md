# 冷静期-三连止损冻结到2h翻转

## 一 职责

**同一个方向连挨三次止损 = 这个方向标签已经过期了。** 停手，等 2h 说一句新话。

## 二 输入契约

- 每次出场的理由和方向
- [[大周期过滤-2h双均线粘性多空]] 的 `状态刚切换`
- 2h 的已收盘下标（用于计天花板）

## 三 判定规则

```
出场时：
    理由 == 止损：
        若 方向 == 连击方向：  连击 += 1
        否则：                连击方向 ← 方向，连击 ← 1
        若 连击 ≥ 冷静期_触发次数：
            冻结中 ← 真
            冻结起点 ← 已收盘下标2h[i]
            连击 ← 0                      ← 武装同时清零，释放后不会立刻再武装
    理由 == 追踪止盈：        连击 ← 0
    理由 == 到期 / 窗口末根：  不动
    理由 == 反手：            不动

每根 bar：
    若 大周期状态刚切换：       冻结中 ← 假，连击 ← 0        ← 主释放路径
    否则若 已收盘下标2h[i] − 冻结起点 ≥ 冷静期_最长时长：冻结中 ← 假   ← 天花板
```

出场理由对计数器的作用：

| 理由 | 对连击 | 为什么 |
|---|---|---|
| `止损` | **+1** | 唯一携带「看错方向」信息的出场 |
| `追踪止盈` | **清零** | 赚到了，说明方向标签还管用 |
| `到期` | 不动 | 日历驱动，不携带方向信息 |
| `窗口末根` | 不动 | 同上 |
| `反手` | 不动 | 信号驱动而非风险驱动 |

## 四 输出契约

`冻结中 ∈ {真, 假}`。冻结期间 [[入场确认合成-三腿同时成立]] 的信号一律不许开仓，[[反手-反向信号成立时同价反手]] 也被挡住。

## 五 参数与开关

| 参数 | 默认 | 含义 | 改了会怎样 |
|---|---|---|---|
| `冷静期_触发次数` | `3` | 连几次止损后冻结 | 与 `src/rules/cooldown.py:37` 同值。调到 2 会频繁误伤正常的连亏段 |
| `冷静期_释放条件` | `大周期翻转` | 什么时候解冻 | 换 `固定根数` 就是 [[冷静期-固定根数计时]]，与「三连止损说明方向标签过期」的因果脱钩 |
| `冷静期_最长时长` | `24根2h` | 天花板 | 只在大周期长期不翻转时兜底，防止永久冻结。约 3~6 个交易日，随品种夜盘档位而变 |

## 六 无未来函数

只读已发生的出场和 `已收盘下标2h[i]` 指向的那一根。触及 **i-1**。

## 七 与其他模块位的耦合

- **依赖**：[[大周期过滤-2h双均线粘性多空]]（释放条件就是它翻转）、[[成交口径-入场开盘价出场线价带跳空补价]]（给出场理由）
- **被重置**：大周期切换时连击清零、冻结解除
- **我约束**：[[入场确认合成-三腿同时成立]]、[[反手-反向信号成立时同价反手]]

## 八 这个模块自身的代价

**其一：释放条件与触发条件是同一件事的两面，这既是优点也是风险。** 优点是自洽：从上行切到下行的过程中必然先连吃几次止损，冷静期正好桥接「方向标签过期」到「方向官方翻转」这段空窗。风险是**它假设方向一定会翻**——如果 2h 长期胶着，冷静期只能靠天花板解除，而天花板是个和因果无关的数字。

**其二：`到期` 出场对计数器不可见，可能让冷静期失灵。** [[持仓时长-跨时段持有加最长上限]] 那边已经点明：若 `到期` 占比很高，「三次连续止损」可能横跨很长时间，中间夹着一堆亏损的到期出场——冷静期看不见它们。

现引擎踩过完全一样的坑并留下了结论：试过「亏损的整批收盘平仓算一次看错」，59 品种 × 5 模式下冷静期 +25%、批次 −14%、逐组合 129 好 / 152 差（噪声），**行为改变远大于它解决的问题，已回退**。给出的方向是「给『连续』加时间限制，而不是把别的出场塞进这个计数器」。**本装配尚未加那个时间限制**——这是一个已知的、自觉留着的洞。

**其三：连击按方向分，但冻结不分。** 触发时冻结的是**整个**入场，不只是那个方向。因为释放条件是大周期翻转，而翻转之后原方向本来也不会再开——分方向冻结在这套释放条件下没有额外意义。但换成 [[冷静期-固定根数计时]] 之后就有意义了，届时要重新想。

**其四：天花板在不同品种上不是同一段时间。** `24 根 2h` = 6.0 / 4.0 / 3.4 / 3.0 个交易日，2 倍极差。

## 九 同位候选与退化关系

- [[冷静期-固定根数计时]] —— `冷静期_释放条件 = 固定根数`。**注意它不是纯参数点**：改了释放条件之后，「连击按方向分」这条需要重新设计
- [[冷静期-日线实体吞没均线时触发]] —— 现引擎的第二触发器，已实现（`src/strategy/pullback.py:260`）。实测 **RB 一年 13 次冷静期里有 9 次来自它**，而不是三连止损——这个数字说明它可能比本模块更常起作用，值得优先试
- [[冷静期-无]] —— `冷静期_触发次数 = 无穷`

## 十 测试钩子

- 同向三次纯止损武装冷静期；两次不够
- 武装那一刻计数器清零（释放后不会立刻再武装）
- `到期` / `窗口末根` / `反手` 既不推进也不打断连击
- `追踪止盈` 清零连击
- 反向的止损重置连击方向并从 1 开始
- 大周期切换时冻结立即解除
- `成本_每仓基点` 从不进入本模块的任何判断（改它，冷静期区间必须逐字节不变）
- **埋点**：冷静期触发次数、平均时长、以及触发时距离下一次大周期翻转还有多久，**报 n**。最后一个数用来验证「三连止损是翻转的早期警报」这个论点到底成不成立
