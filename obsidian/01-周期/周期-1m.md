# 周期-1m

**原子单位，也是驱动时钟。** 不由任何东西合成，它就是清洗后的原始数据。

## 它在本装配里干什么

| 用途 | 说明 |
|---|---|
| 推进循环 | [[求值顺序与无未来函数审计]] 的七步在每一根 1m 上跑一遍 |
| 成交价 | 入场和反手用 `开盘价[i]`，到期强平用 `收盘价[i]` |
| 盘中触发 | 止损和追踪止盈用 `最低价[i]` / `最高价[i]` 判定，见 [[成交口径-入场开盘价出场线价带跳空补价]] |
| 跳空补价 | 跳空穿过止损时按 `开盘价[i]` 成交 |

## 一个诚实的观察：1m 在入场端目前不值钱

本装配的入场三腿分别在 5m / 15m / 15m 上，它们**只在各自周期收盘时改变状态**。所以入场事实上只可能落在 5m 边界之后的那一根 1m 上——1m 时钟在入场这一步没买到任何东西。

它挣钱的地方全在出场：止损、追踪线、到期都是逐分钟测的，这是 1m 相对 5m 驱动的真实增量。

要让 1m 在入场端也起作用，得往 [[位-入场快腿]] 换 [[入场快腿-1m价在双均线之上]]，或者往 [[位-入场确认合成]] 底下加一条 1m 触发腿。现在没有，这是自觉的空缺。

## 数据事实

- 时间戳标在**分钟末端**：标 09:01 的这根覆盖 `[09:00, 09:01)`。见 [[K线标注-标在分钟末端]]
- 每个时段的**第一根是集合竞价撮合结果**，不是一分钟连续交易，`开=高=低=收`。在 1m 层面**原样保留**，只在合成更高周期时被并进下一箱，见 [[竞价孤儿箱-并入下一箱]]
- 每交易日根数：无夜盘 225，至 23:00 是 345，至 01:00 是 465，至 02:30 是 555（不含或含竞价那根，±1）
- 已收盘下标恒等于 `i-1`，这与老引擎的 `history.iloc[:i]` 完全同义。由 `tests/test_v3_timeframes.py:233` 钉死
