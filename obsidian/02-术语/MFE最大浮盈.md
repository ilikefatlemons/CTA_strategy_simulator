# MFE最大浮盈

**入场以来最有利的那个价位。** 多头取最高价的滚动最大值，空头取最低价的滚动最小值。

英文 Maximum Favourable Excursion。代码里叫 `extreme_since_entry`。

## 它驱动两件事

| 用途 | 谁在用 |
|---|---|
| **解锁**：浮盈 = `\|MFE − 入场价\|`，够 `1.5倍ATR` 才打开止盈逻辑 | [[止盈-ATR解锁后追踪]] |
| **追踪线**：`MFE − 1.0倍ATR`（多头） | 同上 |

## 折入必须滞后一根 —— 这是全库最危险的一步

**bar i 上测试用的 MFE，必须是截至 i-1 的；bar i 自己的极值折进去只影响 i+1。**

理由：追踪线是 `MFE − 一段ATR`。如果先把本根最高价折进 MFE 再拿去测本根的止损，等于假设你知道**本根的最高价先于最低价出现**——盘中次序是引擎不可能知道的。

反过来的后果不是「略微乐观」，是**结构性造假**：追踪止盈会在每一根都恰好卡在「最高点回撤一个 ATR」的位置上，凭空拔高收益，且拔高幅度随波动率放大。

对应开关 `极值折入_滞后一根`，默认开，**不许关**。同形先例三处：`src/engine/pullback_backtest.py:296-300`、`src/engine/pullback_v3_backtest.py:549-552`、`src/engine/rbreaker_backtest.py:230-231`。原始理由在 `src/config.py:50`。

## 持仓守卫

折入这一步必须带 `当前有持仓` 的判断，且放在**出场块之后**。否则刚平掉的仓位会在同一根继续更新 MFE，下一笔开仓时带着上一笔的极值。

代码形态（`src/engine/pullback_v3_backtest.py:549-552`）：

```python
if 极值折入_滞后一根 and 持仓 is not None:
    极值 = max(极值, 最高价[i])   # 多头
```

## 冻结的 ATR 让追踪线单调

因为 `止盈_ATR入场冻结 = 开`，追踪线 = `MFE − 常数`，而 MFE 单调不降，**所以追踪线单调不降**。

现有的吊灯止损做不到这一点：它每根都用当前的 ATR 重算，`tests/test_pullback_v3_backtest.py:106` 记着——ATR 上升而极值不变时，吊灯线会**后退**（仍不低于初始止损那个地板）。
