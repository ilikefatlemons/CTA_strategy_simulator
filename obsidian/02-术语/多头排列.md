# 多头排列

「排列」指**若干条线按大小顺序排开**。本库里有两种，必须分清——它们不是同一个东西。

## 甲｜价格 + 两根均线（本装配用的）

```
多头排列  ⟺  收盘价 > MA快 > MA慢
空头排列  ⟺  MA慢 > MA快 > 收盘价
其余      ⟺  混乱（不是第三种状态，是「没有排列」）
```

**价格是最快的那一元。** 三元严格不等，中间不许有等号。

用在 [[大周期过滤-2h双均线粘性多空]] 和 [[入场快腿-5m价在双均线之上]]。

## 乙｜三根均线（现有代码里的）

```
多头排列  ⟺  MA快 > MA中 > MA慢
```

不含价格。`src/strategy/pullback.py:239` 的 `ma_array_states(close, fast=5, mid=20, slow=50)` 就是这个，只用在日线定方向。

## 这两个在代码里都不是现成的

| 要的 | 现有最接近的 | 差在哪 |
|---|---|---|
| 甲（价格 + 2 均线） | 无 | `ma_array_states` 比的是三根**均线**；`ma_fast_mid_states`（`:215`）只比**两根均线**，不含价格。**两个都不是** |
| 乙（3 均线） | `ma_array_states` | 现成 |

所以本装配要一个新原语。它是 `src/strategy/pullback.py` 里第三个同族函数，不是改造现有的哪一个——现有那两个被 `tests/test_pullback_v3_states.py` 逐前缀逐位钉死，一个字都不能动。

## 混乱态怎么处理：两条路

排列不干净的时候（比如 `MA快 > 收盘价 > MA慢`），有两种做法：

| 做法 | 状态数 | 谁在用 |
|---|---|---|
| **粘性**：保持上一个状态 | 2（多 / 空） | [[大周期过滤-2h双均线粘性多空]] —— 方向永远存在，不存在「不知道该看多还是看空」的时刻 |
| **中性态**：单独一个状态 | 3（多 / 空 / 中性） | 现引擎的日线方向；候选 [[大周期过滤-2h三线严格排列带中性态]] |

粘性有一个不显然的后果：**混乱期不会触发状态切换，所以也不会触发重置**。均线纠缠时策略照常按上一个方向找机会。这是设计意图，但它同时让 [[反手-反向信号成立时同价反手]] 变得很罕见，见 [[回调策略]] 缺陷二。

## 严格不等与浮点

三元用的是严格 `>`，恰好相等判为混乱。这不是吹毛求疵：`src/strategy/pullback.py:205` 的注释专门说明为什么均线走 pandas 的 `rolling().mean()` 而不是累加和相减——

> cumsum 的浮点误差与 pandas 的补偿求和不同，可能在 `MA5 == MA20` 的临界处翻转状态。

`tests/test_pullback_v3_states.py:41` 的测试数据刻意把价格吸附到 0.5 的网格上，就是为了制造大量精确相等的临界点。
