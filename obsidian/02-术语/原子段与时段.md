# 原子段与时段

**两个层次，不能混用。** 出处 `src/data/v3_sessions.py:185-192`。

## 原子段（segment）

由「`trading_date` 变了 **或** 时钟间隔 > 3 小时」切出来的最小单位，就是**夜盘段和白盘段**。

它是数据本身的形状，**不随任何配置变化**。五种时段模式都建立在它之上。

### 3 小时这个阈值不是拍的

24 个品种全历史实测，`trading_date` 内部出现过的间隔：

```
0.017h 0.033h 0.05h 0.1h 0.267h 0.283h  2.017h  │  6.517h 8.017h 9.517h 10.017h
                                                 └── 空带 ──┘
日内最大间隔    = 2.017h  （商品午休 11:31–13:30）
夜→日最小间隔   = 6.517h  （AU/AG/SC 的 02:30 → 09:01）
落在 (2.25h, 6h) 的间隔 = 0 个
```

阈值落在一条实测空带的正中，两侧各约 2.7 倍余量。配一条运行时断言 `assert_no_ambiguous_gaps`（`:345`）盯着它——真出现异常品种会立刻炸，而不是被静默错切。

顺带覆盖了四种边界情况：2020 年 2–5 月全市场停夜盘（自然退化成单时段）、中金所品种（唯一间隔 1.517h，单时段）、AU/AG/SC 跨零点（21:00→02:30 是一条连续段）、周五夜盘归下周一（54.5h / 58.0h 的间隔，正确切开）。

### 夜盘还是白盘：不读时钟

规则是「**每个 `trading_date` 的最后一个原子段是白盘段，之前的都是夜盘段**」（`:213`），因为 `trading_date` 总是以白盘收尾（15:00 / 15:15）。

## 时段（session）

原子段**按模式分组**而成。见 [[位-时段模式]]，五种模式：

| 模式 | 一个时段 = |
|---|---|
| **日夜分开**（本装配用） | 一个原子段 |
| 交易日 夜→日 | 一个 `trading_date` 的夜 + 日 |
| 自然日 日→夜 | 白盘段 + 紧随其后的夜盘段 |
| 只日盘 / 只夜盘 | 一个原子段，但另一半不可交易 |

「一个时段最多一笔 + 时段结束强制平仓」这两条纪律作用在**时段**上。本装配把强平关掉了（[[持仓时长-跨时段持有加最长上限]]），所以模式在这里主要只影响哪些 bar 可开仓。

## 关键：分箱只用原子段，不用时段

**把两个原子段并成一个「时段」是交易纪律层面的事，不能让它把 K 线也粘起来。**

分箱键 = `(原子段号, 开盘时刻向下取整)`。不带段号，一根 30m 会横跨夜→日那 6.5 小时断口，甚至横跨周末 58 小时。由 `tests/test_v3_timeframes.py:100` 钉死「任何一根合成 bar 都不可能跨段」。

唯一的例外是日线——它按 `trading_date` 分箱，一个交易日 = 夜盘段 + 白盘段，**必然跨段**，`src/data/v3_timeframes.py:274` 对它单独开了口子。
