## 已确认的决策

| # | 决策 | 取值 |
|---|---|---|
| 1 | 武装范围 | **按时段重置**。每个 `session_id` 开盘清空武装状态，运行极值从本时段首根重算 |
| 2 | 止损 | **镜像突破半边的 giveback 公式**（见下），`d = 3`，只用四条线 + Bbreak/Sbreak 作天花板 |
| 3 | 触发基准 | **触及即算**：`low[i−1] < Senter` 开空 / `high[i−1] > Benter` 开多；成交在 `open[i]` |
| 4 | 作废 | **不作废**。武装一旦触发就保持到时段结束或成交 |
| 5 | 其余 | 全部沿用突破半边的 baseline，逐条见下 |

### 原样继承的 baseline（不得改动）

- 信号读**已收盘的 bar i−1**，成交在 **bar i 的 open**
- **一根 bar 只做一件事**（入场 或 出场，不可兼得）
- **跳空补价**：`min(stop, open)` 多 / `max(stop, open)` 空
- **同根既触止损又是时段末根 → 止损优先**
- **时段末根不入场、时段首根不入场**
- **每个交易时段最多一笔**
- **时段结束强制平仓**，`reason = SESSION_END`
- **无止盈**，只有追踪止损
- 极值折入在止损测试**之后**，带 `pos != 0` 守卫
- `MFE_geo` 以**理论线**为基准，成交价与理论线之差全额进盈亏、零传导到止损位
- 逐根 mark-to-market 权益曲线；`cost_bps = 0.0` 留旋钮
- 复权、k0 共享、脏数据过滤、时段推导 —— 全部复用 `src/data/v3_sessions.py`，一行不改

## 1. 策略数学

### 1.1 四条线与状态机

只用 **Ssetup / Senter / Benter / Bsetup**（Bbreak / Sbreak 不参与入场，但参与止损的天花板/地板，见 1.2）。

```
武装空 (arm short):  本时段运行最高价 ≥ Ssetup        —— 「观察卖」
触发空 (fire short): 已武装 且 low[i−1] < Senter      —— 「反转卖」→ 成交在 open[i]

武装多 (arm long):   本时段运行最低价 ≤ Bsetup        —— 「观察买」
触发多 (fire long):  已武装 且 high[i−1] > Benter     —— 「反转买」→ 成交在 open[i]
```

「观察价的作用是武装（arming）」是原文第 38 行的原话：*它把一个静态价格变成"必须先走过一段路才生效"的条件，用于排除开盘即贴着该价位来回震荡的情形。*

**同一根 bar 可以既武装又触发。** 运行极值取到 **i−1 为止（含）**，所以一根 `high ≥ Ssetup 且 low < Senter` 的 bar 会当场武装并触发，次根开盘成交。要求武装严格早于触发需要把极值退到 i−2，反而在语义上更绕。留一个开关 `arm_must_precede_trigger`，默认 `False`。跨度门槛：这需要单根 bar 跨越 `Ssetup − Senter`，对 RB 约 13.4 点（0.44%）—— 1 分钟里罕见但存在。

**方向冲突不可能发生。** `Senter − Benter = 0.605·(H−L)`（代数恒等式，写成测试钉住）。一根 1 分钟 bar 不可能同时跌破 Senter 又突破 Benter —— 那要求单根跨越 0.6 倍前日振幅。仍然写一条 `if up and dn: 跳过该 bar` 的显式守卫 + 一个计数器，真发生了要能看见而不是静默偏向某一侧。

### 1.2 止损：镜像 giveback

**同一个 giveback 表达式，同一组常数，只换入场线。**

```
giveback = (Bbreak − Senter) − (Bbreak − Ssetup)/d + MFE_geo·(1 − 1/d)
```

反转空头：入场理论线 = `Senter`，`MFE_geo = Senter − trough`，`stop = trough + giveback`

```
stop_空 = Bbreak − [ (Bbreak − Ssetup) + MFE_geo ] / d
```

反转多头由反射 `p ↦ −p, (H,L,C) ↦ (−L,−H,−C)` 得到（该反射把 `Ssetup ↔ −Bsetup`、`Senter ↔ −Benter`、`Bbreak ↔ −Sbreak` 互换）：

```
stop_多 = Sbreak + [ (Bsetup − Sbreak) + MFE_geo ] / d      MFE_geo = peak − Benter
```

**为什么这才是正确的镜像。** 那个常数项是一段**距离**，与从哪条线入场无关：

```
初始风险_空 = stop_空(MFE=0) − Senter = (Bbreak − Senter) − (Bbreak − Ssetup)/d
初始风险_多(突破) = Bbreak − stop_多(MFE=0) = (Bbreak − Senter) − (Bbreak − Ssetup)/d
```

**逐字相同的表达式。** 实测（RB，参照日 H/L/C = 3085/3053/3061，R = 32）：

| | 入场线 | 初始止损 | 风险 |
|---|---|---|---|
| 突破 多 | Bbreak 3098.60 | 3078.00 | 20.60 (0.66%) |
| **反转 空** | **Senter 3074.40** | **3095.00** | **20.60 (0.67%)** |
| 突破 空 | Sbreak 3033.80 | 3054.68 | 17.64 (0.58%) |
| **反转 多** | **Benter 3055.04** | **3037.40** | **17.64 (0.58%)** |

于是 `突破多 ≡ 反转空`、`突破空 ≡ 反转多`（它们共用同一对线），两个策略**天然风险可比** —— 这正是 A/B 两个策略时想要的性质。

**语义上也是对的**：反转空的止损落在 Bbreak 正下方 `(Bbreak − Ssetup)/d` 处 —— 逆势空单错在哪里？错在市场真的向上突破了。这个位置是镜像自动给出的，不是硬凑的。

**不用 ATR。** 会引入新指标、新参数，还会破坏上面那条风险可比性。

**恒成立的性质**（写成测试）：
- `stop_空(MFE=0) > Senter` 恒成立（等价于 `Bbreak − Senter > (Bbreak − Ssetup)/d`，因 `Bbreak > Ssetup > Senter` 且 `d ≥ 1`）；多头对称。
- `trough` 单调不增 ⇒ `stop_空` 单调不减地收紧，永不放松。
- 与突破半边一样**不设保本地板**。

### 1.3 盈亏

`pnl = (entry_px − exit_px)/entry_px`（空），`entry_px = open[i]`。理论线只驱动止损，成交滑点全额进盈亏。

## 3. 回测主循环

与突破引擎**逐行同构**，只有第 3 步（入场）不同。全部预取 numpy 数组。

```
pos = 0; entry_i = -1; entry_px = nan; theo = nan; ext = nan; capital = 1.0
used_sid = -1
armed_s = False; armed_l = False          # 本时段的武装状态
run_hi = -inf;  run_lo = +inf             # 本时段运行极值(决策 1: 按时段重置)
cur_sid = -1

for i in 0 .. n-1:
    D = day[i]; S = sid[i]; acted = False

    if S != cur_sid:                       # 换时段 -> 武装与运行极值全部重置
        cur_sid = S; armed_s = armed_l = False; run_hi = -inf; run_lo = +inf

    # ── 1. 出场 ── 仅当持仓在 bar i 之前就已建立   [与突破引擎完全相同]
    if pos != 0 and entry_i < i:
        if pos == -1:                                        # 反转空
            stop = BB[D] - ((BB[D] - SS[D]) + ext) / d       # ext = Senter - trough
            hit  = h[i] >= stop
            px   = max(stop, o[i]) if gap_fill else stop
        else:                                                # 反转多
            stop = SBK[D] + ((BS[D] - SBK[D]) + ext) / d     # ext = peak - Benter
            hit  = l[i] <= stop
            px   = min(stop, o[i]) if gap_fill else stop
        trail_arr[i] = stop
        if hit:                     close(i, px, "TRAIL");       acted = True
        elif last_of_sess[i]:       close(i, c[i], "SESSION_END"); acted = True

    # ── 2. 折入本根极值 —— 必须在测试之后 ──
    if pos != 0:
        ext = max(ext, SE[D] - l[i]) if pos == -1 else max(ext, h[i] - BE[D])

    # ── 3. 入场（唯一与突破不同的一块）──
    #    武装用**到 i−1 为止**的运行极值; 触发也只读 bar i−1。
    if (pos == 0 and not acted and valid[D] and S != used_sid
            and not last_of_sess[i] and not first_of_sess[i]):
        j = i - 1
        if run_hi >= SS[D]: armed_s = True          # run_hi 已含 h[j], 不含 h[i]
        if run_lo <= BS[D]: armed_l = True
        up = armed_l and h[j] > BE[D]
        dn = armed_s and l[j] < SE[D]
        if up and dn:  ambiguous += 1               # 代数上不可能, 但要能看见
        elif dn:       open_(i, -1, o[i], theo=SE[D]);  used_sid = S
        elif up:       open_(i, +1, o[i], theo=BE[D]);  used_sid = S

    # ── 3b. 运行极值折入本根(供下一根的武装判定) ──
    run_hi = max(run_hi, h[i]);  run_lo = min(run_lo, l[i])

    # ── 4. 逐根 mark-to-market ── [与突破引擎完全相同]

open_(i, dir, px, theo):
    pos, entry_i, entry_px, theo = dir, i, px, theo
    ext = 0.0                                  # MFE_geo 从理论线量起, 入场时为 0
    trail_arr[i] = 初始止损
    ext = max(ext, SE[D]-l[i]) if dir==-1 else max(ext, h[i]-BE[D])   # 折入本根
```

`ext` 存的是 **MFE_geo 本身**（一个非负标量），不是极值价 —— 比突破引擎存 `peak` 更直接，因为反转的两个方向用的是两条不同的理论线。`ext` 单调不减 ⇒ 止损单调收紧。

### 无未来函数逐行审计

| 步骤 | 读取 | 触及的最新 bar |
|---|---|---|
| 止损位 | `BB[D]`/`SS[D]`（来自 D−1 日 OHLC）、`ext` | **i−1** |
| 止损触发判定 | `h[i]` / `l[i]` | i（事件本身） |
| 跳空补价 | `o[i]` | i（成交那一刻已知） |
| 收盘平仓 | `last_of_sess[i]`、`c[i]` | i（形状静态；close 是成交价） |
| MFE 折入 | `h[i]`/`l[i]` —— **在测试之后** | i，只影响 i+1 |
| **武装判定** | `run_hi`/`run_lo` —— **只到 i−1** | **i−1** |
| 入场触发 | `h[j]`/`l[j]`, j=i−1；`SE[D]`/`BE[D]` | **i−1** |
| 入场成交 | `o[i]` | i（开盘价） |

关键：**第 3b 步（运行极值折入本根）必须排在第 3 步之后**，否则 bar i 的 high 会参与决定 bar i 自己的武装状态。这是本策略新增的唯一一处未来函数风险点，与第 2 步同形，用同一套截断测试钉住。

## 5. 测试

`tests/test_rbreaker_reversal.py`，沿用 `tests/conftest.py` 的 `make_prepared` fixture（合成 bar + 显式参照日 OHLC）。参照日固定 H=110 L=90 C=100 →
`Ssetup 113.5 / Senter 106.05 / Benter 93.95 / Bsetup 86.5 / Bbreak 120.25 / Sbreak 79.75`，
反转空初始止损 `= 120.25 − 6.75/3 = 118.00`，反转多初始止损 `= 79.75 + 6.75/3 = 82.00`。

**几何/公式**
- `Senter − Benter == 0.605·(H−L)`（随机输入 200 组）—— 钉住方向冲突不可能
- 闭式解 == 逐字照抄的 giveback 表达式（多空各 500 组随机输入，差 < 1e-12）
- **`初始风险_反转空 == 初始风险_突破多`**、`初始风险_反转多 == 初始风险_突破空` —— 钉住「镜像同距」这条本次的核心结论
- 初始止损恒在入场线的正确一侧；`ext` 增大 ⇒ 止损单调收紧

**状态机**
- 未武装时跌破 Senter **不**入场
- 武装后跌破 Senter 入场，成交价 == `open[i]`，`theo_entry == Senter`
- 同一根既武装又触发 → 次根成交（默认开关下）
- `arm_must_precede_trigger=True` 时同一根不成交
- **武装按时段重置**：夜盘触及 Ssetup，白盘跌破 Senter → **不**入场
- 同一时段内武装保持（不作废）：触及 Ssetup → 冲破 Bbreak → 崩回 Senter 下方 → **入场**
- 空头是多头的反射（`p ↦ 200 − p`）

**基线纪律（与突破引擎逐条对齐）**
- 一根一动作 / 每时段一笔 / 不跨时段 / 时段首末根不入场
- 跳空按 open 成交、`gapped` 为真
- 时段末根强制平仓；同根止损优先于收盘
- **截断法无未来函数**：把 bar i 之后全部覆写成随机垃圾重跑，`exit_bar_idx < i` 的交易逐字节相同、`trail_stop[:i]` 全等
- **武装的无未来函数**：把 `high[i]` 改成天文数字，bar i 的入场决策必须不变（钉住第 3b 步的位置）
- `cost_bps` 每来回只扣一次；权益曲线 == 逐笔复利

`tests/test_rbreaker_smoke.py` 扩展成 59 品种 × 2 策略，逐品种打印两行，并断言两个策略的结构不变量都成立。

## 7. 已知风险

1. **从空仓武装入场是版本选择，不是原版**（见 Context）。面板副标题已带系数；文档里必须写明这一条，任何对外引用都要声明。
2. **逆势策略缺趋势过滤。** `v3.0-RSCH-策略逻辑评级与规则应对.md` 给逆势/回归类的评分是 7.5，且明确写着「**趋势日会连续亏损，须叠加状态过滤才自洽，独立成立性打折**」；而 `v3.0-RSCH-R-Breaker与Turtle运行逻辑.md` 第 16 行正是说 R-Breaker **没有趋势过滤器**。预期这个策略在单边趋势日连续挨打 —— 这不是 bug，是这类逻辑的已知失效模式，第一版结果出来后应该按 `trading_date` 分组看亏损的聚集性。
3. **涨跌停板对逆势的约束比对突破更硬。** 评级文档第 11 章：「距板一定幅度内禁反向开仓」。本次不实现（仓库没有停板数据），记录在案。
4. **`d = 3` 同样很松。** 突破半边实测离场以收盘为主（AG 25 止损 / 137 收盘）。反转的初始风险与突破同距，预期形态类似。`d` 是第一个该调的参数，两个策略应该一起调以保持可比。
5. **两个引擎的循环骨架重复约 60 行。** 基线纪律（跳空 / 一根一动作 / 时段强平 / 极值折入位置）在两处各写一遍。加交叉引用注释，并让 smoke 测试对两个策略跑同一套结构断言，是本次选择的补偿手段。

## 一处对计划正文的更正（重要）

计划 §1.1 写着「**方向冲突不可能发生**：`Senter − Benter = 0.605·(H−L)`，一根 1 分钟 bar 不可能同时跌破 Senter 又突破 Benter」。

**这个推理是错的。** 空头触发条件是 `low < Senter`、多头是 `high > Benter`，而 `Senter > Benter` —— 一根**整根落在 `[Benter, Senter]` 带内**的 bar 同时满足两者，根本不需要跨越 0.605R。计划里那条守卫（`if up and dn: 跳过该 bar`）会把这类 bar 全部跳过，而它们在两个方向都武装之后会连续出现，导致**那些时段一笔都不做**。

改成了一条真正的规则：**最近发生的那个极值胜出**。触及 Ssetup 武装空、触及 Bsetup 武装多，谁更晚发生谁生效（`armed_dir ∈ {-1, 0, +1}`）——你要 fade 的是最新的那一段推动。两个方向因此**永不同时生效**，是构造性的而非靠事后守卫。

实测影响很小，但规则本身是必需的：

| 品种 | 时段总数 | 两个方向都武装的时段 | 旧守卫会跳过的 bar |
|---|---|---|---|
| RB | 510 | 0 (0.0%) | 0 |
| AU | 510 | 3 (0.6%) | 83 |
| IF | 258 | 9 (3.5%) | 197 |
| CU | 510 | 1 (0.2%) | 0 |

两个方向都武装需要时段振幅覆盖 `Bsetup..Ssetup`（1.35 倍前日振幅），本身就罕见——所以计划的**结论**大致成立，但**理由**站不住。改动后 8 个品种的成交笔数一根未变。

保留了「单根同时越过 Ssetup 和 Bsetup」（真需要跨越 1.35R）的计数器，全 59 品种一年内只有 PF 和 TA 各 1 根。

## 验证过的不变量

pytest **103 项全绿**（10 项 v2.1 原有 + 67 项突破 + 26 项反转），外加真实数据上的三轮校验：

* **镜像同距**（本次的核心结论）：`初始风险_反转空 == 初始风险_突破多`、`初始风险_反转多 == 初始风险_突破空`，在 300 组随机参照日上逐值相等；并在 8 个品种的**每一个合法交易日**上逐日核对。另有一条用非对称参照日（C 偏上）的测试，确认这两对常数**确实不相等**（11.025 vs 12.875），否则前一条可能因为"什么都相等"而假通过。
* **闭式解 == 原始 giveback 表达式**：多空各 500 组随机输入，差 < 1e-12。
* **无未来函数（截断法）**：把 bar i 之后全部覆写成随机垃圾重跑，`exit_bar_idx < i` 的交易逐字节相同、`trail_stop[:i]` 全等。合成数据和 8 个真实品种上都验过。
* **武装的无未来函数**：把某根的 high 改成 999，该根的入场决策必须不变——钉住「运行极值在入场块之后才折入本根」这个新增的风险点。
* **武装按时段重置**：夜盘触及 Ssetup、白盘跌破 Senter → 不入场。
* **不作废**：触及 Ssetup → 冲破 Bbreak → 崩回 Senter 下方 → 仍然入场。
* **基线纪律**：一根一动作 / 每时段一笔 / 不跨时段 / 时段首末根不入场 / 跳空按 open 成交 / 时段末强平 / 止损单调收紧 / 成本每来回只扣一次 / 权益曲线 == 逐笔复利 —— **两个引擎跑同一套断言**，59 品种全历史窗口逐笔核对。
* **两个策略互不干扰**：同一份 `Prepared` 上先后跑两个引擎，结果逐值不变（防止任一引擎意外改写共享数据）。
* **图表层**：桩 `Chart` 无窗口建整个 app，24 段脚本按库的方式拼成一个 blob 送进 `node --check` —— 通过；两条止损线各自的透明点数 == 各自的笔数且落在各自的出场根上。
* **纯浏览器未回归**：`load_minute` 输出契约、`show_minute_candles` 构建、`UI_FONT` 再导出，均通过。

## 对结果的诚实解读

1. **这一年反转看起来比突破好，但这不构成证据。** 一年是一个 regime；成本为 0；且两个策略的参数都没调过。`v3.0-RSCH-策略逻辑评级与规则应对.md` 给逆势/回归类的评分是 7.5 并写明「趋势日会连续亏损，须叠加状态过滤才自洽，独立成立性打折」——本策略没有任何趋势过滤。中位夏普 +0.31 在 59 个品种上远不足以拒绝「无 edge」。
2. **两者近乎正交（相关 +0.145）比两者各自的收益更有价值。** 如果后续要组合，这是理由；但组合之前应该先各自解决成本问题。
3. **成本仍是 0。** 反转一年 5,005 笔 / 59 品种 ≈ 85 笔/品种，2bp 往返就是约 1.7% 的累计拖累——对中位 +1.23% 的净收益，这一项足以翻转符号。
4. **反转的离场同样以收盘为主**（1,308 止损 : 3,697 收盘），和突破一样是 `d=3` 太松的直接后果。两个策略应该一起调 `d` 以保持镜像同距这个性质。
