# R-Breaker 两半边耦合方式编目

## 采用版本与差异（按指令核实）

本文全篇采用**指令中给出的 pivot 版**作为基准坐标系，六价位由大到小：
`Bbreak > Ssetup > Senter > Pivot > Benter > Bsetup > Sbreak`（该顺序在 H ≥ C ≥ L 时可代数证明恒成立）。

公开流传至少两个互不兼容的版本，且被普遍当作"同一个 R-Breaker"讨论：

| | 版本 A：pivot 版（本文基准） | 版本 B：系数版（中文圈实际最主流） |
|---|---|---|
| 构造 | Pivot=(H+C+L)/3，各价位为 Pivot 的线性外推 | Ssetup=H+0.35(C−L)；Senter=1.07/2·(H+L)−0.07L；Bbreak=Ssetup+0.25(Ssetup−Bsetup) |
| **反转带宽 Senter−Benter** | **= H − L（前日全幅）** | **= 0.07·(H−L)** |
| 反转带中心 | 2·Pivot − (H+L)/2，随 C 偏移 | 恒为 (H+L)/2，与 C 无关 |
| 后果 | 反转对相距很远，两步路径必须走完很长的路 | 反转对贴在中价两侧，价格在中枢附近微幅摆动即可反复穿越 |

**这个差异是数量级的，不是参数级的。** 版本 B 的反转带只有版本 A 的约 1/14，凡是涉及"砍掉路径依赖会怎样"（见 Part 3）的判断，在两个版本下结论强度完全不同。任何未声明版本的 R-Breaker 讨论都是含糊的。

来源与可信度：
- 版本 B 参数化形式（a/b/c/d 四参数）：VeighNa（vn.py）社区帖《解密并强化日内经典策略 R-Breaker》，作者 KeKe，2019-10-13，<https://www.vnpy.com/forum/topic/1597-jie-mi-bing-qiang-hua-ri-nei-jing-dian-ce-lue-r-breaker> ——**[实盘]**
- 版本 A 与版本 B 并列列举：VeighNa 社区帖《网络上 R Breaker 策略六条线计算的几种方法》，<https://www.vnpy.com/forum/topic/5755-wang-luo-shang-r-breakerce-lue-liu-tiao-xian-ji-suan-de-ji-chong-fang-fa> ——**[实盘]**
- 归属叙述（Richard Saidenberg 开发、1994 年公布、连续十五年入选《Futures Truth》Top10）在中文材料中被大量互相转抄，**未见任何可查的一手出处**，《Futures Truth》为订阅制商业刊物、无公开可验证的期号索引。**该归属应视为来源不可考的行业传说，不构成 [文献]。**

# Part 1 · 依附反手型（经典基准）

反转半边没有独立生命，它是突破半边所建仓位的一个**带路径条件的反向出口**。

### 四问答案

1. **仅反手。** 反转半边在 FLAT 状态下不产生任何委托。它的触发前提是"当前有仓"，而仓只可能来自突破半边。
2. **结构上不发生冲突。** 突破半边只在 FLAT 在线，反转半边只在持仓时在线，两者定义域不相交。代价：持多单时价格一路跌破 Sbreak，系统**不做任何事**——这是本 part 最反直觉、也最常被实现者私自"修好"的一条。
3. **完整保留两步。** setup 触及是状态记录，enter 跌破是触发。
4. **单向依赖。** 突破半边的状态（是否已建仓）完全决定反转半边的资格；反向不成立，反转半边的状态不影响突破半边。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT | 在线：上破 Bbreak 开多，下破 Sbreak 开空 | **完全离线**（可记录 setup 状态位，但不产生动作） | FLAT → 多 / 空 |
| 持多 | **离线**（不再监控任何突破价位） | 在线两步：日高 ≥ Ssetup 置位 → 价跌破 Senter → 反手做空 | 多 → 空（唯一路径）；止损/收盘 → FLAT |
| 持空 | **离线** | 日低 ≤ Bsetup 置位 → 价升破 Benter → 反手做多 | 空 → 多；止损/收盘 → FLAT |

### 持仓假设

**必须日内强平。** setup 状态位是当日路径的函数，隔夜后既无定义也无法延续；六价位盘前静态，跳空会一次性跨越多条线，使"两步"在开盘瞬间被压缩成零步。

### 区别轴

基准。其余各 part 均以"改动了四问中的哪一问"相对它定位。

### 退化关系

最接近 **Part 2**。只要允许 setup→enter 序列在 FLAT 状态下也执行委托，Part 1 立即成为 Part 2；反向地，Part 2 关闭 FLAT 下的反转挂单即退回 Part 1。

### 实现

**1-a｜标准反手单（状态位 + 双倍手数一次成交）**
- 机制：维护布尔量 `flag_S = (当日 high ≥ Ssetup)`；持多且 `flag_S` 且 `last < Senter` 时，发出 2×手数的卖出委托，一次成交完成平多与开空。
- 主要失效情景：冲高回落后立刻二次上攻的日子——反手空单恰好开在当日次低点附近，且因已翻空而错过整段主升。
- **[实盘]**（各量化平台样例代码的通行写法；具体首倡者来源不可考）

**1-b｜平反分离（只平不反 / 平后需二次条件才反向）**
- 机制：触发时先发平多委托；反向开空需追加条件（如该 bar 收盘价仍在 Senter 下方，或等到下一根 bar）。
- 主要失效情景：单边急跌日——平仓正确但放弃了反手段的全部利润，系统退化为"带路径条件止盈的纯突破系统"。
- **[实盘]**（vn.py 版原文明确写作"开仓做空**或者反手（先平仓再反向开仓）**做空"，把两种成交结构并列而未择一，见前引 KeKe 2019 帖）

**1-c｜三步确认（enter 跌破后要求 N 根 bar 内不收复）**
- 机制：触 Ssetup → 破 Senter → 其后 N 根 bar 内价格不重新站上 Senter，才执行反手。
- 主要失效情景：V 型反转日——确认走完时价格已远离 Senter，反手价严重劣化，盈亏比被吃掉。
- **[推测]**（未见成型的公开实现；"加确认必然牺牲触发价"这一权衡本身是常识，但三步版本本身是外推）

# Part 2 · 双向对等型（反转半边取得独立开仓权）

两个半边升格为两个**并列的信号源**，共用一套价位，各自可从 FLAT 开仓。这是中文圈实际最常被写出来的版本，尽管它常被当作"经典"介绍。

### 四问答案

1. **可从空仓直接开仓。** setup→enter 序列在 FLAT 下同样成立，成交结果是新开仓而非反手。
2. **必须显式裁决。** 这是唯一让两个半边在同一状态（FLAT）下同时在线的 part，因此"同 bar 双触发"从结构性不可能变成了必须写死的规则。**同 bar 优先级在本 part 内属实现维度，而非 part 维度**——因为只有本 part 让冲突真实存在。
3. **保留两步。** 若同时砍掉两步，就落入 Part 3。
4. **两个半边彼此独立。** 一个半边是否成交、成败如何，都不改变另一个半边的资格。这一点与 Part 6 正相反。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT | 在线：Bbreak / Sbreak | **同样在线**：日高 ≥ Ssetup 置位 → 破 Senter **开空**（非反手）；下方镜像 | FLAT → 多 / 空，**入口有两条且性质相反** |
| 持多 | 离线（或仅允许更高价同向加仓） | 在线，执行反手 | 多 → 空 |
| 持空 | 离线（镜像） | 在线，执行反手 | 空 → 多 |

**与 Part 1 的分岔情景（同一时刻不同仓位）**：当日价格冲高触及 Ssetup 但**始终未上破 Bbreak**，随后回落跌破 Senter。Part 1 全天空仓；Part 2 在 Senter 处持空。这类"高点落在 Ssetup 与 Bbreak 之间"的日子在震荡市中占比很高，两者的持仓差异是系统性的而非偶发。

### 持仓假设

**日内强平为主，可隔夜但代价明确。** 隔夜需在开盘重置状态位，并接受跳空一次跨越多条线导致两个半边同时"已触发"的歧义——此时裁决规则从裁决同 bar 变成裁决开盘集合竞价，性质不同。

### 区别轴

**Q1：反转半边是否拥有独立开仓权。** 这是与 Part 1 唯一但决定性的分歧。

### 退化关系

最接近 **Part 1**。关闭 FLAT 状态下的反转委托即退化为 Part 1。若同时把仲裁规则设为"突破恒优先且反转当 bar 作废"，在趋势日里两者的成交序列会高度重合，差异只在震荡日暴露。

### 实现

**2-a｜双边停止单（触及 setup 后同时挂出 break 与 enter 两张停止单，先触先成交）**
- 机制：FLAT 且近 N 根 bar 高点 > Ssetup 时，在 `max(Bbreak, 当日最高价)` 挂买入开仓停止单，**同时**在 Senter 挂卖出开仓停止单；两张单构成一组事实上的 OCO，价格先扫到哪张就成哪张。可对两侧配置不对称手数（原实现为突破 1 手、反转 3 手）。
- 主要失效情景：单根 bar 内价格快速扫过两条线——两张单可能**都成交**，账户同时留下一多一空。该缺陷由社区成员在原帖 #14 楼直接指出，原文未修正。
- **[实盘]**（KeKe，《解密并强化日内经典策略 R-Breaker》，VeighNa 社区，2019-10-13，<https://www.vnpy.com/forum/topic/1597-jie-mi-bing-qiang-hua-ri-nei-jing-dian-ce-lue-r-breaker>）

**2-b｜突破恒优先（同 bar 双触发时执行突破，反转信号当 bar 作废）**
- 机制：bar 内条件求值顺序固定为先 `Bbreak/Sbreak` 后 `Senter/Benter`，命中前者则跳过后者，反转状态位不清零、留待下一根 bar。
- 主要失效情景：假突破日——恰恰是反转半边最该发挥作用的日子，规则把优先权让给了错误的一方。
- **[实盘]**（绝大多数公开代码的隐含行为，来源于 if/elif 的书写顺序而非有意设计；**来源不可考**）

**2-c｜禁止同 bar 双触发（冻结当 bar，下一 bar 重新判定）**
- 机制：检出同 bar 双条件成立则不下任何单，把两个信号都推迟到下一根 bar 用新的开盘价重新求值。
- 主要失效情景：高波动日——真正有价值的行情恰恰集中在双条件同时成立的大幅 bar 上，冻结等于系统性回避最大的那几根 K 线。
- **[推测]**

# Part 3 · 路径剥离型（反转价位降级为静态翻转线）

砍掉 setup 记录，Senter / Benter 直接作为价格穿越触发。

### 四问答案

1. **通常可从空仓开仓**（也可限制为仅反手，但那样它只是个反向止损）。
2. **实际上反转恒优先，且无须规则。** 因为 `Benter < Pivot < Senter` 且两者比 Bbreak / Sbreak 更靠近开盘价，价格从任何常规起点出发几乎总是先触及 enter 线。裁决规则写不写都一样。
3. **砍掉。性质发生根本改变**——这是本 part 的全部内容：
   - 两步的作用是把 Senter 从一条**价格线**变成一条**失败确认线**：只有当价格先证明了自己能到 Ssetup、然后跌回来，跌破 Senter 才叫"冲高失败"。
   - 砍掉第一步后，因 `Senter > Pivot` 恒成立，"跌破 Senter 做空"就变成**在中枢上方做空**，语义从"衰竭反转"塌缩为"区间均值回归"。
   - 更具体的破坏：价格在 Benter–Senter 之间来回时，系统会在下行穿 Senter 处翻空、在上行穿 Benter 处翻多，形成一台在最不该交易的中枢区域全速运转的翻转机。这台机器的转速由版本决定——版本 A 的带宽 = H−L，一天转不了几圈；**版本 B 的带宽仅 0.07(H−L)，同样的震荡幅度下翻转次数高一个数量级**。
4. **弱耦合。** 两个半边只共享价位表，不共享状态。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT | 在线，但因价位更远而**几乎总是被反转半边抢先** | 在线，无前置条件：跌破 Senter 开空 / 升破 Benter 开多 | FLAT → 多 / 空，实际入口以反转为主 |
| 持多 | 离线 | 跌破 Senter 即反手，**不问当日是否曾摸到 Ssetup** | 多 → 空 |
| 持空 | 离线 | 升破 Benter 即反手 | 空 → 多 |

**与 Part 1 / Part 2 的分岔情景**：当日高开后直接下跌、全天未触及 Ssetup。Part 1 / Part 2 的反转半边从未武装，价格跌破 Senter 无事发生；Part 3 已在 Senter 处持空。

### 持仓假设

**两者皆可——这是它唯一的结构性优势。** 砍掉路径依赖后系统不再持有任何当日状态，六价位退化为一张纯静态网格，跨日持仓在逻辑上自洽（代价是它已不再是 R-Breaker，而是一个日线级别的区间翻转系统）。

### 区别轴

**Q3：路径深度。** 唯一被改动的问题，但它改的是反转半边的语义本身，而非触发时点。

### 退化关系

最接近 **Part 2**。加回 setup 状态位即升为 Part 2；若同时取消 FLAT 开仓权则升为 Part 1。

### 实现

**3-a｜静态六价位翻转（无状态位，触线即动作）**
- 机制：每根 bar 只判 `close`（或 `last`）与六条线的相对位置，不维护任何当日高低点记录。
- 主要失效情景：中枢窄幅震荡日——每次穿越都产生一次双倍手数的反手，手续费与滑点线性累积而方向收益为零。
- **[实盘]**（大量公开代码事实上就是这样写的，多数并非有意选择，而是把 setup 一步默默省略；**来源不可考**）

**3-b｜一步 + bar 收盘确认**
- 机制：要求 bar 的收盘价（而非最高/最低价）越过 Senter / Benter 才触发，用收盘过滤盘中毛刺。
- 主要失效情景：在 1 分钟、5 分钟级别上，收盘价与最高/最低价的差别本身就是噪声量级——过滤掉的和放行的属于同一分布，只是牺牲了触发价。
- **[推测]**（收盘确认是通行做法，但把它当作路径依赖的替代品是外推；**我不看好这一条，见收尾第 3 节**）

# Part 4 · 互斥在线型（外生 regime 决定启用哪个半边）

两个半边**永不同时在线**。由一个与两者都无关的外部变量（时钟或市况判定）决定当前谁有资格。

### 四问答案

1. **在其在线窗口内可从空仓开仓**——因为窗口内它是唯一的系统，若限制为仅反手则该窗口永远无仓可反。
2. **冲突不可能发生。** 不是"规定了优先级"，而是"定义域被外生变量切开"。任何写下的仲裁规则都是死代码。
3. **通常保留两步**（在反转窗口内），因为窗口本身已经承担了一部分过滤职能，两步用于过滤剩余部分。
4. **两个半边互不影响。** 门控来源是**外生的**——时钟或 regime 判定，与任一半边的持仓和成败无关。这是与 Part 6 的分界。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT・突破窗口（早盘 / 判定为趋势态） | 在线 | **离线**（不挂单；状态位可记可不记） | FLAT → 多 / 空（仅突破入口） |
| FLAT・反转窗口（尾盘 / 判定为震荡态） | **离线** | 在线，可空仓开仓 | FLAT → 多 / 空（仅反转入口） |
| 持多 | 若仍在突破窗口：只有移动止损，不反手 | 若窗口已切换：允许一次反手，或直接强平交由反转半边重开 | 多 → 空，或 多 → FLAT（窗口切换强平） |
| 持空 | 镜像 | 镜像 | 空 → 多 / FLAT |

**与 Part 2 的分岔情景**：尾盘价格上破 Bbreak。Part 2 开多；Part 4 忽略（突破半边此时离线），可能反而因反转条件成立而持空。

### 持仓假设

**日内强平。** 门控轴本身就是日内时钟或按日重置的市况判定；跨日持仓会让持仓的"归属窗口"失去定义。

### 区别轴

**两个半边是否可同时在线**，且门控变量是外生的。

### 退化关系

最接近 **Part 2**。把窗口设为全天恒开，两个半边即同时在线，成为 Part 2（此时 Part 2 的仲裁规则从死代码变为活代码）。

### 实现

**4-a｜时段分工（早盘只做突破，尾盘只做反转 + 强平）**
- 机制：以交易时钟切分，如开盘后 X 分钟内仅启用 Bbreak / Sbreak；收盘前 Y 分钟仅启用 Senter / Benter，并在 exit_time 无条件平仓。
- 主要失效情景：整段趋势发生在尾盘窗口的日子——突破半边已离线，系统只能逆着这段趋势做反转。
- **[实盘]**（`exit_time` 尾盘强平是所有公开实现的通行做法，见前引 vn.py 代码；把时段进一步用于**分配半边**则较少见，来源不可考）
- 其所依赖的底层现象"日内动量"有同行评议文献支持：**Lei Gao, Yufeng Han, Sophia Zhengzi Li, Guofu Zhou, "Market intraday momentum," *Journal of Financial Economics*, 2018, 129(2): 394–414**，<https://doi.org/10.1016/j.jfineco.2018.05.009> ——该文以 1993–2013 年 SPY 高频数据显示首个半小时收益可预测最后半小时收益，且在高波动、高成交、宏观数据发布日更强。**[文献]** 注意：文献支持的是"日内首尾存在动量关联"这一现象，**不支持任何具体的时段切分参数，更不支持 R-Breaker 这一模板**。

**4-b｜趋势 / 震荡 regime 切换**
- 机制：用开盘区间宽度 (H−L)/ATR、ADX、或近 N 根 bar 的唐奇安通道宽度判定当日形态，趋势态只启用突破半边，震荡态只启用反转半边。
- 主要失效情景：regime 反转日——判定量本身是滞后统计量，切换总在形态已经改变之后完成，等于系统性地在每次转折处站错边。
- **[推测]**（regime 择时是通行思路，但用它**排他性地开关 R-Breaker 的某一半边**未见成型公开实现；**我不看好这一条，见收尾第 3 节**）

# Part 5 · 分层仓位型（突破定方向，反转只调仓位）

反转半边被剥夺了改变方向的权力，只保留改变仓位大小的权力。

### 四问答案

1. **两者皆非——这是第三种答案。** 反转半边既不反手也不空仓开仓，它只在既有方向内做减仓（或加仓），仓位方向永远由突破半边决定。
2. **突破定方向优先，反转在方向内调整**，二者不构成竞争关系，可在同一 bar 内先后执行。
3. **保留两步。** 两步在这里的用途从"确认反转"变成"度量衰竭程度"：触及 Ssetup 是衰竭的第一档证据，跌破 Senter 是第二档，因此天然对应两级减仓。这是路径依赖在本 part 中最贴合的用法。
4. **单向依赖，但比 Part 1 更弱。** 反转半边的资格由"当前是否有底仓"决定；突破半边完全不受反转半边影响，可在减仓后重新加回。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT | 在线：破 Bbreak 建多头底仓 1 单位；破 Sbreak 建空头底仓 1 单位 | 离线（无仓可调） | FLAT → 多1 / 空1 |
| 持多 | **仍在线**：可在更高价补回或加仓，但**不可反向** | 日高 ≥ Ssetup → 减至 0.5；破 Senter → 减至 0 | 多1 → 多0.5 → FLAT；**从不出现 多 → 空** |
| 持空 | 镜像 | 日低 ≤ Bsetup → 减至 0.5；破 Benter → 减至 0 | 空1 → 空0.5 → FLAT |

**与 Part 1 的分岔情景**：Senter 被跌破的那一刻，Part 1 的仓位从 +1 变为 −1（净变动 2 单位），Part 5 从 +1 变为 0（净变动 1 单位）。此后价格若掉头重新上破 Bbreak，Part 1 需要先平空再开多，Part 5 直接从 0 到 +1——两者不仅在触发瞬间仓位不同（−1 vs 0），此后整段行情的持仓路径与成本都不同。

### 持仓假设

**可隔夜，且分层仓位的价值主要体现在可隔夜时。** 若强制日内强平，底仓与减仓层在收盘前一律归零，分层只在几个小时内有意义，收益大部分被交易成本吃掉。这与 Part 1 / 4 / 6 的日内属性形成明确对立。

### 区别轴

**反转半边的动作空间**：从"翻方向"缩小为"调仓位"。

### 退化关系

最接近 **Part 1**。把减仓比例设为 200%（即全平并反向建立等量仓位），Part 5 精确退化为 Part 1；设为 100% 则退化为 Part 1 的实现 1-b（只平不反）。

### 实现

**5-a｜两级减仓（Ssetup 减半，Senter 清仓，不反向）**
- 机制：`日高 ≥ Ssetup` 时卖出 50% 底仓；`价 < Senter` 时卖出剩余；若价格重新站上 Ssetup 则按突破半边规则补回。
- 主要失效情景：真正的大级别反转日——系统全程只是逐级退出，完全放弃了反向那一半利润，而反手正是 R-Breaker 与普通突破系统的区别所在。
- **[推测]**（用价位网格做加减仓的**思路**在中文材料中被泛泛提及，如 AiCoin/宽客在线等转载文所述"也可以根据这些网格价格线进行加减仓的头寸管理"，但**未见给出具体分层规则的实现**；因此机制层面判为推测）

**5-b｜在反转价位金字塔加仓（持多时回落至 Benter 加多）**
- 机制：把 Benter 当作多头回调的支撑加仓点，价格回落触及即增加多头仓位。
- 主要失效情景：任何真正的下跌日——在系统自己判定为"当日反转触发线"的位置逆势加仓，风险结构与本策略的其余部分直接冲突。
- **[推测]**（**仅为覆盖"仓位分层"这一方向而列出，我明确不看好，见收尾第 3 节**）

# Part 6 · 交叉门控型（内生状态改变另一半边的资格）

一个半边的**当日成败与触发历史**回过头来改写另一个半边的资格。经典是单向依赖，本 part 把它变成双向且内生。

### 四问答案

1. **视实现而定，且这一问不是本 part 的判别维度。** 门控机制与"反转是否能空仓开仓"正交，可叠加在 Part 1 或 Part 2 之上。
2. **反转优先。** 本 part 的反转半边被赋予"纠错"语义（它的存在是为了否定突破半边的判断），因此在同 bar 冲突时让位给突破是自相矛盾的。
3. **保留，且常被加强为三步**：突破 → 反转 → 锁定，第三步即门控本身。
4. **这就是本 part 的定义特征：双向且内生。** 门控变量由当日盘中路径与交易结果生成——反手发生了几次、突破是否被证伪——而非外部时钟或市况判定（后者是 Part 4）。

### 三态行为表

| 状态 | 突破半边 | 反转半边 | 仓位跃迁 |
|---|---|---|---|
| FLAT・门控未耗尽 | 在线 | 在线（视是否叠加 Part 2 而定） | FLAT → 多 / 空 |
| FLAT・门控已耗尽（如当日反手额度用完，或当日突破已被证伪） | **离线，拒绝一切突破信号** | 视实现保留或一并关闭 | **全天保持 FLAT，即使价格再次上破 Bbreak** |
| 持多 | 离线 | 在线；若反手额度已用完则降级为"只平不反" | 多 → 空 或 多 → FLAT |
| 持空 | 离线（镜像） | 镜像 | 空 → 多 或 空 → FLAT |

**与 Part 1 的分岔情景**：当日已发生一次反手（多 → 空），空单随后止损离场回到 FLAT，此后价格重新上破 Bbreak。Part 1 照常开多；Part 6（额度已耗尽）拒绝入场。同一时刻，一个持多一个空仓，原因不是信号不同而是**资格不同**。

### 持仓假设

**日内强平。** 门控变量按日重置，跨日持仓会让"当日额度"与"当日证伪"两个概念失去锚点。

### 区别轴

**Q4：依赖方向。** 经典是单向（突破 → 反转），本 part 是双向且门控源为内生状态。这与 Part 4 的外生门控是两条不同的轴，不可混为一谈。

### 退化关系

最接近 **Part 1**（或 Part 2，取决于 Q1 如何设置）。把门控条件设为恒真——无次数上限、无证伪禁用——本 part 精确退化为它所叠加的那一个。

### 实现

**6-a｜反手次数上限**
- 机制：计数器 `reversals_today`；达到上限后，反转半边降级为只平不反，且突破半边当日不再接受新开仓信号，系统只允许离场。
- 主要失效情景：额度在早盘被两次噪声反转耗尽，而真正的行情在午后展开——系统全天旁观。上限的取值直接决定这个失效概率，而它没有先验合理值。
- **[实盘]**（日内策略普遍设有当日交易次数或反手次数上限；**具体到 R-Breaker 的实现来源不可考**）

**6-b｜突破证伪后当日禁用突破半边**
- 机制：若当日发生过"突破建仓 → 被反转半边打掉"的完整序列，则把当日标记为震荡日，此后禁用 Bbreak / Sbreak，只保留反转半边。
- 主要失效情景：假突破之后紧跟真突破的日子（早盘诱多、午后主升）——系统用一次失败推断了整天的性质，而这个推断的样本量是 1。
- **[推测]**

# 收尾 1 · 逻辑上互相矛盾、不可同时使用的耦合

1. **Part 3（砍掉路径依赖）与 Part 6（内生状态门控）**：Part 6 的门控变量正是 setup 状态与反转成败序列；Part 3 把这些状态删掉了，门控失去可门控的对象。二者不是"配合不好"，是一方消灭了另一方的输入。
2. **Part 5（只调仓位）与 Part 1 / Part 2（反手）**：同一个 Senter 触发不可能既执行 +1 → −1 又执行 +1 → 0。必须在设计时择一，不存在折中版本（"减 150%"只是把 Part 5 的参数推向 Part 1，不是两者共存）。
3. **Part 4（互斥在线）与 Part 2 的同 bar 仲裁规则**：互斥在线使双触发在结构上不可能发生，任何仲裁规则都是永不执行的死代码。若一份实现同时写了时段分工和 bar 内优先级，其中一个必然是误解的产物。
4. **Part 3 的一步式反转与 Part 6 的次数上限**：一步式反转在中枢震荡时会高频触发，而它唯一的保护恰恰是"继续反转"；次数上限会在保护最需要的时刻切断它，让系统带着最后一次错误方向的仓位度过当日剩余时间。
5. **Part 2 的"突破恒优先"与 Part 6 的"反转优先纠错"**：两者对"谁在裁决谁"给出相反答案。前者认定突破半边是主信号，后者认定反转半边是纠错器。同一系统内只能有一种权力结构。
6. **可隔夜（Part 3 / Part 5）与当日路径状态（Part 1 / Part 4 / Part 6）**：跳空开盘会一次性跨越多条价位，使"当日最高价是否触及 Ssetup"在开盘瞬间既已成立又未经历过程。凡依赖当日路径的耦合，隔夜属性都是伪装的日内属性。

# 收尾 2 · 公开实现中最常被搞错或干脆未指明的

1. **路径依赖被悄悄砍掉，且往往不是有意的。** 大量公开代码直接写 `if price < Senter: short()`，没有 `day_high >= Ssetup` 的状态位。文字描述保留两步、代码只有一步，是最常见的形态。读者以为在讨论 Part 1，实际运行的是 Part 3——而这两者的反转语义完全不同（见 Part 3 第 3 问）。

2. **"仅反手"还是"可空仓开仓"，几乎从来没有被讲清楚，而是被一对括号糊过去。** 中文主流描述写作"在该点位（**反手、开仓**）做空"；vn.py 版写作"如果持有多单（**空仓**）"。括号里那个词决定了系统是 Part 1 还是 Part 2，而两者在震荡日的持仓差异是系统性的。这是整个 R-Breaker 公开材料中最大的一处未指明。

3. **同 bar 优先级基本从不定义，且缺陷已被公开指出而未修正。** 前引 vn.py 实现在 FLAT 时同时挂出 Bbreak 买入停止单与 Senter 卖出停止单，社区成员在原帖 #14 楼指出：若价格在两根 bar 之间快速扫过两条线，两张单可能都成交，留下一多一空。原帖未作修正。绝大多数实现的优先级只是 `if/elif` 书写顺序的副产品，不是设计决策。

4. **六价位公式版本混用而不声明。** 版本 A 的反转带宽 = H−L，版本 B 的 = 0.07(H−L)，相差约 14 倍。两个版本在"反转触发频率"上不属于同一个策略，却被当作同一个 R-Breaker 讨论和比较。

5. **公式抄写错误导致价位顺序颠倒，且被多人指出仍未修正。** 前引 vn.py 代码写作 `buy_break = buy_setup + d*(sell_setup − buy_setup)`、`sell_break = sell_setup − d*(...)`，与其自身文字描述相反，可能出现 Bbreak < Sbreak（原帖 #10、#11、#13 楼均指出）。正确形式应为 `Bbreak = Ssetup + d*(Ssetup − Bsetup)`、`Sbreak = Bsetup − d*(...)`。

6. **"触及"的数据口径未定义，这直接决定回测是否含未来函数。** 用 bar 的 high/low 还是 close？用 tick 还是 bar？当 Ssetup 触及与 Senter 跌破落在同一根 bar 内，只有 tick 级数据能判定先后顺序；用 bar 级数据回测时，"日高 ≥ Ssetup 且 close < Senter"会被判为成立，而实盘中这可能是先跌后涨。这一条几乎所有公开回测都未说明。

7. **归属叙述被反复转抄而无一手来源。** "Richard Saidenberg 开发 / 1994 年公布 / 连续十五年入选《Futures Truth》Top10"这三句话在中文材料中逐字重复，未见任何指向原始出版物、期号或专利的引用。这不影响策略本身，但它意味着**任何声称 R-Breaker 变体有"文献支持"的说法都需要被直接质疑**。

# 收尾 3 · 只为覆盖度列出、我并不看好的实现

1. **5-b（在 Benter 处对多单金字塔加仓）**。它把系统自己标记为"当日反转触发线"的价位当作加仓支撑，语义与反转半边直接冲突；且是逆势摊平，风险结构在本编目所有实现中最差。列出它只是因为"仓位分层"这一覆盖方向理论上包含加仓侧。

2. **3-b（一步 + bar 收盘确认）**。在 1 分钟、5 分钟级别上，收盘价与最高/最低价的差异属于同一噪声分布，收盘确认既没有恢复两步路径所携带的信息（"价格曾经到过阻力位"），又实打实地牺牲了触发价。两头不讨好。

3. **4-b（趋势 / 震荡 regime 切换）**。regime 判定量本身滞后，且其阈值是一组全新的自由参数——很容易把过拟合从价位层面搬到 regime 层面，而参数数量增加了。更值得注意的是反证：前引 vn.py 回测把两个半边**同时在线**做成 1:3 的组合后夏普提升到约 2，其逻辑是两个半边负相关、互为对冲；而 regime 切换恰恰是主动放弃这种对冲，改为押注自己能提前判断市况。**在没有强证据表明 regime 判定准确率显著高于随机之前，切换不如共存。**

4. **6-b（突破证伪后当日禁用突破半边）**。用当日一次失败推断当日整体形态，样本量为 1，且推断方向与"日内动量在高波动日更强"（Gao et al. 2018）的经验证据相反——高波动日既更容易出现假突破，也更容易出现真趋势。
