## ⚠ 一条先验没兑现

方案 §九 写的是：

```
C1  冻结变短  → 笔数增
```

实测：冻结 **77 → 60 根 2h（−22%）**，笔数 **104 → 102（−2）**。方向相反。

**不是「两个开关抵消」**——单独开 C1（on,off）就已经是 102 笔，C2 不参与也一样。三项验收证明两个开关都真的接上了，所以这不是空接。

合理的解释是：解除提前会改变**整条后续轨迹**——早开的那一单占住仓位，挡掉后面本来会开的另一单；或者它自己止损，又触发下一次冻结（CD 次数 10→9）。**笔数对冻结时长不是单调的。**

但按 A1，这一条在 AU 上**不能下结论**：10 个被挡意图撑不起任何因果判断。记在这里是为了 55 品种那一跑时能对照——若横截面上笔数也普遍下降，先验就要改写。
