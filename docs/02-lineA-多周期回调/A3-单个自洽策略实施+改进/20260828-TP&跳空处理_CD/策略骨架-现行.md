# 一、前提条件 / 坐标系

## 前端

四个格位固定 2×2，每格一个下拉框，六个周期（1m/5m/15m/30m/2h/1d）任选，**允许重复**。
默认 `左上 1m · 右上 15m · 左下 30m · 右下 2h`。

>> 二稿写的是「六个 tf + 页面切换」。**改成四格位 + 下拉框**（2026-08-28）——「允许重复」
>> 这一条决定了模型必须是「四个瓦片绑位置、周期可变」而不是「六个瓦片绑周期、位置可变」，
>> 后者没法让同一个周期同时出现在两格。

## 驱动时钟

`策略参数.驱动周期 = "1m"`。

>> 二稿 L15 的 TODO：从 15m 改成 1m。**已做。**

它**只决定「多久看一眼价格」**：成交、出场触发、极值累积、mark-to-market 都在它上面。
**信号层不跟着它走**——大周期永远读 2h 自己的已收盘 bar，回调与两个开关永远读 15m 的，
30m 只出一个 ATR。将来换逐 tick 数据只改这一个字段。

**1m 驱动不增加笔数。** 三条腿全在 15m 及以上，15m 信号在一个 15m 箱内是常数，所以入场
仍落在该箱第一根 1m，`open` 与 15m 的 open 逐字节相同（实测 103 笔全同、价差 0）。变的
只有出场：止损从每 15 分钟查一次变成每分钟一次，出场中位提前 10 分钟。要让笔数变多得把
某条腿下放到 5m 或 1m，那是 TODO 3。

# 二、Entry

## 大周期过滤

2h，`收盘[i-1]` + MA21 + MA55 的三元严格排列：

```
收盘 > MA21 > MA55   ->  多
MA55 > MA21 > 收盘   ->  空
其余（含任意两者相等）->  保持上一状态
```

**没有中间态**——粘性前向填充，「未定」只可能出现在开头暖机段。
大周期翻转是**唯一的全量重置点**：清回调武装与两个开关的观测状态，**但不平仓**。

## 回调判断

15m，同一套三线排列，但必须与 2h **完全反向**（2h 多 → 15m 必须 `MA55>MA21>收盘`）。
读的是**不带粘性**的 15m 瞬时状态——回调要的是「此刻确实完全反向」这个事实。

**闩锁，不过期。** 看到过就记住，只被两件事清空：大周期翻转、入场成交。
被冷静期或闸门挡住的触发**不消耗**武装。

## 入场：两个开关，都开着就在下一根 bar 的 open 成交

>> 二稿把这两项叫「开关」和「锁」。**现在两个都叫开关**（2026-08-28），
>> 区别只在记不记忆。命名与实现在 `strategy/lineA_03.py`。

```
开关1  价格站回 MA21      瞬时，每根重算，不记忆
       开 = 收盘[i-1] > MA21[i-1]              空头镜像
       关 = 不满足

开关2  MACD 水下金叉      闩锁，跨根记忆        柱 = DIF − DEA
       开 = 柱[i-2]<0 且 柱[i-1]>0 且 DIF[i-1]<0 且 DEA[i-1]<0
       关 = 柱[i-2]>0 且 柱[i-1]<0              不看水位
       空头镜像：水上死叉开，下一次金叉关
```

**一瞬时一闩锁的不对称是承重的。** 开关1 闩住就可能在价格已跌回 MA21 之下时入场，与
「重新站回」的原意相反；开关2 若做成瞬时的，就要求它与开关1 恰好同根成立，概率极低，
与门下等于永不入场。

>> 平局取法写死：`柱 == 0` 一律算「不在上行」（开写 `柱[b-1] <= 0`、关写 `柱[b] <= 0`）。
>> 与规格的严格 `< 0` 只在柱恰为 0 时分歧，而全序列 10,006 根里只有下标 0 那一根，
>> 落在暖机守卫内。

**暖机守卫两层，一层都不能省**：`ewm(adjust=False)` 第一根之后永不返回 NaN，前几十根的
DIF/DEA 是垃圾却看不出来。第一层不输出，第二层**守卫期内根本不累积闩锁状态**。

实测分工（103 笔）：开关1「本根刚成立」占 93%，开关2 段龄中位 1 根、94% 在 8 根内；
点火的是开关1 的 63 笔、开关2 的 40 笔。**两个都在干活。**

>> 闩锁**不设段龄上限**。理论上一次水下金叉能授权此后整段行情，但入场几乎都挤在段首
>> ——开关1 已经把时点卡住了，加 8 根上限只砍掉 1 笔。

# 四、TP（吊灯 / 追踪止盈）

```
原线   = 持仓极值 ∓ 3 × ATR(14, 30m)         ATR **每根重取**
阀门   = 原线差于入场价 -> 本根不许用吊灯出场，有效止损退回固定止损
有效线 = 固定止损                if 受阻
         取更优(原线, 固定止损)    otherwise        地板 = 固定止损
```

>> 二稿 L56：**ATR 不再钉死在入场，每根重取**。已做（`止盈_ATR随动`，默认开）。
>> 取的是 `closed_pos` 那一根——「截至本根**已收盘**的 30m」，**不是包含本根的那一根**，
>> 后者成交时还没收盘、用它就是未来函数。09:31 那根 1m 对应 09:30 的 30m，不是 10:00。
>>
>> 代价：追踪线**不再单调**（ATR 上升而极值不变时会后退）。刻意接受。

>> 二稿 L57：**止盈阀门**。已做（`止盈_不得差于入场价`，默认开）。**逐根判不是闩锁**
>> ——线抬上去就能用，掉下来又不能用。`TP > SL` 那一半本来就满足（吊灯有地板），
>> 缺的只有 `TP > 入场价`。吊灯亏损因此从 27 笔降到 2 笔。

>> 二稿 L55（路径只能用 `bar[i-1]`）：**复核通过**，第一稿就已经是对的。
>> 独立重算 292/292 笔与引擎逐笔一致；把本根 high 先折进极值再测试的错排版有 5 笔不一致，
>> **全部提前出场、无一延后**（提前中位 361 分钟）。偏差有方向，不是噪声。

# 六、执行纪律

二稿里没有单独写，但现在这几条都是纪律的一部分。

## 竞价根完全退出成交判定

>> 2026-08-28 新增。原则：**凡是「会导致按这个价成交、或因这个价而改变成交」的地方
>> 一律排除。** 入场、出场、极值折入三处全挡。

判据见 `v3_timeframes._竞价根`。AU 上：

| | 根数 | 时刻 | 零振幅 | 成交中位 |
|---|---|---|---|---|
| 竞价根 | 268 | 全在 21:00 | **100%** | 99 手 |
| 只是段首根 | 274 | 全在 09:01 | 0% | 2266 手 |

>> 原先闸门用错了字段（`is_session_first`），把 274 根**真实可交易**的白盘第一分钟一起
>> 挡了一整年。数据里根本没有标签 `09:00` 的 bar。

**极值那条最容易漏也最要紧**：竞价根是零振幅的单点，折进持仓极值会把吊灯线拉走、进而
改变真实出场。实测 91 个落在持仓区间内的竞价根里有 24 个（26%）真的刷新了极值，最大一次
推了 4.95。

**逐根 mark-to-market 不在此列**——它只记账不产生成交，竞价价是那一刻交易所公布的唯一价格。

## 一根 bar 只做一个动作

`一根bar只做一个动作` 默认开：本根开的仓最早下一根才可能平。同根既开又平要求知道 bar
内部「先到开盘价还是先到止损位」的次序，而这一版的立场恰恰是**不知道**。

副作用：**入场那一根没有止损线**（出场块没跑），但它的 high/low 照样进极值——出场守卫是
`i > e`、极值守卫是 `i ≥ e`，两者不同。引擎与图层两处测试都把这条不对称钉死了。

## 跳空补价

止损触发后按 `min(线, bar的open)`（空头取 max）成交。价格跳过止损位时按线成交是不诚实的。

## 顺序

```
1 冷静期评估   ->  2 大周期方向  ->  3~6 入场  ->  7~10 出场  ->  11 极值折入  ->  12 MTM
```

三条不能动：极值折入在出场测试**之后**；入场在出场**之前**；止损计数在出场块里（本根的
止损不会挡住本根的入场）。

# 八、下一轮的靶子

## 1. 跳空穿过止损位时 TP 仍可能亏

阀门管的是**线**，成交价能跳空穿过它。现存 2 笔就是这样：

```
2026-06-02 22:31 空  入场 968.9805   出场 21:01 @971.8802  线 968.5056（满足阀门）
2026-07-01 01:16 空  入场 868.1391   出场 21:01 @868.8295  线 864.0346（满足阀门）
```

要做到 strictly「TP 绝不亏损」，得改成**跳空时不走 TP，只能等 SL 或后续的 TP**。
那是另一个语义——它会把一笔本该在此了结的交易继续持有下去，风险敞口跟着变。

## 2. CD 的样本量

214 个交易日 10 次。改之前得先想清楚怎么才能证伪：换更长区间、换多品种、还是先降触发
门槛看行为。**在 AU 单品种上调 CD 参数，调出来的一定是噪声。**
