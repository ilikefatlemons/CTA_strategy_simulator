# 一、阶段 0 观测(AU · 214 交易日 · 10 次冻结)

**这些数是本方案的前提,后面每条约束都从它们来。**

## 1. 冻结挡下的入场意图:**10 个**

```
被挡的 1m 根            2,041
合并连续根后的段          17
独立 15m 箱             136
去重到独立武装段          10     ← 「本来会开几单」的真实量级
至少挡下一次的冻结区间     7 / 10
```

前三个数是同一件事的重复计数(同一次武装持续 32 个 15m 箱 ≠ 32 个机会)。
**10 次冻结里有 3 次(#3 #5 #6)一次都没挡到,纯粹白冻。**

## 2. 解除后首次成交间隔:中位 **33** 个 15m 箱

```
0 箱 ×3 (04-03、07-07、07-15)
20, 28, 38, 40, 51, 52, 80
中位 33 箱(≈8h)   p25 5 箱   min 0   max 80   ≤2 箱: 3/10
```

「解除即入场」只坐实 3/10。其余 7 次解冻后要等 20~80 箱才有下一笔。

## 3. 武装段龄(每段首次被挡时):中位 **6** 箱

```
2, 2, 5, 6, 6, 6, 8, 12, 18, 57      ≤8 箱占 7/10,仅 1 段 > 32
```

逐根口径(中位 20、max 87)是重复计数造成的假象,不采用。

## 4. 冻结时长(2h 根数)

```
逐个 3, 3, 4, 4, 5, 5, 7, 13, 15, 18
中位 5.0  均值 7.7  p25 4.0  p75 11.5  合计 77 根 ≈ 15.7 交易日 ≈ 全时段 7.3%
```

## 由此确立的四条硬约束

**A1. AU 上不做性能判断。** 10 个入场意图支撑不了任何参数回测。四格 A/B 在 AU 上**只用于验证开关做了它说的事**,盈亏读数一律视为噪声。性能判断只在 59 品种横截面上做。

**A2. C1 / C2 按语义选,不按 AU 回测选。** 这句必须进最终文档,不能省。

**A3. 原 C2 的理由(闩锁会变成化石)已被数据证伪,收回。**
新理由:缺陷不在「旧」,在**冻结期间信号层还在工作**——3/10 的 0 箱案例正是解冻那刻条件已齐,而那个条件是在本该停摆的期间攒出来的。**不是信号旧,是冷静期没有真的冷静。**

**A4. C2 之后,CD 的价值主要在「重置」,不在「时长」。**
信号层停摆意味着即使冻结只有 1 根 2h,武装与开关2 闩锁也被清空、必须重走完整 setup。**因此缩短解除条件是低成本的**,这是 rev2 采用 R2′ 的依据。

# 二、CD 完整逻辑链(实现按此)

## 全局口径

```
所有判据只读 bar[i-1] 与 bar[i-2],永不读 bar[i] 的任何字段。
现有 大周期 / 开关1 / 开关2 已是此口径;R2′ 天然落在 i-1 / i-2,不引入新惯例。
```

## 状态

```
ACTIVE | FROZEN
```

## 进入 FROZEN

```
触发:  连续三次同方向止损(不变,`冷静期_按方向计数` 默认开)

进入那一根:
    清 回调武装
    清 开关2 闩锁
    不平仓
    止损连亏计数归零              已拍板:冷静期不自我延长
```

## FROZEN 期间

```
仍运行:
    大周期方向(粘性,i-1 / i-2)          R2′ 依赖 2h 序列
    出场块全流程                          存量持仓必须继续管理
    极值折入、MTM、跳空补价、竞价根排除

完全停摆:
    回调武装的观测与累积
    开关2 闩锁的观测与累积
    开关1 求值
    入场判定

不变量:
    FROZEN 期间 回调武装 与 开关2 闩锁 恒为空(每根可断言)

大周期翻转:
    仍是全量重置点,但对信号层是 no-op(已空)
```

## 解除(R2′)

```
state(b) ∈ {多, 空, 非干净}        2h,不带粘性
    多     ⇔ 收盘[b] > MA21[b] > MA55[b]
    空     ⇔ MA55[b] > MA21[b] > 收盘[b]
    非干净 ⇔ 其余(含任意两者相等)

解除 ⇔ state(i-1) ∈ {多, 空}  且  state(i-2) ≠ state(i-1)
```

真值表:

| state(i-2) | state(i-1) | 解除 |
|---|---|---|
| 非干净 | 多 / 空 | ✓ |
| 空 | 多 | ✓ |
| 多 | 空 | ✓ |
| 多 | 多 | ✗ |
| 空 | 空 | ✗ |
| 任意 | 非干净 | ✗ |

**三点必须做对:**

1. **必须用不带粘性的三值态。** 粘性方向会让非干净根继承上一方向,`非干净→干净同向` 比不出「不同」,R2′ 退化。
2. **i-1 / i-2 指 2h 序列上最后两根已收盘 bar**,不是 1m。2h 信号在一个 2h 箱内是常数,解除实际落在新 2h 箱的第一根 1m。与「信号层不跟驱动时钟走」一致。
3. **零长度冻结的封堵(见 §四 K1)**:解除只在冻结起点之后收盘的 2h bar 上评估。最短冻结 = 1 根新 2h。比较用的 `state(i-2)` 允许是冻结前收盘的那根,不构成未来函数。

```
解除那一根:
    状态 → ACTIVE
    大周期方向 = state(i-1)           已确定且干净
    信号层状态仍为空                   FROZEN 期间从未写入
    不平仓
    不入场
```

## 解除之后

```
从下一根起,按 ACTIVE 常规逻辑重新判断:
    ① 15m 三线反向(相对上面那个大周期方向)  → 重新武装
    ② 开关1  价格站回 MA21
    ③ 开关2  MACD 水下金叉
三者齐 → 下一根 1m 的 open 成交
```

## 开关

```
冷静期_解除用状态跨越      默认 True      C1(R2′)
冷静期_信号层停摆          默认 True      C2
```

两者独立,各自关闭即还原现行行为,便于 2×2 拆解归因。

# 五、已拍板

**FROZEN 期间存量持仓止损:不计入连亏,进入 FROZEN 时计数归零。**
理由:冻结期不开新仓,存量单的止损是冻结之前那个决策的后果,拿它延长冻结等于同一批信息罚两次。
