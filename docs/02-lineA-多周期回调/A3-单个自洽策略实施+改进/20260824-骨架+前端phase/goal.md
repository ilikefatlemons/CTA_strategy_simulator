# 当前实现的策略完整链路如下（2026/08/20 Meeting）：

四张图，5m 15m 30m 2h

## Entry:
### 大周期过滤
在2h周期上，用两根均线+现价判断。MA21, MA55。

如果Close>MA21>MA55，判断为多头；反之为空头。没有中间态，所以直到Close和两条MA完全反向排列之前，都不改变大周期上判断出的方向。

### 回调判断
在15m周期上，用两根均线+现价判断。MA21, MA55。
如果Close>MA21>MA55，判断为多头；反之为空头。
需要与大周期的排列完全反向，判定为回调出现
拿2h多头举例，15m上必须MA55>MA21>Close

### 入场
在15m周期上，有两个锁，都解锁直接触发入场。

1. 价格必须重新站回MA21之上 (bar[i-1]_close > bar[i-1]_MA21)

2. 多：MACD水下金叉；空：MACD水上死叉

注意所有判断都在bar[i-1]上完成，防止未来函数。
条件满足，即在bar[i]_open开仓

## TP：
在15m周期上TP，用入场点bar的bar[i-1]; 30m的3*ATR(14)_bar[i-1]吊灯止盈

## SL:
对应在15m周期上SL，30m的ATR指标。选用入场点反向1.5*ATR(14)_bar[i-1]固定止盈

## CD：
连续三次止损，冷静直到2h上出现连续三根同方向的三线排列（止损的当前根不能计入count，一定从止损过的当根2h bar的下一根开始算）
