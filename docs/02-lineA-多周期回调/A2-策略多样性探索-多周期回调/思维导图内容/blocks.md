# 回调策略 · 模块树

## 0. 全局前提

- 1m 右侧时间戳；bar i 只见 ≤ i−1
- HTF 状态只在各自收盘更新
- 1m = 推进时钟 + 执行时钟，非信号时钟
- 高周期由 1m 合成，不满补足
- 多品种统一，不单独调参
- 白名单：MA/EMA · ATR · MACD · RSI · 布林 · Donchian/摆动高低点 · 成交量
- 硬约束一：必须有显式主方向
- 硬约束二：入场必须在逆向回撤之后
- 方向翻转 → 状态机全重置 + CD 清零，不强平
- 反手 = 持仓未平 + 反向全链确认 → 直接翻，不计 CD
- 边界：只做策略层，不做账户层 / 组合层

## 1. 周期分配

### L1 三级分工（方向 / 回调 / 触发 各占一周期）

- M1 4–6 倍步进 {2h · 30m · 5m}
- M2 3 倍步进 {30m · 15m · 5m}
- M3 触发层双周期冗余 {2h · 30m · 15m+5m}
- M4 交易日锚定方向层（日 / 半日）

### L2 两级分工（方向周期 + 执行周期，回调与触发同周期）

- M1 紧凑 {30m · 5m}
- M2 标准 {2h · 15m}
- M3 大跨度 {2h · 5m}

### L3 单周期 + 指标长度分层

- M1 长均线定方向 / 短均线定回调
- M2 布林中轨定方向 / 带宽定回调
- M3 长 Donchian 定方向 / 短 Donchian 定回调

### L4 四级共振

- M1 相邻双高周期同向 + 中周期回调 + 低周期触发
- M2 高周期定向 + 次高周期不反对

### L5 自适应周期 ❌

- 否决：自由度爆炸，不可解释，典型过拟合

## 2. 方向定义

### L1 均线排列

- M1 价格 + 双均线三重排列
- M2 单均线斜率符号
- M3 价格 vs 单均线位置
- M4 布林中轨斜率

### L2 价格结构 HH/HL

- M1 摆动高低点序列
- M2 Donchian 通道创新高 / 新低
- M3 前 N 根区间突破后状态保持

### L3 净位移 / 变化率

- M1 ROC 符号
- M2 RSI 相对 50 中枢
- M3 MACD 快慢线相对零轴

### L4 多周期共振

- M1 两相邻高周期排列同向
- M2 高周期定向 + 次高周期不反对

### L5 三态：多 / 空 / 中性 ⚠ 待 meeting 确认

- M1 均线间距 < k×ATR → 中性
- M2 布林带宽低分位 → 中性
- M3 价格长期停留 Donchian 通道内 → 中性
- M4 ATR 低于自身均值 → 中性
- ⚠ 待定：独立逻辑 vs 叠加层
- ⚠ 待定：中性态下 CD 与反手的语义

## 3. 回调确认

### L1 中周期趋势反向（动量翻转型）

- M1 中周期均线排列反向
- M2 中周期 MACD 死叉
- M3 中周期连续 N 根收在均线下方

### L2 回踩参考锚（位置型）

- M1 回到方向层均线
- M2 回到布林中轨
- M3 回到前期结构位
- M4 回到 Donchian 中轨

### L3 动量回落（不要求价格到位）

- M1 RSI 跌回中枢下方
- M2 MACD 柱转负
- M3 顺势 bar 实体连续缩小

### L4 回撤幅度阈值（纯位移）

- M1 距 swing 极值 ≥ k×ATR
- M2 回撤 ≥ 推动段固定比例
- M3 跌破前 N 根低点

### L5 时间型整理（回调可以是横的）

- M1 N 根不创新高
- M2 N 根区间宽度 < k×ATR
- M3 布林带宽收缩

## 4. 入场触发

### L1 低周期趋势恢复（状态型）

- M1 低周期均线排列恢复顺向
- M2 价格重新站上低周期均线
- M3 双周期确认：低周期排列 + 中低周期位置

### L2 突破回调结构（事件型）

- M1 破回调期间最高点
- M2 破前一根 bar 高点（stop 单）
- M3 破回调期 Donchian 上轨

### L3 动量恢复交叉

- M1 MACD 金叉
- M2 RSI 上穿中枢
- M3 MACD 柱由负转正

### L4 波动率收缩 → 扩张

- M1 带宽收缩后出现 ≥ k×ATR 顺势 bar
- M2 内包 bar 后顺向突破
- M3 放量 + 顺向实体收阳

### L5 位置型左侧触发（到锚位挂限价，不等确认）⚠ 待 meeting 确认

- M1 方向层均线处限价
- M2 布林中轨 / 下轨处限价
- M3 前期结构位处限价
- ⚠ 连带：5-L3 触发信号证伪 对本条失效，SL 必须走结构或波动率

## 5. 止损

### L1 波动率止损

- M1 入场价 ∓ k×ATR
- M2 布林下轨 / 通道下沿

### L2 结构止损

- M1 回调极值之外
- M2 最近 swing low 之外
- M3 Donchian 下轨

### L3 触发信号证伪

- M1 低周期排列重新反向
- M2 收回触发均线之下
- M3 MACD 重新死叉

### L4 前提失效

- M1 回调层重新反向
- M2 方向层翻转即平 ⚠ 与"允许反手"互斥，留第二步

### L5 条件式收紧 / 保本（状态依赖）

- M1 浮盈达 x×ATR 后移至成本
- M2 浮盈达 x×ATR 后收紧为 k′×ATR
- M3 每创新高一档抬高一档

## 6. 止盈

### L1 带锁追踪（达门槛才开 trailing）

- M1 门槛与追踪均用 ATR（吊灯）
- M2 门槛用 ATR，追踪用均线
- M3 门槛用 R 倍数，追踪用 Donchian 下轨

### L2 固定倍数

- M1 x × R
- M2 x × ATR

### L3 结构目标

- M1 前高 / 前低
- M2 通道上轨
- M3 推动段等长投影

### L4 反向信号平仓

- M1 触发层反向
- M2 回调层反向
- M3 动量衰竭

### L5 波动率高潮

- M1 出现 ≥ k×ATR 顺势超大 bar 后平
- M2 触及布林上轨外后回落

### L6 不设 TP

- 只靠 SL / 时间出场，自由度最低

## 7. 仓位与加减仓

### L1 单笔定量、一次进出

- 基准 null 逻辑

### L2 风险等额

- M1 SL = k×ATR → 手数 ∝ 1/ATR
- M2 SL = 结构距离 → 手数 ∝ 1/结构距离

### L3 金字塔加仓

- M1 每前进 x×ATR 加一档
- M2 每出现一次新"回调→触发"加一档
- M3 仅浮盈 > 1R 后加

### L4 试探仓 + 确认仓

- M1 回调确认开小仓，触发确认补足
- M2 单周期触发开小仓，双周期共振补足

### L5 分批止盈 ❌

- 否决：固定仓位下损益 = 两条 TP 规则的算术平均，线性组合，属拼接

## 8. 时间管理

### L1 硬性最大持仓

- M1 按方向层周期计数
- M2 按触发层周期计数
- M3 按自然时间

### L2 无进展止损

- M1 N 根内浮盈未达 x×ATR
- M2 N 根未创新高
- M3 MAE 持续未改善

### L3 setup 时效

- M1 固定 M 根后作废
- M2 回调层状态失效即作废
- M3 价格离开锚位 k×ATR 即作废

### L4 无时间限制

- null 逻辑

## 9. 时段与隔夜

### L1 全时段 + 允许隔夜

- 与长持仓、高周期方向层匹配
- 风险：ATR 止损对跳空无效

### L2 禁止隔夜

- M1 日盘收盘前平
- M2 夜盘收盘前平
- M3 仅跨夜盘不跨日

### L3 尾盘禁开新仓

- M1 收盘前 N 分钟停开
- M2 剩余时间 < 预期持仓时长则不开

### L4 时段过滤

- M1 开盘 N 分钟内不开
- M2 不做夜盘
- M3 只做高流动性时段

### L5 合约层过滤

- M1 临近交割停开新仓
- M2 成交量 / 持仓量门槛
- M3 主力换月规则

## 10. 冷却与重置

### L1 连续止损计数

- M1 按品种独立计
- M2 按方向状态段计（翻转清零）
- M3 多 / 空分别计

### L2 方向翻转即全重置 + 计数清零

- 全局规则，列出以便互斥判定

### L3 出场后固定冷却 N 根

- M1 按方向层周期计
- M2 按触发层周期计
- M3 仅止损后冷却

### L4 单 setup 单次

- M1 严格一次
- M2 同一回调内允许重试 k 次

## 11. 反手

### L1 允许

- M1 反向全链确认即翻
- M2 反向全链确认 + 非亏损状态才翻

### L2 禁止

- M1 平仓后立即可再开
- M2 平仓后进入冷却

### L3 有条件反手

- M1 仅当浮亏未达 1R
- M2 仅当方向层刚翻转
- M3 仅当反向信号为双周期共振
