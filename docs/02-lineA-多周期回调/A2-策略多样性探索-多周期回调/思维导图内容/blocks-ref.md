# blocks-ref · 逐条措施说明

给自己看的参考册。`blocks.md` 是骨架，本文件是骨架上每根枝的注解。不进 XMind。

**读法**：`2-L5M2` = 第 2 板块 · 第 5 条逻辑 · 第 2 个措施。
每条逻辑先给一句**赌注**（它到底在赌什么），再逐条列措施：`措施名 — 怎么判 / 它相对同组其他措施的位置`。

---

## 0. 全局前提（汇报时先讲这段）

- **1m 右侧时间戳** — 09:00 是集合竞价 bar，09:01 是连续交易第一根。时间戳标的是 bar 的结束时刻。
- **bar i 只见 ≤ i−1** — 在第 i 根 bar 上做决策时，只能用第 i−1 根及之前的数据。防未来函数的硬约束。
- **HTF 只在收盘更新** — 2h/30m/15m/5m 的状态只在各自 bar 收盘那一刻改变，中间不动。1m 只负责推进时钟和执行（挂单、监控止损），不产生信号。
- **不满补足** — 高周期 K 由 1m 合成，跨休息时段的 bar 天然更短（10:15–10:30 休息，那根 30m bar 实际只有 15m 数据），照常使用不做填充。
- **多品种统一** — 同一套逻辑跑所有品种，不为单品种调参。这是防过拟合的第一道闸。
- **方向翻转 → 状态机全重置 + CD 计数清零，但不强平**。
- **反手** = 持仓未平 + 反向全链确认 → 直接翻，不计入 CD 计数。
- **只做策略层**，账户层 / 组合层规则（资金曲线、总仓位、相关性）本阶段一律不管。

## 1. 周期分配

### L1 三级分工
> 赌注：方向、回调、触发是三个性质不同的判断，各自需要专属尺度；分工越清晰，信号越不互相污染。

- **M1 4–6 倍步进 {2h·30m·5m}** — 相邻周期倍率 4–6 倍。经典间距，保证低周期噪声不污染高周期判断。
- **M2 3 倍步进 {30m·15m·5m}** — 倍率压到 3，整体尺度下移。交易更频繁，回调更浅，持仓更短。
- **M3 触发层双周期冗余 {2h·30m·15m+5m}** — 触发用两个周期互相背书。假信号最少，代价是入场最晚、错过最快的那波。
- **M4 交易日锚定方向层** — 方向层改用日 / 半日，而非固定小时数。规避夜盘日盘拼接导致的 2h bar 不等长问题。

### L2 两级分工
> 赌注：回调和"回调结束"本来是同一件事的两面，硬拆到两个周期反而制造尺度错配。

- **M1 紧凑 {30m·5m}** — 全链条最短，日内属性最强。
- **M2 标准 {2h·15m}** — 方向慢、执行中速，最常见的折中。
- **M3 大跨度 {2h·5m}** — 方向极慢、执行极快。信号最少、持仓预期最长，但轴 1（尺度自洽）风险最高，需重点验。

### L3 单周期 + 指标长度分层
> 赌注：多周期本质上只是"不同长度的平滑"，那就直接用长短参数代替，省掉重采样与不满补足的全部麻烦。

- **M1 长均线定方向 / 短均线定回调**
- **M2 布林中轨定方向 / 带宽定回调**
- **M3 长 Donchian 定方向 / 短 Donchian 定回调**

优点：数据链最短，无跨周期对齐问题，最好实现。缺点：失去"高周期收盘确认"这一天然滤波，信号会更抖。

### L4 四级共振
> 赌注：方向判断错的代价最大，值得用一个额外周期做冗余。

- **M1 相邻双高周期同向** — 强确认，信号最少。
- **M2 高周期定向 + 次高周期不反对** — 弱确认：次高周期只需"不反向"而非"同向"。信号量明显多于 M1。

### L5 自适应周期 ❌
按波动率动态切换周期。否决：自由度爆炸、不可解释、典型过拟合。

## 2. 方向定义

### L1 均线排列
> 赌注：方向 = 价格相对自身平滑值的位置。最主流、最易解释、最好汇报。

- **M1 价格 + 双均线三重排列** — `P>MA_快>MA_慢` 为多，反向为空，纠缠期不切换。要求最严，状态切换最少，方向最干净。
- **M2 单均线斜率符号** — 只看均线在涨还是在跌。对价格穿越不敏感，比 M1 更平滑更迟钝。
- **M3 价格 vs 单均线位置** — 一个条件，最简。切换最频繁，横盘会反复翻。
- **M4 布林中轨斜率** — ⚠ 与 M2 数学同构（中轨即 MA）。只有在同时要用带宽做中性态时才值得单列，否则按"同质取一"应删。

### L2 价格结构 HH/HL
> 赌注：方向是市场自己写出来的（高低点序列），不需要任何平滑或指标。

- **M1 摆动高低点序列** — 连续 HH+HL 为多，LL+LH 为空。需定义 swing（左右各 N 根确认）。最贴近人工看图。
- **M2 Donchian 通道创新高 / 新低** — 突破前 N 根最高价即转多。机械，无参数歧义，最好实现。
- **M3 前 N 根区间突破后状态保持** — 与 M2 近似，区别在突破后状态"锁死"，直到反向突破才切换。切换更少。

### L3 净位移 / 变化率
> 赌注：方向不在价格的绝对位置，而在变化率的符号。对品种价格量级天然免疫，跨品种可比性最好。

- **M1 ROC 符号** — 最纯粹的位移方向。
- **M2 RSI 相对 50 中枢** — RSI>50 视为多。有界，跨品种直接可比。
- **M3 MACD 快慢线相对零轴** — ⚠ 零轴之上 = 快 EMA > 慢 EMA，与 L1 数学高度重叠。严格执行"同质取一"的话，L3 应只留 M1/M2。

### L4 多周期共振
> 赌注：单周期方向会骗人，两个周期同时骗人的概率低得多。

- **M1 两相邻高周期排列同向** — 强确认。
- **M2 高周期定向 + 次高周期不反对** — 弱确认，信号量更大。

### L5 三态：多 / 空 / 中性 ⚠
> 赌注：横盘期的方向判断没有信息量，与其猜不如不做。

- **M1 均线间距 < k×ATR → 中性** — 均线纠缠的直接量化，与 L1 天然配套。
- **M2 布林带宽低分位 → 中性** — 用波动率压缩定义横盘。带宽必须与自身历史比（分位数），不能用绝对值。
- **M3 价格长期停留 Donchian 通道内 → 中性** — 结构语言的横盘定义：既不创新高也不创新低。
- **M4 ATR 低于自身均值 → 中性** — 最粗最稳。**已知弱点**：它量的是波动率不是趋势，低波动的慢牛会被误判为中性。

## 3. 回调确认

### L1 中周期趋势反向（动量翻转型）
> 赌注：回调 = 中周期尺度上方向真正翻转，而不只是价格回落一点。

- **M1 中周期均线排列反向** — 范例用法。要求最严，回调最深，信号最少，但也最容易错过浅回调。
- **M2 中周期 MACD 死叉** — 比 M1 早，MACD 对拐点更敏感。回调更浅，信号更多。
- **M3 中周期连续 N 根收在均线下方** — 加时间确认，过滤单根插针造成的假回调。

### L2 回踩参考锚（位置型）
> 赌注：回调的意义在于"回到一个有参考价值的位置"，而不是跌了多少。

- **M1 回到方向层均线** — 最主流。均线同时是方向依据和回踩锚，自洽度最高。
- **M2 回到布林中轨** — 与 M1 同构，附带拿到带宽信息。
- **M3 回到前期结构位** — 前高转支撑 / 前低。无参数，但需明确定义"取哪个结构位"。
- **M4 回到 Donchian 中轨** — 机械化的结构位，无歧义，好实现。

### L3 动量回落
> 赌注：回调的本质是动能衰竭，价格到不到位不重要 —— 强趋势里价格根本不回来。

- **M1 RSI 跌回中枢下方** — 有界，跨品种统一。
- **M2 MACD 柱转负** — 量的是加速度，最早的信号，回调最浅。
- **M3 顺势 bar 实体连续缩小** — 不用指标，直接读推动力衰减。最原始也最直观。

### L4 回撤幅度阈值（纯位移）
> 赌注：只承认位移，不承认任何指标。自由度最低，最难过拟合。

- **M1 距 swing 极值 ≥ k×ATR** — 用波动率标准化，跨品种可比。首选。
- **M2 回撤 ≥ 推动段固定比例** — 相对推动段幅度，自动适配行情大小。
- **M3 跌破前 N 根低点** — 最简，纯事件，无需维护 swing。

### L5 时间型整理
> 赌注：回调不一定是跌，也可以是横着磨。忽略横盘型回调会漏掉强趋势里最好的入场。

- **M1 N 根不创新高** — 只约束时间。
- **M2 N 根区间宽度 < k×ATR** — 同时约束时间和空间，更严。
- **M3 布林带宽收缩** — 标准的"挤压"定义，与 4-L4 天然配套。

## 4. 入场触发

### L1 低周期趋势恢复（状态型）
> 赌注：低周期先于高周期反应，低周期恢复顺向即回调结束的最早可靠证据。

- **M1 低周期均线排列恢复顺向** — 标准做法。
- **M2 价格重新站上低周期均线** — 比 M1 早，条件更松，假信号更多。
- **M3 双周期确认** — 范例：5m 排列 + 15m 位置。最晚最稳，入场价最差。

### L2 突破回调结构（事件型）
> 赌注：只有价格真正越过回调期的阻力，才算回调结束。

- **M1 破回调期间最高点** — 需维护回调期高点。最结构化。
- **M2 破前一根 bar 高点（挂 stop 单）** — Elder 第三屏原版。触发最快，但可能在回调仍在进行时被触发，必须严格依赖回调确认状态才激活。
- **M3 破回调期 Donchian 上轨** — M1 的机械化版本。

**L1 与 L2 的根本区别（汇报重点）**：L1 是"状态达成"，可能在离回调低点很远的地方才确认，延迟大但确定；L2 是"事件发生"，在特定价位触发，及时但吃假突破。这不是参数差异，是两种不同的确认哲学。

### L3 动量恢复交叉
> 赌注：回调结束的信号是动能回来了，不必等价格结构走出来。

- **M1 MACD 金叉** — 水上 / 水下之分属超参，本层不区分。
- **M2 RSI 上穿中枢** — 与 2-L3M2 同源，若方向层也用 RSI 需注意冗余。
- **M3 MACD 柱由负转正** — 比 M1 更早（柱先转正，线后交叉）。

### L4 波动率收缩 → 扩张
> 赌注：回调末端一定伴随波动率压缩，压缩后的第一次顺向扩张就是启动。

- **M1 带宽收缩后出现 ≥ k×ATR 顺势 bar** — 与 3-L5M3 天然配套。
- **M2 内包 bar 后顺向突破** — 无指标的收缩定义，最简洁。
- **M3 放量 + 顺向实体收阳** — 引入成交量作为独立确认维度。

### L5 位置型左侧触发 ⚠
> 赌注：确认是有代价的（滑点 + 更差的入场价）。在有明确锚位时直接挂限价，用更好的价格换更低的胜率。

- **M1 方向层均线处限价**
- **M2 布林中轨 / 下轨处限价**
- **M3 前期结构位处限价**

**连带后果**：限价成交点不存在"信号被证伪"这一事件，所以 5-L3 对本条完全失效，SL 必须走结构（5-L2）或波动率（5-L1）。

## 5. 止损

### L1 波动率止损
> 赌注：止损距离应由市场波动决定，而非主观点数。这是跨品种统一的唯一办法。

- **M1 入场价 ∓ k×ATR** — 最主流。距离先验可知 → 能算 R、能配风险等额仓位。
- **M2 布林下轨 / 通道下沿** — 距离随波动率动态变化，但不从入场价起算，R 不固定。

### L2 结构止损
> 赌注：止损应放在"这笔交易的前提被证伪"的价位，而不是一个统计距离。

- **M1 回调极值之外** — 自洽度最高：入场赌回调结束，跌破回调低点即赌错。轴 2 满分。
- **M2 最近 swing low 之外** — 更宽的结构，容错更大，R 更小。
- **M3 Donchian 下轨** — 机械化，无 swing 定义歧义。

### L3 触发信号证伪
> 赌注：入场靠信号，出场也该靠同一个信号消失，不用价位。

- **M1 低周期排列重新反向**
- **M2 收回触发均线之下**
- **M3 MACD 重新死叉**

**共同特征**：无固定止损距离 → 无法先验算 R → **不能配风险等额仓位（7-L2）**，且轴 4 无法在设计阶段判定。这是链 C 的缺口来源。

### L4 前提失效
> 赌注：上游前提比入场信号更重要，前提没了就不该持仓。

- **M1 回调层重新反向** — 中等激进。
- **M2 方向层翻转即平** — ⚠ 与全局前提"允许反手"直接互斥（翻转即平则无仓可反）。留第二步。

### L5 条件式收紧 / 保本
> 赌注：浮盈本身是信息 —— 赚到一定程度后，这笔交易不该再变回亏损。

- **M1 浮盈达 x×ATR 后移至成本** — 显著提高胜率、压低平均盈利，可能把大趋势提前扫掉。
- **M2 浮盈达 x×ATR 后收紧为更小的 k′×ATR** — M1 的连续版本。
- **M3 每创新高一档抬高一档** — ⚠ 与 6-L1 带锁追踪高度重叠，区别仅在"有无启动门槛"。两者同选会重复，留第二步。

**为什么它在止损板块而不在仓位板块**：它对同一仓位施加**状态依赖**（后段行为取决于前段是否发生），非线性，产生了原规则没有的损益形状 —— 这正是它与"分批止盈"的分界线。

## 6. 止盈

### L1 带锁追踪
> 赌注：趋势尾部的收益值得追，但追早了会被正常波动扫出，所以必须先锁住一个门槛。

- **M1 门槛与追踪均用 ATR** — 即吊灯止损（Chandelier Exit，Chuck LeBeau 提出）：从持仓期最高价回撤 k×ATR 离场。范例用法。
- **M2 门槛用 ATR，追踪用均线** — 追踪线更平滑，容忍更大回撤，持仓更久。
- **M3 门槛用 R 倍数，追踪用 Donchian 下轨** — 结构化追踪，与价格结构派配套。

### L2 固定倍数
> 赌注：不预测行情能走多远，只要求赔率达标就走。最容易统计验证。

- **M1 x × R** — 与止损距离绑定，R 恒定，期望值能直接算。轴 4 最好验。
- **M2 x × ATR** — 不与止损绑定；若止损也用 ATR 则退化为 M1。

### L3 结构目标
> 赌注：市场会在特定结构位遇阻，提前挂单在那里离场。

- **M1 前高 / 前低** — 最直观。
- **M2 通道上轨** — 机械化。
- **M3 推动段等长投影** — 假设回调后第二段与第一段等长。三者中最"预测性"，也最需要警惕过拟合。

### L4 反向信号平仓
> 赌注：不设目标位，只在方向证据消失时走，让盈利自然延伸。

- **M1 触发层反向** — 最快，回撤最小，也最容易被噪声打断。
- **M2 回调层反向** — 慢，容忍大回撤，吃到的趋势段最长。
- **M3 动量衰竭** — 冲高后动量回落，介于两者之间。

### L5 波动率高潮
> 赌注：情绪性的加速冲刺往往是一段行情的末端，在极端 bar 之后离场能吃到最高的位置。

- **M1 出现 ≥ k×ATR 的顺势超大 bar 后平**
- **M2 触及布林上轨外后回落**

### L6 不设 TP
> 赌注：所有主动止盈都在削趋势的右尾。只用止损和时间出场，让收益分布保持长尾。

自由度最低的一条，也是最适合做基准对照的一条。

## 7. 仓位与加减仓

### L1 单笔定量、一次进出
所有比较的原点。汇报时应把它当作 baseline。

### L2 风险等额
> 赌注：每笔交易应承担相同的**风险金额**而非相同手数，否则高波动品种会主导整个损益曲线。

- **M1 SL = k×ATR → 手数 ∝ 1/ATR**
- **M2 SL = 结构距离 → 手数 ∝ 1/结构距离**

**硬前提**：必须有可先验计算的止损距离，因此与 5-L3（信号证伪止损）**不兼容**。

### L3 金字塔加仓
> 赌注：趋势被验证得越多，越值得下重注。它改变的是收益分布的形状，不是平均值。

- **M1 每前进 x×ATR 加一档** — 机械，与波动率派配套。
- **M2 每出现一次新的"回调→触发"加一档** — 复用策略自身的信号，自洽度最高。
- **M3 仅浮盈 > 1R 后加** — 最保守。

**注意**：加仓必须同步定义整体止损（是每档独立止损，还是全仓统一止损），否则风险敞口不可控。

### L4 试探仓 + 确认仓
> 赌注：确认强度与入场时机是矛盾的。用仓位大小把这个矛盾连续化 —— 早信号小仓，晚信号补足。

- **M1 回调确认时开小仓，触发确认时补足**
- **M2 单周期触发开小仓，双周期共振时补足**

这是本板块唯一能改变"右侧确认"这件事本身性质的逻辑。

### L5 分批止盈 ❌
`50% 走 TP-A + 50% 走 TP-B`。否决：固定仓位下其单位损益恰等于两条 TP 规则的算术平均 —— 线性组合，不产生任何原规则没有的行为，属拼接而非新逻辑。

---

## 8. 时间管理

### L1 硬性最大持仓
> 赌注：策略有固有的时间尺度，超出还没走完，说明判断已经失效。

- **M1 按方向层周期计数** — 与方向层同尺度，轴 1 最自洽。
- **M2 按触发层周期计数** — 短得多，更激进。
- **M3 按自然时间（分钟）** — 不受周期定义影响，最易解释和汇报。

### L2 无进展止损
> 赌注：一笔正确的交易应该很快就有浮盈；长时间不动本身就是负面信息。

- **M1 N 根内浮盈未达 x×ATR** — 用波动率标定"进展"。
- **M2 N 根未创新高** — 纯结构，无参数。
- **M3 MAE 持续未改善** — 最细，需记录持仓期最大不利偏移。

### L3 setup 时效
> 赌注：回调确认与入场触发之间隔得越久，两者的关联越弱；过期作废。

- **M1 固定 M 根后作废** — 最简。
- **M2 回调层状态失效即作废** — 用状态代替时间，轴 2 最自洽。
- **M3 价格离开锚位 k×ATR 即作废** — 用空间代替时间。

### L4 无时间限制
null 逻辑。出场完全由价格决定。合法，且是自由度最低的选项。

---

## 9. 时段与隔夜

### L1 全时段 + 允许隔夜
与高周期方向层、长持仓天然匹配。**代价**：跳空风险 —— ATR 止损在跳空下完全失效，实际亏损可远超设计值。

### L2 禁止隔夜
- **M1 日盘收盘前平**
- **M2 夜盘收盘前平**
- **M3 仅跨夜盘不跨日** — 中国期货特有：夜盘与次日日盘基本连续，真正的跳空发生在夜盘开盘那一刻。这条是最精细的折中。

### L3 尾盘禁开新仓
- **M1 收盘前 N 分钟停止开仓**
- **M2 剩余时间 < 预期持仓时长则不开** — 把时段规则与持仓时长绑定，比 M1 自洽。

### L4 时段过滤
- **M1 开盘 N 分钟内不开** — 集合竞价后价格未稳定，且所有指标都被开盘跳空污染。
- **M2 不做夜盘** — 夜盘的流动性与波动结构和日盘不同。
- **M3 只做高流动性时段**

### L5 合约层过滤
- **M1 临近交割停开新仓** — 保证金提高、流动性枯竭。
- **M2 成交量 / 持仓量门槛** — 多品种策略的必需项。
- **M3 主力换月规则** — 换月点的价格跳变会污染所有指标，必须显式处理（复权方式本身是数据端问题，但策略要声明依赖）。

---

## 10. 冷却与重置

### L1 连续止损计数
> 赌注：连续止损是"当前环境不适合本策略"的最直接证据，比任何指标都及时。

- **M1 按品种独立计** — 多品种下最自然。
- **M2 按方向状态段计（翻转清零）** — 与全局前提一致，范例用法。
- **M3 多 / 空分别计** — 允许单边行情中反向的连败不干扰顺向交易。

### L2 方向翻转即全重置 + 计数清零
已定为全局规则。在树中单列，是为了在第二步做互斥 / 冗余判定时有个明确对象。

### L3 出场后固定冷却 N 根
> 赌注：刚出场时的市场状态与出场原因高度相关，立刻再进等于在同一个信息上重复下注。

- **M1 按方向层周期计**
- **M2 按触发层周期计**
- **M3 仅止损后冷却** — 止盈不冷却，因为止盈说明判断是对的。三者中最有道理的一条。

### L4 单 setup 单次
> 赌注：同一个回调只提供一次机会，反复入场是在同一份信息上重复下注。

- **M1 严格一次** — 直到出现新的回调确认才解锁。
- **M2 同一回调内允许重试 k 次** — 折中，但 k 是超参，注意别把它当成新逻辑。

## 11. 反手

### L1 允许
- **M1 反向全链确认即翻** — baseline。
- **M2 反向全链确认 + 非亏损状态才翻** — 避免在亏损中直接放大敞口。

### L2 禁止
- **M1 平仓后立即可再开** — 只是拆成两步，实际行为接近反手。
- **M2 平仓后进入冷却** — 真正的"禁止"，与横盘保护同源。

### L3 有条件反手
- **M1 仅当浮亏未达 1R**
- **M2 仅当方向层刚翻转** — 把反手限定在方向真正改变时，排除横盘噪声。语义最清晰。
- **M3 仅当反向信号为双周期共振** — 提高反手的证据门槛。

**为什么本板块只有 3 条逻辑**：反手的行为空间本身就是"允许 / 禁止 / 有条件"三分，已经穷尽。再拆是把措施伪装成逻辑。
