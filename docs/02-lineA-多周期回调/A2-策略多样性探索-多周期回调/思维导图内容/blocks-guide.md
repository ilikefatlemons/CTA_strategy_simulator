# blocks-guide · 模块树的说明、示例链与自检

配套 `blocks.md`。本文件不进 XMind。

---

## 一、判据回顾

**逻辑 vs 措施**
- 逻辑：同一段行情下产生**结构性不同**的行为
- 措施：换掉它，逻辑不变

**去重两条**
1. **同质取一** —— 设计思想相近的，只留最主流 / 最可解释的
2. **组合 ≠ 新逻辑** —— 若 C 的行为可由已有 A、B 的**线性组合**复现，C 是拼接不是逻辑

**自洽四轴**
1. 时间尺度：出场 / 止损周期 ≤ 定方向周期，且与预期持仓时长同量级
2. 前提证伪：出场条件应是入场前提的否定
3. 状态机：重置 / CD / 反手 不得互相吞并或死锁
4. 统计量级：止损距离 · 止盈距离 · 隐含胜率 能凑出正期望的量级

## 二、❌ 否决项与理由

**1-L5 自适应周期（按波动率动态切换周期）**
自由度爆炸，不可解释，典型过拟合。违反元件准入。

**7-L5 分批止盈（50% 走 TP-A，50% 走 TP-B）**
固定仓位下，其单位损益恰等于两条 TP 规则的算术平均 —— 线性组合，不产生任何原规则没有的行为。属策略拼接，违反去重第 2 条。

> **边界澄清：**`达 1R 后把止损移到成本` **不是**拼接。后段行为**条件依赖于**前段是否发生，非线性，产生了两条原规则都没有的损益形状。因此它作为独立逻辑保留在 **5-L5**（止损板块），而非仓位板块。
>
> 仓位板块剩下的四条（单笔定量 / 风险等额 / 金字塔 / 试探+确认）都通过判据：它们改变的是**手数与市场状态的函数关系**，不是把两条已有出场规则加权平均。

**账户层规则（累计回撤 CD、资金曲线暂停等）**
已从树中移除。本阶段只做策略层，账户层 / 组合层不管。

## 三、⚠ 待 meeting 确认项

**2-L5 三态方向层**
- 争议点：它与 L1–L4 **半正交**。当独立逻辑 → 组合数 +1；当叠加层 → 组合数 ×2
- 倾向：当独立逻辑，保持树的纯粹
- 连带：中性态下 CD 与反手的语义须重新定义（二象性无中间态，三态有）

**4-L5 位置型左侧触发**
- 范式松绑后，"到锚位挂限价、不等反转确认"在字面上属于回调策略
- 连带：限价成交点不存在"信号被证伪"这一事件 → **5-L3 触发信号证伪对它失效**，SL 必须走结构（5-L2）或波动率（5-L1）
- 纳入则本板块从"右侧"扩为"右侧 + 左侧"

**5-L4M2 方向层翻转即平**
- 与全局前提"允许反手"直接互斥（翻转即平则无仓可反）
- 属跨板块问题，留第二步的自洽矩阵处理

## 四、内部自洽完整链（4 条，各走完 11 个板块）

### 链 A · 均线动量派（范例基线）

| 板块 | 选择 |
|---|---|
| 1 周期分配 | L1M3 三级 {2h·30m·15m+5m} |
| 2 方向 | L1M1 价格+双均线三重排列 |
| 3 回调 | L1M1 30m 排列反向 |
| 4 触发 | L1M3 5m 排列 + 15m 位置双确认 |
| 5 止损 | L2M1 回调极值之外 |
| 6 止盈 | L1M1 ATR 带锁追踪 |
| 7 仓位 | L1 单笔定量 |
| 8 时间 | L3M1 setup 时效 |
| 9 时段 | L3M1 尾盘禁开 |
| 10 CD | L1M2 + L2 连续止损 3 次 & 翻转清零 |
| 11 反手 | L1M1 允许 |

**自洽理由**
- 轴 1：SL 与 TP 均落在回调层周期（30m），与"回调结束"这一前提同尺度
- 轴 2：SL 是"回调未真正结束"的直接否定
- 轴 3：CD 计数与方向段绑定 —— 方向翻转前的连续止损正是横盘特征，与反手同源；因允许反手，SL 不得选 L4M2
- 轴 4：止损为回调深度，止盈为趋势延伸，量级不对称但方向正确

### 链 B · 价格结构派

| 板块 | 选择 |
|---|---|
| 1 周期分配 | L2M1 两级 {30m·5m} |
| 2 方向 | L2M1 摆动高低点序列 |
| 3 回调 | L4M1 距 swing 极值 ≥ k×ATR |
| 4 触发 | L2M1 破回调期高点 |
| 5 止损 | L2M2 swing low 之外 |
| 6 止盈 | L3M1 前高目标 |
| 7 仓位 | L2M2 风险等额（按结构距离） |
| 8 时间 | L2M2 N 根未创新高即平 |
| 9 时段 | L2M1 禁止隔夜 |
| 10 CD | L4M1 单 setup 单次 |
| 11 反手 | L2M1 禁止 |

**自洽理由**
- 全链只用价格结构，零指标（ATR 仅作标尺）：入场是结构突破，止损是结构失效，止盈是下一个结构位 —— 三者同语言
- 轴 1：禁隔夜与两级紧凑周期、短持仓时长匹配
- 轴 3：禁反手与"单 setup 单次"同源，都是抑制同一结构上的重复交易
- 轴 4：止损距离由结构给出，仓位按其反推 → 每笔风险恒定，最易验算

### 链 C · 纯动量派

| 板块 | 选择 |
|---|---|
| 1 周期分配 | L1M2 三级 {30m·15m·5m} |
| 2 方向 | L3M3 MACD 相对零轴 |
| 3 回调 | L3M2 MACD 柱转负 |
| 4 触发 | L3M1 MACD 金叉 |
| 5 止损 | L3M3 MACD 重新死叉 |
| 6 止盈 | L4M1 触发层反向平仓 |
| 7 仓位 | L1 单笔定量 |
| 8 时间 | L1M2 硬性最大持仓 |
| 9 时段 | L1 全时段 + 允许隔夜 |
| 10 CD | L3M3 仅止损后固定冷却 |
| 11 反手 | L3M3 仅双周期共振才反手 |

**自洽理由**
- 轴 2 满分：进出场用同一指标族，出场条件严格是入场条件的否定
- 轴 1：三级周期紧凑，出场周期 < 方向周期

**已知缺口（第二步必须复核）**
- **轴 4 无法在本步判定**：本链没有固定止损距离，风险敞口不可先验估计。用"硬性最大持仓"兜底，但这不是止损，只是时间边界
- 允许隔夜 + 无价位止损 = 跳空风险敞口无上界。若轴 4 复核不过，第一优先是把 9-L1 换成 9-L2，其次是给 5 加一条并联的 L1M1

### 链 D · 波动率派

| 板块 | 选择 |
|---|---|
| 1 周期分配 | L2M2 两级 {2h·15m} |
| 2 方向 | L5M2 三态（带宽低分位 = 中性不开仓）⚠ |
| 3 回调 | L5M3 带宽收缩视为回调完成 |
| 4 触发 | L4M1 收缩后 ≥ k×ATR 顺势 bar |
| 5 止损 | L1M1 入场价 ∓ k×ATR |
| 6 止盈 | L5M1 超大顺势 bar 后离场 |
| 7 仓位 | L2M1 风险等额（手数 ∝ 1/ATR） |
| 8 时间 | L3M1 setup 时效 M 根 |
| 9 时段 | L3M2 剩余时间不足则不开 |
| 10 CD | L2 仅方向翻转重置 |
| 11 反手 | L2M2 禁止，平仓后冷却 |

**自洽理由**
- 计量单位全链统一为波动率：中性态 · 回调 · 触发 · 止损 · 止盈 · 仓位六处都用 ATR / 带宽表达，尺度天然一致（轴 1 最强）
- 轴 3：三态方向层已过滤横盘，故不需要连续止损计数型 CD，也不需要反手 —— 反手正是横盘的产物
- 依赖 2-L5 的确认结果；若三态被否，本链的 CD 与反手选择要重做
