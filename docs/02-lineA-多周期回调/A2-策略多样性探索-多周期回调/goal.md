# GOAL — 回调再入场策略：模块化穷举与自洽组合

## 0. 一句话

在中国期货 1m 多品种数据上，把「回调再入场」这一类范式，拆成 `板块 → 逻辑 → 设计措施` 的三层树，穷举出可互换的元件库；再以**自洽性**为唯一筛选器，装配出若干套内部自洽、彼此独立的完整策略。

---

## 1. 范式边界（本阶段**不**收窄）

**硬约束只有两条：**
1. 必须存在一个被显式定义的**主方向**（没有主方向就没有"回调"，只有均值回归）。
2. 入场必须发生在**相对主方向的逆向回撤之后**，而不是在推动段中直接追。

**明确排除：** 无主方向的均值回归、无回撤的突破追单、网格、套利、事件驱动、日内高频。

**不在本阶段钉死的：** 用几级周期、右侧确认还是左侧挂单、确认强度多高 —— 这些都是板块内的**逻辑选项**，进入收窄阶段时再选。

> 范例基线（`高周期定方向 → 中周期确认逆向回调 → 低周期确认回调结束并重回原方向 → 右侧入场`）= Elder 三重滤网的期货 1m 状态机版，是**候选之一**，不是约束。
> Alexander Elder, *Trading for a Living: Psychology, Trading Tactics, Money Management*, Wiley, 1993（Triple Screen Trading System）。ISBN 0-471-59224-2

## 2. 三层结构

| 层 | 定义 | 判据 |
|---|---|---|
| **板块** Block | 策略的功能位 | 去掉它，策略跑不起来 |
| **逻辑** Logic | 同板块下**设计思想本质不同**的解法 | 同一段行情下产生**结构性不同**的行为，而非仅数值差异 |
| **设计措施** Measure | 同逻辑下的平行实现（RSI / MACD 都是动量） | 换掉它，逻辑不变 |
| ~~超参~~ | 本阶段**不讨论** | — |

**去重规则（两条，缺一不可）：**
- **同质取一** — 设计思想相近的逻辑，只留最主流 / 最可解释的那一个。
- **组合 ≠ 新逻辑** — 若某逻辑 C 的行为可由已有逻辑 A、B 的**线性组合**复现，C 不是新逻辑，是拼接。
  典型：`50% 仓位走 TP-A + 50% 仓位走 TP-B`，其单位损益恰等于两者的算术平均，不产生任何新行为 → 否决。
  反例（合法）：`达 1R 后把止损移到成本` —— 后段行为**条件依赖于**前段是否发生，非线性，算新逻辑。

## 3. 元件准入

- 指标白名单：MA/EMA、ATR、MACD、RSI、布林带、Donchian / 摆动高低点、成交量。
- 复杂指标 = 隐性过拟合 → 直接否。
- 每个逻辑必须能**一句话说清它在赌什么**。说不清 → 删。
- 多品种共用同一套逻辑，不为单品种定制。

## 5. 自洽性 —— 唯一的筛选器

四条轴，任一条不过即判不自洽，且**必须写明理由，不能只写结论**：

1. **时间尺度自洽** — 出场 / 止损所用周期 ≤ 定方向周期，且与预期持仓时长同量级。
2. **前提证伪自洽** — 出场条件应是入场前提的**否定**。
3. **状态机自洽** — 重置 / CD / 反手的优先级与触发面，不得互相吞并或死锁。
4. **统计自洽** — 止损距离、止盈距离、隐含胜率的**量级**能凑出正期望（不精算，只排除明显不可能）。

---

## 6. 扩张原则（要球，不要刺）

- 目标密度：每板块 **3–5 个逻辑**，每逻辑 **2–4 个措施**。
- **先横向铺满所有板块，再回头加深**。出现「A 板块 8 种逻辑、B 板块 1 种」= 违规。
- 够了就停。不追求穷尽，追求**覆盖不同的设计维度**。

---

## 7. 全局前提（数据假设已正确）

- 1m 右侧时间戳：09:00 = 集合竞价 bar，09:01 = 连续交易第一根。
- **bar i 只能看到 ≤ i−1 的信息**；信号在 bar i 判定，最早于 bar i 成交。
- 高周期 K 由 1m 合成，**不满补足**（跨休息时段的 bar 天然更短）。
- **高周期状态只在各自 bar 收盘时更新**；1m 是推进时钟 + 执行时钟，不是信号时钟。
- 方向层翻转 → 状态机全重置 + CD 计数清零；但**不强平**现有仓位。
- 反手 = 持仓未平 且 反向信号全链确认 → 直接翻；不计入 CD 计数。

## 10. 已知风险（自检时盯住）

- **多样性假象** — 换指标 ≠ 换逻辑。RSI 版与 MACD 版是同一策略的两次抽样，不能当两套独立策略做统计。

- **有效样本数远小于 bar 数** — 高周期方向状态的切换，单品种一年只有十几到二十几次。「方向」这一层的独立观测数 = 品种数 × 年切换次数，不是 1m bar 数。

- **组合爆炸 + 多重检验** — 11 板块 × 4 逻辑 × 3 措施的原始组合是天文数字；自洽性筛选是唯一不带数据窥探的降维手段，后续回测必须**限制被测组合总数**。核心结论：*被试过的变体数量本身就会制造假阳性，变体越多，样本内最优者的样本外衰减越确定。*

  > *Pseudo-Mathematics and Financial Charlatanism: The Effects of Backtest Overfitting on Out-of-Sample Performance*,
  > Notices of the American Mathematical Society, 61(5), 2014, pp. 458–471.
