# v4.0 策略逻辑

## 〇、总览

### 三个策略共用一个终端

- 入口 `python -m src.run_v3_rbreaker_chart`
- 右上角三向互斥切换：Archive-Pullback / Breakout / Reversal
- 数据层：59 个中国商品期货品种，1 分钟 K 线，复权后按品种存 parquet
- 三者共用同一套时段划分与「时段锁死」纪律，因此结果可横向对比

### 三个策略的一句话定位

- **R-Breaker 突破**：顺势。价格站上 Bbreak 做多 / 跌破 Sbreak 做空
- **R-Breaker 反转**：逆势。冲到 Ssetup 武装后回落跌破 Senter 做空，反之做多
- **Archive-Pullback**：顺势回调。日线定方向，小周期等回调再顺势入场

### 最关键的三处差异（先看这个）

- **止损性质**
    - R-Breaker 两个策略：**追踪止损**，逐根随行情收紧，入场时只有一条起始线
    - Archive-Pullback：**入场时定死**一条固定止损，止盈后才换成追踪的吊灯线
- **止盈**
    - R-Breaker 两个策略：**没有止盈**。只有追踪止损和时段末强平
    - Archive-Pullback：2R 处平掉一半，剩下一半交给吊灯线
- **一个时段几笔**
    - R-Breaker 两个策略：**每时段最多一笔**（`one_trade_per_session=True`）
    - Archive-Pullback：不限笔数，平掉就能再找下一次回调

## 一、公共底座

### 1.1 时段划分（五种模式）

- 两层模型
    - **原子段 segment**：由「trading_date 变化 或 时钟间隔 > 3 小时」切出，就是夜盘段和日盘段。不随模式变化
    - **时段 session**：由原子段按模式分组而成。「时段末强平」和「每时段一笔」两条纪律都作用在它上面
- 五种模式
    - `split` 日夜分开（默认）：夜、日各算一个时段
    - `night` 夜盘：只有夜盘段可交易
    - `day` 日盘：只有日盘段可交易
    - `night_day` 交易日 夜→日：一个 trading_date 的夜+日合成一个时段
    - `day_night` 自然日 日→夜：日盘段 + 紧随其后的夜盘段合成一个时段
- 只有 `night` / `day` 会把 `tradable` 置 False；另外三种全是 True，区别只在**分组**
- 中国期货的 trading_date 口径：夜盘 bar 已经带着**下一个**交易日的日期（21:00 开的夜盘属于次日，周五夜盘属于下周一）

### 1.2 时段锁死（本阶段新增，三个策略共享）

- 见下面第五节，单独展开

### 1.3 成本口径

- `cost_bps` 单次往返成本（基点），默认 0
- **成本绝不进入任何决策**，只在记账层叠加。调费率不允许改变成交序列
- Archive-Pullback 一批两条腿时，成本按整批收一次：`Σ 腿(size_fraction × pnl_net)` 里的成本项恰好是 `1.0 × cost_bps/1e4`

### 1.4 跳空补价

- 止损/追踪止损：按「止损线」与「本根 open」里**更差**的那个成交
- 理由：10:15→10:31、11:30→13:31 以及每个时段边界都是零根 bar，那里的跳空是真实的
- **止盈不补价**（挂在触发价的限价单）；**时段末强平不补价**（按 close）
- 口诀：止损吃亏，止盈不占便宜

## 二、R-Breaker 突破（Breakout）

### 2.1 六条线（自上而下）

- 由**前一交易日**的 H / L / C 投射，当日固定不动，次日整套重算
- `Ssetup = H + f1×(C − L)`
- `Bsetup = L − f1×(H − C)`
- `Senter = ((1+f2)/2)×(H + C) − f2×L`
- `Benter = ((1+f2)/2)×(L + C) − f2×H`
- `Bbreak = Ssetup + f3×(Ssetup − Bsetup)`
- `Sbreak = Bsetup − f3×(Ssetup − Bsetup)`
- 严格顺序：`Bbreak > Ssetup > Senter > Benter > Bsetup > Sbreak`
- 系数：`f1=0.35`、`f2=0.07`、`f3=0.25`
- 恒等式：`Ssetup − Bsetup = (1+f1)×(H−L)`，因此 `Bbreak − Ssetup = 0.3375×(H−L)`
- **出处提醒**：R-Breaker 没有作者本人发表的规范文档，网上流传的公式版本彼此有出入。引用任何回测结果都必须带上这组系数

### 2.2 入场

- **只读两条线**：Bbreak / Sbreak
- 触发条件（默认 `entry_trigger_on_range=True`）
    - 多：bar i−1 的 **high > Bbreak**
    - 空：bar i−1 的 **low < Sbreak**
    - 关掉则改为要求 bar i−1 的 **收盘**站上/跌破
- 成交价：**bar i 的 open**（决策只用到 i−1 的信息，开盘那一刻已知）
- 多空互斥是构造性的：`Bbreak − Sbreak = (1+2f3)×(Ssetup−Bsetup) > 0`
- 闸门（全部要满足）
    - 当前空仓
    - 本根没有发生过出场动作（一根 bar 只做一件事）
    - 当日有合法的前日参照 `valid[D]`
    - `tradable[i]`：时段模式允许
    - **每时段最多一笔**（`one_trade_per_session`）
    - **不是时段末根**：否则这根既入场又被强平
    - **不是时段首根**：bar i−1 属于上一个时段，可能隔 6~58 小时，而且可能是另一个 trading_date 的另一套线

### 2.3 止损：追踪止损（价格随行情走，不是入场时定死）

- **性质：入场时只给出一条起始线，之后每根 bar 重算，单调收紧、永不放松**
- 闭式解
    - 多：`stop = Senter + (peak − Ssetup) / d`
    - 空：`stop = Benter − (Bsetup − trough) / d`
- `peak` / `trough` = 入场以来 high / low 的运行极值，**种子是理论线**（多头种在 Bbreak，空头种在 Sbreak），不是实际成交价
    - 推论：实际成交价 `open[i]` 与理论线之间的差额**全额计入盈亏、零传导到止损位**
- `d = 3.0`，来自 giveback 原式
    - `giveback = (Bbreak − Senter) − (Bbreak − Ssetup)/d + MFE_geo×(1 − 1/d)`
    - 语义：极限情况下锁定 MFE 的 `1/d`，即最多回吐峰值浮盈的三分之二
    - `d` 越大止损越**松**：d=3 时初始止损在入场价下方约 0.6 倍前日振幅，要到 MFE ≈ 1.79 倍前日振幅才回到保本
- **没有保本地板**（刻意的，与 Archive-Pullback 的吊灯线不同）
- 触发与成交
    - 判定：本根 low ≤ stop（多）/ high ≥ stop（空）
    - 成交价：`min(stop, open[i])`（多）/ `max(stop, open[i])`（空）—— 跳空补价
    - `gapped=True` 表示按 open 成交而不是按止损线

### 2.4 止盈

- **没有止盈。** 只有追踪止损和时段末强平两个出口
- 出场原因只有两种：`TRAIL` / `SESSION_END`

### 2.5 顺序纪律（无未来函数的关键）

- 出场块排在入场块**之前**，且出场那一根不再入场
- `entry_i < i`：成交那一根不测试止损 —— 保证每笔 `exit_bar_idx > entry_bar_idx`
- **本根极值在止损测试之后才折入** `peak`，所以拿去和本根比较的那条线永远只依赖到 i−1
- 同一根既触止损又是时段末根 → 走止损（更早发生，价格通常也更差）

### 2.6 冷静期

- **没有冷静期。** 这是 Archive-Pullback 独有的机制

## 三、R-Breaker 反转（Reversal）

### 3.1 与突破的关系

- **基线执行纪律逐行同构**：跳空补价、一根一动作、时段强平、极值折入的位置完全一致
- 追踪止损用**同一个 giveback 表达式、同一组常数**，只换入场线
- 因此两个策略的**初始止损距离逐字节相同**，风险天然可比
    - 实测（RB，参照日 H/L/C = 3085/3053/3061）
        - 突破多：入场 3098.60，止损 3078.00，风险 20.60
        - 反转空：入场 3074.40，止损 3095.00，风险 20.60 ← 同距
    - 突破空 与 反转多 共用另一个常数，风险同为 17.64

### 3.2 入场：两段式「武装 → 触发」

- **只读四条线**：Ssetup / Senter / Benter / Bsetup
- 第一步 · 武装（arm）
    - 运行最高价 `run_hi ≥ Ssetup` → 武装**空**方向
    - 运行最低价 `run_lo ≤ Bsetup` → 武装**多**方向
    - `run_hi` 只增、`run_lo` 只减，所以每个阈值每时段至多被越过一次
    - **最近发生的那个极值胜出**：刚冲到 Ssetup 就等回落做空；刚砸到 Bsetup 就等回升做多。两个方向永不同时生效
        - 这一条是**必需**的：空头触发是 `low < Senter`、多头是 `high > Benter`，而 `Senter > Benter` —— 一根**整根落在 [Benter, Senter] 带内**的 bar 同时满足两者。实测 RB 一年有 606 根这样的 bar。不定方向的话那些时段会一笔都不做
    - 单根同时越过 Ssetup 和 Bsetup（跨越 1.35 倍前日振幅）→ 记为 `ambiguous_arm`，本时段不定方向
    - **换时段清空**：武装状态与运行极值全部重置。夜盘碰到的高点不能武装日盘
- 第二步 · 触发
    - 已武装空 且 bar i−1 的 **low < Senter** → 做空
    - 已武装多 且 bar i−1 的 **high > Benter** → 做多
    - 成交价：**bar i 的 open**
- `arm_must_precede_trigger`（默认 False）
    - False：运行极值取到 i−1 为止（含），所以一根 `high ≥ Ssetup` 且 `low < Senter` 的 bar 会当场武装并触发
    - True：要求武装严格发生在触发**之前**的某一根（运行极值退到 i−2）
- 闸门与突破完全一致（空仓 / 未动作 / valid / tradable / 每时段一笔 / 非时段末根 / 非时段首根）

### 3.3 止损：追踪止损（同样随行情走）

- 闭式解
    - 反转空：`stop = Bbreak − [(Bbreak − Ssetup) + MFE_geo] / d`
    - 反转多：`stop = Sbreak + [(Bsetup − Sbreak) + MFE_geo] / d`
- `MFE_geo` 从**理论线**量起，入场时为 0，单调不减 ⇒ 止损单调收紧
    - 空：`MFE_geo = Senter − trough`
    - 多：`MFE_geo = peak − Benter`
- 语义自洽：反转空的止损落在 Bbreak 正下方 `(Bbreak−Ssetup)/d` 处 —— 逆势空单错在哪里？错在市场真的向上突破了
- **同样不设保本地板**
- 入场那一根的 low/high 立刻折进 MFE，所以 bar i+1 的止损位已经含它

### 3.4 止盈

- **没有止盈。** 出场原因只有 `TRAIL` / `SESSION_END`

### 3.5 冷静期

- **没有冷静期。**

## 四、Archive-Pullback（回调入场）

### 4.1 来历与周期映射

- 移植自 v2.1 phaseF 美股 5 分钟策略，**逻辑一个字没改**，只换数据源和前端
- 周期角色一一对应
    - 5m → **1m**：执行/成交粒度；回调与触发的快腿
    - 15m → **5m**：回调与触发的另一条快腿
    - 30m → **30m**：回调的硬性条件；止损平台位；风险 ATR
    - 2h → **1d**：趋势方向 bias；冷静期
- **重要警告**：这个重映射把策略的时间常数拉长了约 12 倍（趋势方向从一天变 3 次变成一天变 1 次）。结果**不能**和 docs/v2.1 的账本比
- 暖机段：需要 60 个交易日（日线 MA50），不显示也不交易；凑不满时面板副标题标「暖机不足」

### 4.2 入场：四周期 MA 级联

- 第一步 · 方向 bias（日线）
    - 日线 MA5 / MA20 / MA50 **严格排列**
        - `MA5 > MA20 > MA50` → 多头方向
        - `MA5 < MA20 < MA50` → 空头方向
        - 否则 neutral，不做
    - 方向变了（含变成 neutral）→ 累积的回调作废
- 第二步 · 回调确认
    - **30m 必须转反向**（硬性条件）
    - **且** 1m / 5m 至少一个也转反向
    - 满足则置 `pullback_seen = True`，并在图上记一个黄色圆点
    - **回调确认的那一根绝不同时入场** —— 触发必须是更晚的一根
- 第三步 · 触发
    - 1m **和** 5m **都**转回与日线同向
    - 成交价：**bar i 的 open**（默认完成根口径，1m 只读到 i−1）
- 闸门
    - 冷静期未激活（排在最前面，激活时**连方向都不更新**）
    - 三个高周期都已有收盘 K 线
    - `tradable[i] & in_window[i]`
    - **成交那一根不是时段末根**
    - 被闸门挡住时**不消耗** `pullback_seen` —— 级联好不容易凑齐的一次回调不该被一根不可交易的 bar 白白吃掉
- 触发后 `pullback_seen` 清零，下次入场要重等一轮回调
- **不限每时段笔数**

### 4.3 止损：入场时定死（与 R-Breaker 的根本区别）

- **性质：成交那一刻算出一个固定价格，整批持有期间不变**
- 两个候选取**离入场价更近**的那个（亏得更少的那个）
    - **ATR 止损**：`入场价 ∓ 1.5 × ATR30`
    - **平台止损**：30m 上离入场价最近的摆动点
        - 多头取**低于入场价的最高低点**；空头取**高于入场价的最低高点**
        - 摆动点定义：左右各 `k=2` 根都不超过它
    - 平局时 ATR 止损胜出
- 再向不利方向偏移 `sl_offset_pct = 0.003`（0.3%），防止被程序化扫损
- **ATR 用哪根**：读**最后一根已收盘的 30m** 的 ATR(14)，绝不用本根
- 触发与成交
    - 判定：本根 low ≤ stop（多）/ high ≥ stop（空）
    - 成交：跳空补价
    - 整批一次性平掉，`size_fraction = 1.0`，出场原因 `SL`

### 4.4 止盈：2R 部分止盈（价格入场时定死）

- **触发价 = 入场价 ± 2.0 × R**，其中 `R = |入场价 − 止损价|`
- **这个价格在入场那一刻就算好了，不随行情移动**
- 触发后
    - 平掉 `partial_ratio = 0.5`（一半仓位）
    - 成交价**恰好等于触发价** —— 挂在触发价的限价单，**不做跳空补价**
    - `gapped` 恒为 False
    - 出场原因 `TP`
- 同一根里止损与止盈都触及 → **悲观地先走止损**（`pessimistic_both_hit`）

### 4.5 剩余仓位：吊灯止损（价格随行情走）

- 止盈触发那一刻，`trailing_stop` 先置回**原始止损位**
- 之后每根重算：`吊灯 = 入场以来极值 ∓ 3.0 × ATR30`
- **有保本地板**：`max(raw, 原始止损)`（多）/ `min(raw, 原始止损)`（空）
    - 所以剩余仓位任何时刻的下行风险都不超过原始止损
    - 与 R-Breaker 的追踪止损不同 —— 那两个**刻意不设**地板
- **注意：吊灯线并非单调只上移。** 它每根按 `极值 − 3×ATR` 重算，ATR 变大时会被拉回来（只被原始止损兜住）。v2.1 的文档说「只上移」，实现并非如此，这里保真移植
- 触发后平掉剩余 `1 − partial_ratio = 0.5`，出场原因 `PROTECTIVE_SL`（护盈止损）
- **本根极值在吊灯测试之后才折入**，所以拿去和本根比较的那条线永远不依赖本根
- ATR 同样读最后一根已收盘的 30m，绝不用本根

### 4.6 一批的四种收尾形状

- `[SL]` —— 整批一次止损，100%
- `[TP, PROTECTIVE_SL]` —— 止盈一半 + 吊灯打掉剩下一半，50% + 50%
- `[END_SESSION]` —— 没走到任何出场位，整批被时段末强平，100%
- `[END_SESSION, TP]` —— 止盈那一根**正好**是时段末根，剩下一半被强平，50% + 50%
- **不变量：同一批各腿的 `size_fraction` 恒加到 1.0**（成本口径和统计层都依赖它）
- 没有第五种：SL 和 PROTECTIVE_SL 都会把批次置空，不可能与 END_SESSION 同批

### 4.7 冷静期（Cooldown）— 只有这个策略有

- **作用**：激活期间**完全不开仓**，连方向都不更新。但不影响已持仓位的出场
- **解除条件（两个触发器共用）**：连续 3 根**日线**都是同一个干净排列（不要求方向与触发前一致，允许反转）
    - 不能只判断「当前非 neutral」就解除 —— 入场本来就只在非 neutral 时才产生信号，那等于形同虚设
    - 触发的当根不可能同时满足「连续 3 根」，所以天然不会当场解除
- **日频门控**：引擎每根 1m 都调它，但门控成「每根新日线只评一次」。不门控的话计数按调用次数推进（3 根 1m = 3 分钟，而不是 3 个交易日），冷静期形同虚设

#### 触发器 1 · 同方向连续 3 次纯止损

- 含义：连续判断错了方向
- 计数规则（**本阶段的重点**）
    - **纯止损 SL** → 同方向 +1；不同方向则重置为 1
    - **部分止盈 TP** → **清零**（这一轮方向是对的）
    - **护盈止损 PSL** → **什么也不做**
        - 它其实恒等于空操作：走到 PSL 必然已经 TP 过，而 TP 刚清过零，两条腿之间同一批一直持着仓，没有别的批次能改计数器
        - 实测 59 品种 × 5 模式共 594 个 TP+PSL 批次，零个反例
    - **时段末强平 END_SESSION** → **什么也不做**（既不加也不清零）
- 够阈值（3）时 **arm 冷静期，并在 arm 的同时把计数器清零**
    - 所以冷静期解除之后是从 0 重新数，不会一进一出就再次触发
- 「什么也不做」与「清零」在观察上是能区分的
    - `SL, END, SL, SL` → **会** arm（END 没打断连续）
    - `SL, TP, SL, SL` → **不会** arm（TP 清零了）
- **已知代价，如实记录**：时段锁死之后 END_SESSION 占了约七成批次却对计数器透明，于是三笔真止损可以横跨一周、中间夹着五个收盘批却仍被算成「连续三次」。实测 RB/split 下四次连续止损冷静期**全部**是这种
    - 曾试过「亏损的整批 END 算一次看错」：59 品种 × 5 模式下冷静期 +25%、批次 −14%、逐组合收益 129 好 / 152 差（噪声），行为改变远大于它解决的问题，已回退
    - 真要收紧，应该给「连续」加时间上限，而不是把收盘平仓塞进这个计数器

#### 触发器 2 · 单根日线实体吃穿 ≥2 条均线

- 含义：暴力单边行情，均线本身滞后，需要先观望而不是继续按级联信号进场
- 判定：日线实体区间 `[min(open,close), max(open,close)]` 包住 MA5/MA20/MA50 中至少 2 条
- 开关 `cooldown_on_structure_break`（默认 True）
- **它比看上去重得多**
    - 开着时策略约**一半时间**在冷静期里（59 品种均值 45%~51%）
    - 关掉降到 10%~25%，批次 +14.3%
    - 295 个（品种,模式）组合里**没有一个**从不触发它
    - 时段锁死之后触发器 1 很少响（七成批次走不到止损），所以触发器 2 实际扛了大头：RB 一年 13 个冷静期区间里 **9 个**来自它

### 4.8 参数表（全部沿用 v2.1 默认值）

- `ma_fast=5` / `ma_mid=20` / `ma_slow=50`
- `atr_period=14`
- `sl_atr_mult=1.5` / `sl_offset_pct=0.003` / `swing_k=2`
- `partial_ratio=0.5` / `rr_trigger=2.0` / `chandelier_mult=3.0`
- `cooldown_sl_threshold=3` / `cooldown_release_bars=3`
- 设计巧合：`rr_trigger × sl_atr_mult == chandelier_mult`（2.0×1.5 = 3.0）时，部分止盈触发的那一刻吊灯线恰好落在保本位。这是两条腿共用同一个 ATR 的理由。破坏它不是错，但要知道自己在破坏什么

## 五、时段末强平 End Session（本阶段新增，三个策略共享）

### 5.1 语义

- 时段模式从「只挡入场」升级为**锁死**
- 两个正交的开关合起来才叫锁死
    - `session_gates_entry`：不可交易时段不开仓，外加时段末根不开仓
    - `session_forces_flat`：时段最后一根 1 分钟 bar 强制平仓
- 结果：**未选中的时段完全空仓且无交易**

### 5.2 机制

- 由 `is_session_last[i]` 驱动
    - 该列由 `session_id` 单独算出，**完全不看 `tradable`**
    - 帧的**最后一根**恒为 True，所以锁死下收尾必然空仓
- **成交价 = 该根的 close**
- **不做跳空补价**，`gapped` 恒为 False
- 三个策略逐字同构（R-Breaker 突破/反转本来就是这个逻辑，本阶段只是把 Archive-Pullback 对齐过去）

### 5.3 为什么裸 `is_session_last[i]` 就够，不需要 `and tradable[i]`

- 持仓只可能开在可交易时段内
- 而那个时段自己的末根也带 `is_session_last` → 会在那里被平掉
- 走不到下一个不可交易时段

### 5.4 入场端的配套闸门

- **成交那一根是时段末根 → 不开仓**
- 否则这一批既在这根成交、又在这根被强平，会产生一条 0 根 bar 的 END_SESSION 腿
- 必须按**成交下标**判定（成形根口径下成交发生在 i+1）
- Archive-Pullback 里这道闸门**不消耗** `pullback_seen`

### 5.5 部分仓位的处理（容易错的地方）

- Archive-Pullback 的一批可能已经 2R 止盈平掉一半
- 此时强平的 `size_fraction` 必须是 **`1 − partial_ratio = 0.5`**，不是 1.0
- 写死 1.0 会让 `Σ size_fraction` 变成 1.5，破坏成本口径和统计层
- **强平不是 `elif`**：同一根上止盈刚平掉一半时，剩下那一半也要在这根被强平 → 这一批产生 TP + END_SESSION 两条腿
- 实测每种时段模式发生 6~10 次

### 5.6 对冷静期的影响（Archive-Pullback）

- **END_SESSION 不计入「同方向连续止损」计数器**：既不加一，也不清零
- 理由：时段强平是日历驱动的，不含任何方向判断信息 —— 既不像纯止损那样「确认看错了方向」，也不像止盈那样「这一轮赚到了」
- 这是 v3.0 新增的第三档：v2.1 的 `cooldown.py` 只有「加一」和「清零」两档，两边语义从此有一处**刻意**的不对齐
- 可观测后果：`SL, END, SL, SL` 会 arm 冷静期（END 没打断连续）

### 5.7 锁死带来的可观测变化

- **五种时段模式第一次两两不同**
    - 锁死之前 `split` / `night_day` / `day_night` 逐字节相同（它们 `tradable` 全为真，区别只在分组，而当时没有任何逻辑读分组）
    - 强平读 `is_session_last`，而它直接由分组算出 → 分组第一次变成可观测的东西
- 强平点数（RB，2025-07-01 ~ 2026-07-29）
    - `split` 日夜分开：510（每天两次：夜盘收盘 + 15:00）
    - `day_night` 自然日 日→夜：259（每天一次，夜盘收盘）
    - `night_day` 交易日 夜→日：258（每天一次，15:00）
    - `day` 日盘：258
    - `night` 夜盘：252
- **唯一的例外：无夜盘品种**
    - 每个 trading_date 只有一个原子段，三个分组键同步递增
    - 于是 `split ≡ night_day ≡ day_night ≡ day`，而 `night` 零成交
    - 59 个品种里有 14 个：AP CJ IC IF IH JD LH PK SF SM T TF TS UR
- 改动幅度：默认 `split` 下约**八成批次被改写**（RB 实测 50 批中 40 批原本跨时段）
- 出场构成：收盘平仓成为**最主要**的出场方式（59 品种 split 合计 5105 / 7484 条腿）

### 5.8 为什么这不是未来函数

- 收盘时间是交易所**提前公告**的
- `is_session_last` 是窗口形状的属性，循环开始前就已确定，不依赖任何价格

## 六、三个策略横向对比

### 6.1 出场原因

- R-Breaker 突破：`TRAIL` / `SESSION_END`
- R-Breaker 反转：`TRAIL` / `SESSION_END`
- Archive-Pullback：`SL` / `TP` / `PROTECTIVE_SL` / `END_SESSION`

### 6.2 止损价格何时确定

- R-Breaker 突破：**随行情**。入场给一条起始线，每根重算，单调收紧，无保本地板
- R-Breaker 反转：**随行情**。同上，公式镜像
- Archive-Pullback：**入场时定死**。止盈后剩余仓位才换成随行情的吊灯线，且**有保本地板**

### 6.3 止盈价格何时确定

- R-Breaker 突破：无止盈
- R-Breaker 反转：无止盈
- Archive-Pullback：**入场时定死**（入场价 ± 2R），限价成交，不补价

### 6.4 每时段笔数

- R-Breaker 突破：最多一笔
- R-Breaker 反转：最多一笔
- Archive-Pullback：不限

### 6.5 冷静期

- R-Breaker 突破：无
- R-Breaker 反转：无
- Archive-Pullback：有，两个触发器

### 6.6 入场时是否需要暖机

- R-Breaker 突破：只需前一个可用交易日的 H/L/C
- R-Breaker 反转：同上
- Archive-Pullback：需要 60 个交易日（日线 MA50）

### 6.7 读几条线 / 几个周期

- R-Breaker 突破：2 条线（Bbreak / Sbreak），单周期
- R-Breaker 反转：4 条线（Ssetup / Senter / Benter / Bsetup），单周期
- Archive-Pullback：不读线，读 4 个周期的 MA 级联（1m / 5m / 30m / 1d）

## 七、读结果之前必须知道的

- **不要在一年数据、多重比较里挑赢家**。59 品种 × 5 模式 × 3 策略的表格里最好看的那一格基本注定是噪声。只看结构性差异（笔数 / 持有时长 / 离场构成 / 跳空）
- **Archive-Pullback 的结果不能和 v2.1 phaseF 的账本比**。周期重映射把时间常数拉长约 12 倍，再叠一层强制时段内平仓
- **R-Breaker 突破与反转天然可比**（初始风险距离逐字节相同），但它们与 Archive-Pullback 不可比（后者有止盈、有冷静期、不限笔数）
- **系数是旋钮不是真理**。R-Breaker 的 f1/f2/f3 有多个流传版本；`cost_bps` 目前是 0，仓库还没有 tick_size / 合约乘数 / 费率表
