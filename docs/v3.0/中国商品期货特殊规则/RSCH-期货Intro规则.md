# 1. 交易所与监管框架

## 1.1 监管层级

三层结构，权责不同，不可混为一谈：

| 层级 | 主体 | 职能定位 |
|---|---|---|
| 行政监管 | 中国证监会（CSRC） | 品种注册核准、规则备案、行政处罚、机构牌照 |
| 一线自律 | 五家商品交易所 | 制定并执行交易/结算/交割/风控规则，实时监控，异常交易处理 |
| 行业自律 | 中国期货业协会（CFA） | 期货公司与从业人员自律管理、资格考试、投教 |
| 数据集中 | 中国期货市场监控中心 | 保证金安全存管监控、账户统一开户、市场运行数据 |

**关键点：**本文档讨论的绝大多数"规则差异"发生在**交易所层面**。证监会不规定收盘时间、订单类型、板块划分；交易所也不规定期货公司软件里有什么按钮。混淆这三层是理解本主题最常见的错误。

# 2. 行情数据形式

## 2.1 数据层级：Level-1 与 Level-2

| 层级 | 盘口深度 | 内容 |
|---|---|---|
| Level-1（基本行情） | **买一/卖一，仅 1 档** | 最新价、成交量、成交额、持仓量、最高/最低、涨跌停价、昨结算等 |
| Level-2（深度行情） | **买五/卖五，5 档** | Level-1 全部字段 + 五档委托价量 |

**重要认知纠偏：**国内期货交易所的 Level-2 **不是**股票市场那种逐笔委托/逐笔成交。**国内商品期货交易所目前不对外发布逐笔（tick-by-tick）委托与成交流，只发布定频快照**【二手，多方一致】。所谓"期货 tick 数据"在国内语境下几乎总是指"快照"，与美股/A股逐笔数据不是一个东西。这是回测中最容易被高估的数据精度来源。

**各交易所提供情况：**

| 交易所 | Level-1 | Level-2（深度行情） | 备注 |
|---|---|---|---|
| SHFE | 有 | 有 | 官网设"基本行情/深度行情"资料下载栏目【官方网站栏目】 |
| INE | 有 | 有 | 同上【二手】 |
| DCE | 有 | 有 | 五档【二手】 |
| CZCE | 有 | 有 | 【二手】 |
| GFEX | 有 | 有 | 官网明确设"基本行情资料下载/深度行情资料下载/延时行情资料下载"三栏【官方网站栏目】 |

Level-2 为**付费授权**行情，需通过交易所行情信息授权或数据商购买；免费软件默认给 Level-1。

## 2.2 行情字段逐一解释

| 字段 | 含义 | 易错点 |
|---|---|---|
| 开盘价 | 开市前 5 分钟集合竞价产生的成交价；集合竞价未产生成交价的，以其后第一笔成交价为开盘价【官方，《上海期货交易所交易规则》】 | 有夜盘品种，"开盘价"指**夜盘 21:00 的开盘价**，不是日盘 9:00 的价格 |
| 最高/最低价 | 当日交易期间的极值 | 同样跨夜盘+日盘整个交易日 |
| 收盘价 | **当日交易的最后一笔成交价格**【官方，《上海期货交易所交易规则》】 | 国内商品期货**没有收盘集合竞价**，收盘价就是 15:00 前最后一笔撮合价 |
| 成交量 | 当日所有成交合约的**单边**数量【官方，《上海期货交易所交易细则》】 | 单边/双边口径在历史数据中曾变化，跨期比较需注意【待核实切换日期】 |
| **持仓量** | 交易者持有的未平仓合约的**单边**数量【官方，同上】 | 与成交量正交：成交量衡量换手，持仓量衡量资金沉淀。持仓量增减方向是判断资金进出的核心，也是数据商定义"主力合约"的主要依据（见 §5） |
| **结算价** | **当日成交价格按成交量的加权平均价**（全天 VWAP）。当日无成交的，按交易所另行规定确定【官方，《上海期货交易所交易细则》】 | 见下 |
| 买卖盘口 | 申买价/申买量、申卖价/申卖量。Level-1 仅 1 档，Level-2 为 5 档 | 快照口径下，盘口是切片时刻的状态，不含中间过程 |

### 收盘价 vs 结算价 —— 必须分清的一对

这是本节最重要的区分：

| | 收盘价 | 结算价 |
|---|---|---|
| 定义 | 当日最后一笔成交价 | 当日成交量加权平均价（商品期货） |
| 性质 | 一个**时点**价格 | 一个**全日汇总**价格 |
| 用途 | 行情展示、技术分析 | **当日无负债结算的唯一依据**：计算持仓盈亏、占用保证金；作为**下一交易日涨跌停板的基准价**；期权行权实值判定 |
| 可被操纵性 | 高（尾盘单笔即可影响） | 低（需要全天真实成交量） |

**实务含义：**
1. 盘中浮盈与结算单上的盈亏必然不一致，差异来自"以结算价而非收盘价盯市"。这只是把总盈亏在持仓期间重新分摊，不改变最终结果。
2. **算涨跌停板要用昨结算价，不是昨收盘价。**用收盘价算停板是回测中的高频错误。
3. 三家商品交易所（SHFE/INE、DCE、CZCE）均采用全天成交量加权均价【SHFE 为官方；DCE/CZCE 为【二手】，建议查各所《交易细则》"结算价"条款】。中金所股指/国债采用最后一小时加权均价【二手】——**这是"结算价"一词在不同交易所含义不同的典型例证**。
4. 交割结算价另有一套规则，且各所差异更大（郑商所配对日前十个交易日结算价算术平均、大商所集中交割为交割月全月加权均价、上期所部分品种取最后交易日结算价等）【二手，各品种规则不同，逐品种核实】。

## 2.4 衍生序列：主力合约 / 连续合约 / 加权指数

**这三者都不是交易所产品，全部由数据商合成，不可交易。**

| 序列 | 数据来源 | 构造方式 | 特性 |
|---|---|---|---|
| 主力合约（主连） | 真实合约行情的拼接 | 按规则选出当前"主力"月份合约，把历次主力合约的行情首尾相接 | 每段是真实可交易价格，但**换月处有跳空缺口** |
| 加权指数（指数） | 同品种全部月份合约 | 按持仓量（或成交量）对所有活跃月份加权平均 | 曲线平滑无跳空，但**任一点都不对应任何可成交价格** |
| 换月拼接（展期序列） | 真实合约 + 展期规则 | 按固定节奏分批移仓（例如 5 个交易日每日 20%） | 更接近实盘移仓成本，构造复杂度最高 |

三者用途分工：加权指数适合看品种级别的趋势与做板块比较；主力连续适合信号计算但需处理跳空；换月拼接适合严肃回测。**把加权指数当作可交易价格序列做回测，会系统性高估收益**——因为它抹掉了真实存在的换月成本。

# 4. 委托指令（Order）类型

## 4.1 核心区分：交易所原生 vs 软件模拟

这是本节的全部要点。市面上流传的"期货订单类型清单"绝大多数把两者混在一起，造成严重误解。

| | 交易所原生指令 | 期货公司/软件端条件单 |
|---|---|---|
| 存放位置 | 交易所撮合主机 | 期货公司柜台服务器（CTP 等）或客户本地软件 |
| 触发保证 | 交易所撮合保证 | **无任何交易所保证**。触发依赖柜台/本地收到行情并发单，可能因断线、行情延迟、涨跌停无对手方而失效 |
| 排队优先级 | 报单即进入交易所订单簿排队 | 触发前**不在交易所订单簿中**，触发后才发单，排队位置在触发时刻才确定 |
| 典型代表 | 限价、市价、FAK、FOK、（部分所）止损（盈）、套利指令 | 各软件"止损止盈单""预埋单""条件单""追踪止损" |

**权威佐证：**CTP（综合交易平台）官方开发文档明确说明，其条件单"为 CTP 后台系统自带指令，并非交易所官方支持指令"【官方级技术文档】。这一句是理解整个问题的钥匙。

**实务后果：**极端行情下（跳空、连续涨跌停），软件端止损单几乎必然失效或成交在远离预期的价位；而交易所原生的限价止损（盈）指令虽然进了交易所，但触发后转成的限价单同样可能无法成交。**任何形式的止损都不是保险。**

## 4.2 交易所原生指令：按交易所分列

| 指令 | SHFE | INE | DCE | CZCE | GFEX |
|---|---|---|---|---|---|
| **限价指令** | ✅【官方】 | ✅ | ✅【官方】 | ✅【官方】 | ✅【官方】 |
| **市价指令** | ❌ **无原生市价指令**【二手，多方技术文档一致】 | ❌【二手】 | ✅ 执行时**自动以同方向停板价参与撮合**【二手】 | ✅ 按当时市场可执行的最优报价成交【官方，《郑商所期货交易细则》】 | 【待核实】 |
| **FAK**（立即成交剩余撤销） | ✅【二手】 | ✅ | ✅【官方，《大商所交易细则》第三十九条】 | ✅【二手】 | 【待核实】 |

| **套利指令** | ❌ 无原生【二手，倾向"无"，待核实】 | ❌【待核实】 | ✅ 跨期、跨品种【官方】 | ✅ 跨期、跨品种【官方，《郑商所期货交易细则》】 | 官网设"套利合约明细""套利保证金优惠参数"栏目，推定有【二手，待核实】 |

## 4.3 市价指令的三种不同实现（各所行为不一致，务必区分）

市价指令是"看似统一实则完全不同"的重灾区：

| 交易所 | 行为 |
|---|---|
| **SHFE / INE** | **交易所层面不存在市价指令**。快期、文华等软件显示的"市价"按钮，实际是**以涨跌停板价发出的限价单**【二手，CTP 开发资料与多方技术文档一致】。因此在 SHFE 下"市价单"，你的委托会真实挂在停板价上 |
| **DCE** | 市价指令的定义即为"执行时自动以同方向停板价格参与交易"【二手】。与上期所的软件模拟结果相似，但这是**交易所原生行为** |
| **CZCE** | 市价指令为标准含义：按当时市场可执行的最优报价成交；**未成交部分自动撤销**；**交易期间市价指令先于限价指令执行**；行情出现单方无报价时未成交的市价指令自动撤销【官方，《郑州商品交易所期货交易细则》】 |

**共同限制：**
- 市价指令**不参与集合竞价**；集合竞价申报时段发出的市价指令会被交易所视为无对手方而自动撤单【官方（郑商所细则）/【二手】（其他所）】
- 附加 FAK/FOK 属性的指令**只在连续交易期间有效**，其他时段不得申报【二手】
- 各所对限价指令、市价指令的**每次最大下单量**有单独且不同的规定，并会针对个别合约临时调整（例如郑商所曾将动力煤限价指令最大下单量调至 50 手、市价指令 10 手）【官方，郑商所公告转述】。**这个数字逐品种逐时点变化，本文不列。**

## 4.4 集合竞价期间的指令限制（各所不同，见 §6 展开）

以大商所为例，日盘集合竞价申报阶段仅支持**无属性的市价单和限价单、市价止损（盈）单和限价止损（盈）单**的申报与撤单；**套利单不能参与集合竞价**；撮合阶段**市价止损（盈）单与限价止损（盈）单不参与撮合**【官方，大商所发〔2023〕20号转述】。

其他交易所的限制条款不同，不可套用。

# 5. 合约命名、切分与拼接

## 5.1 合约命名规则（按交易所分列，差异真实存在且致命）

| 交易所 | 格式 | 示例 | 说明 |
|---|---|---|---|
| SHFE | 小写品种代码 + **4位** 年月（YYMM） | `rb2510` = 螺纹钢 2025年10月 | 【官方/二手一致】 |
| INE | 小写品种代码 + **4位** 年月 | `sc2603` = 原油 2026年3月 | 同上 |
| DCE | 小写品种代码 + **4位** 年月 | `m2601` = 豆粕 2026年1月 | 同上 |
| **CZCE** | **大写**品种代码 + **3位**（年份末1位 + 月份2位） | `SR601` = 白糖 2026年1月；`MA509` = 甲醇 2025年9月 | 【官方，交易所报单格式】 |
| GFEX | 大写品种代码 + **4位** 年月 | `PT2606` = 铂 2026年6月；`LC2701` = 碳酸锂 2027年1月 | 【官方，广期所公告中合约代码写法】 |

### 郑商所 3 位代码是一个真实的数据陷阱

`CF701` 既可表示 **2007年1月** 棉花合约，也可表示 **2017年1月** 棉花合约——**10年一循环，仅凭合约代码无法区分**。

处理方式因数据商而异，无统一标准：
- 米筐（RiceQuant）明确说明：将郑商所代码统一补齐，例如 `CF701` 补为 `CF1701`【官方文档，米筐 RQData】
- BigQuant 明确说明：合约代码与交易所保持一致，**不做补全**，`SR409.CZC` 既可能是 2014年9月也可能是 2024年9月【官方文档】
- 天勤 TqSdk：郑商所写法为大写 + 3 位数字，`CZCE.SR901`，不接受 4 位写法【官方文档】

**实务后果：**跨数据源拼接郑商所历史数据时，若一方补齐、一方不补齐，会静默产生错误合并；十年以上的长周期回测尤其危险。**这是数据工程层面必须显式处理的问题，不是可以忽略的细节。**

另需注意：**同一份数据里，大小写规则也不统一**——上期所/大商所小写，郑商所/广期所大写。区分大小写的系统里 `ma2509` 与 `MA509` 是两个不存在的东西。

## 5.2 合约月份

**没有全市场统一的挂牌月份规则。**由各品种合约文本单独规定，例如：
- 工业金属类多为 1–12 月全月连续挂牌
- 部分农产品仅挂单月或特定月份（例如白糖历史上为 1、3、5、7、9、11 月）
- 部分品种设"主力月份"与"非主力月份"，流动性极度集中于少数月份（典型如农产品的 1/5/9 月，工业品的 1/5/10 月）

【上述月份举例为【二手/常识】，**具体以各所各品种合约文本为准**，不得据本文推断。】

**流动性的月份集中现象比合约月份规则本身更重要：**同一品种，非主力月份可能全天成交几十手，其"收盘价"与"结算价"几乎没有信息含量，直接用于计算跨期价差会得到大量噪声。

## 5.3 主力合约的定义

**交易所不定义"主力合约"。**这是一个纯粹的数据商/研究机构约定概念，**各家不同**：

| 口径 | 切换条件 | 采用方 |
|---|---|---|
| 持仓量最大 | 次主力持仓量超过主力时切换 | 文华财经主连本质采用此方案【二手，来源为公开研究整理】 |
| 成交量最大 | 以成交量为准 | 部分软件与研究口径 |
| 持仓量 + 成交量双条件 | 两者同时超过才切换 | 部分数据商 |
| 加确认期 | 例如"连续 3 个交易日超过"才触发切换 | 中期协研报所述某商品指数方案：连续 3 个交易日远月持仓量超过样本合约，则从下一交易日开始展期，展期周期 5 个交易日，每日 20%【官方级研报】 |
| 不回切规则 | 一旦切换到远月，即使近月持仓回升也不切回 | 多数严肃实现会加入此约束，否则会出现主力反复横跳 |

**结论：**"主力合约"在不同软件里指向的可能是不同的实际合约，尤其在换月窗口期。**任何以"主力合约"为口径的统计，必须先声明用的是谁的定义。**

## 5.4 三种拼接方式：产生三条不同的价格序列

对同一个品种、同一段历史，下述三种方法给出的 K 线**互不相同**，且都"正确"——它们回答的是不同问题。

### （1）主力连续
把历次主力合约的行情按时间首尾相接。
- **优点**：每一段都是真实成交价格，可与实盘对照
- **缺点**：换月点存在**跳空缺口**。因为旧主力与新主力的价格本就不同（基差/月差），这个缺口不是行情波动，是拼接产生的假信号
- **后果**：所有依赖价格连续性的指标（收益率、波动率、均线、突破）在换月点全部失真

### （2）加权指数
把该品种全部（或活跃）月份合约按持仓量（或成交量）加权平均。
- **优点**：曲线平滑无跳空，最能代表"品种整体价格水平"
- **缺点**：**任何一点都不是可成交价格**。且换月期间权重在两个价差很大的合约间转移，指数本身会产生与真实价格变化无关的位移
- **适用**：品种间比较、板块指数编制、宏观研究
- **禁忌**：不可用于计算实盘可实现收益

### （3）换月拼接（展期序列）
按预设规则分批移仓，例如触发条件满足后 5 个交易日内每日移仓 20%。
- **优点**：最接近实盘操作，把换月成本显式建模进序列
- **缺点**：规则参数（触发条件、展期天数、每日比例）本身是主观选择，不同参数给出不同序列
- **适用**：严肃回测、指数产品编制（商品 ETF/指数基金普遍采用此类规则）

## 5.5 换月复权方式

复权用于消除主力连续序列在换月点的跳空。**三种处理，各自改变价格序列的不同部分：**

| 方式 | 做法 | 对价格序列的影响 |
|---|---|---|
| **不复权** | 直接拼接，保留跳空 | 最新价格 = 真实价格；历史价格 = 真实价格；但**收益率序列在换月点错误** |
| **前复权** | 以最新合约价格为基准，向前调整全部历史价格 | **最新价 = 真实价**，历史价被改写。每次换月，整条历史曲线都会变动一次 → **历史信号会"闪烁"**（昨天回测出的历史信号，今天可能不存在了） |
| **后复权** | 以最早合约价格为基准，向后调整后续价格 | **历史价 = 真实价**，最新价被改写，可能与盘面价格差出很远（长周期后甚至可能为负）。优点是**历史序列稳定不变**，回测可复现 |

**调整方法还分两类**（与上面正交）：
- **价差调整（加减法）**：新旧主力价差直接加减。保持绝对价差不变，适合做价差交易
- **比例调整（乘除法）**：按新旧价格比例缩放。保持收益率不变，适合做收益率类研究

**给量化实务的判断：**回测优先用**后复权**（历史不变、结果可复现）；实盘信号展示用不复权 + 显式处理换月。前复权因"历史闪烁"问题，是回测中最容易产生自我欺骗的选项。

## 5.6 核心结论：拼接口径无统一标准

**不同数据商的主力定义、切换规则、加权方式、复权方式全部不同，且大多不完整公开。**同一段行情在文华财经、同花顺、Wind、东方财富、米筐、天勤中会呈现不同的 K 线形态。

实务纪律：
1. **策略研发全程锁定单一数据源**，不得中途混用
2. 换数据源等同于换了研究对象，必须全部重跑
3. 论文/研报中若未声明拼接口径，其回测结果不可复现，也不应被采信

# 6. 竞价规则（重点：夜盘到日盘的特殊规则）

## 6.1 集合竞价的基本结构

集合竞价固定为**开市前 5 分钟**，内部拆分为两段：

| 阶段 | 时长 | 可做什么 |
|---|---|---|
| 指令申报阶段 | 前 4 分钟 | 可报单、可撤单 |
| 集合竞价撮合阶段 | 后 1 分钟 | **不接受任何指令申报**，此时下单为废单 |

**撮合原则：最大成交量原则**——取能产生最大成交量的价格为集合竞价成交价。高于该价的买单全部成交，低于该价的卖单全部成交，等于该价的一方按数量少的一方成交【官方，《上海期货交易所交易细则》】。

### 用一个例子讲清 SHFE/DCE 与 CZCE 的实质区别

假设投资者昨夜挂了一笔买单未成交，也未撤单：

**在大商所（如铁矿石）**：今早 8:55–8:59 可以撤单。若不撤，该单进入 8:59–9:00 集合竞价撮合——**若集合竞价价格低于其挂单价，该单以集合竞价价格成交（成交价优于挂单价）**；若集合竞价价格高于挂单价则不成交，转入连续竞价继续挂着。**集合竞价机制在这里对投资者是保护性的。**

**在郑商所（如甲醇）**：今早 8:55–8:59 只能撤单，**不能做任何其他操作**。若不撤，该单在 9:00 开盘瞬间直接进入连续竞价。若隔夜外盘暴跌、开盘直接低开至挂单价以下，**该买单会在开盘瞬间成交，形成即时浮亏**。

【上述机制说明基于财联社等媒体对交易所规则的解读【二手】，逻辑与各所公告一致，但具体成交细节建议以交易所规则原文复核。】

**这就是为什么"各交易所处理差异"这一条必须逐所列出——同样的挂单行为，在两个交易所会产生完全不同的风险敞口。**

## 6.4 连续竞价的撮合价形成机制

连续竞价采用**价格优先、时间优先**排序，买入价 ≥ 卖出价时自动撮合。

**成交价的确定（上期所规则，明确写入规则文本）：**
成交价等于买入价（bp）、卖出价（sp）、前一成交价（cp）**三者中居中的一个价格**【官方，《上海期货交易所交易规则》第二十四条】。

即：
- 若 bp ≥ sp ≥ cp，则成交价 = sp
- 若 bp ≥ cp ≥ sp，则成交价 = cp
- 若 cp ≥ bp ≥ sp，则成交价 = bp

**含义：**新报单不会以任意价格成交，"取中间价"机制限制了单笔大单在稀薄盘口上的瞬时冲击幅度。这条规则在低流动性合约上尤其重要。

其他交易所的连续竞价成交价规则表述可能不同【待核实】，请查各所《交易规则》。

# 7. 节假日规则

## 7.1 三条核心规则

**规则一：法定节假日前第一个工作日不进行夜盘交易。**

官方标准表述（见各所品种上市通知）：
> 法定节假日前第一个工作日（不包含周六和周日）的连续交易时间段不进行交易。
> 【官方，上期所铸造铝合金期货上市通知】

郑商所表述为"夜盘交易时间段不进行交易"，含义相同【官方】。

**注意括号里的"不包含周六和周日"**——这个限定语是必要的：假期若从周一开始，"前第一个工作日"是上周五，不是周日。

**规则二：法定节假日期间全市场休市，不存在任何隔夜交易通道。**

国内期货市场在休市期间**完全关闭**，持仓者无法平仓、无法调整、无法对冲。外盘（LME、CME、ICE）在此期间正常交易，价格可能大幅变动。这构成中国商品期货特有的**假期跳空风险**。

各交易所为此在节前统一**上调涨跌停板幅度与交易保证金比例**，节后再逐步恢复。例如上期所 2026年春节前公告：黄金期货涨跌停板调至 20%、一般持仓保证金 22%；白银调至 25% / 27%；铜铝锌铅氧化铝调至 13% / 15%；铸造铝合金、线材、不锈钢调至 11% / 13%【官方，上期所 2026年春节工作安排通知】。**此为示例，非通用值，每年每次假期均不同。**

**规则三：交易日历——夜盘归属"次一交易日"。**

这是理解整套时间规则的关键概念：

> **交易日 T 的起点是 T-1 日晚上 21:00 的夜盘，终点是 T 日 15:00 收盘。**

推论：
- 周一的交易日**始于上周五晚 21:00** 的夜盘
- 夜盘的成交计入次日的成交量、结算价、持仓量
- 夜盘时段的行情，K线归属日期是**次一交易日**（这也是为什么不同数据商对夜盘K线的日期归属可能不一致，需核对）
- 假期前最后一个交易日 T 当晚本应属于交易日 T+1 的夜盘被取消 → **节后第一个交易日只有日盘**，且当天 08:55–09:00 进行集合竞价，**当晚恢复夜盘**

## 7.2 具体示例（示例性质，不作为通用日期）

上期所 2026年春节安排【官方】：

| 日期 | 安排 |
|---|---|
| 2026年2月13日（周五） | 日盘正常交易；**当晚夜盘停盘** |
| 2026年2月14日 – 2月23日 | 全市场休市 |
| 2026年2月24日（周二） | 08:55–09:00 集合竞价，日盘正常交易；**当晚恢复夜盘** |

**此表仅为机制示例。**

## 7.3 关于具体节假日日期的明确声明

**本文不列任何未来年度的节假日休市日期。**

原因：
1. 中国法定节假日安排由国务院办公厅**每年年底发布次年安排**，含调休，不可提前推算
2. 各交易所在此基础上**逐次发布休市安排公告**，且交易所公告的休市日与法定假日不完全等同（涉及调休上班日是否交易）
3. 交易所会另行公告**非法定假日的休市日**（如系统升级）

**正确做法：**
- 逐次查阅各交易所"通知公告"栏目的《关于XX节期间交易时间安排的通知》
- 或使用交易所官网提供的**交易日历**（例如广期所设有"交易日历"栏目）
- 程序化系统应从交易所公告或行情商的交易日历接口动态获取，**严禁在代码中硬编码假期日期**

# 8. 板块划分（明确：无单一权威标准）

## 8.1 首先必须说明的事实

**五家商品期货交易所均不发布统一的商品板块分类标准。**

交易所只按自身上市品种组织信息（例如上期所在官网将品种分为"有色金属/贵金属/黑色金属/能源化工"栏目），但这是**该所自身品种的目录组织**，不是全市场分类标准，也不跨交易所。

因此，市场上流通的一切"板块"划分——黑色系、能化、有色、农产品、油脂油料——**全部是数据商、研究机构、媒体各自的约定**，彼此不同，**没有任何一种是"官方"或"权威"的**。

这不是措辞谨慎，而是有实际后果：同一个品种在不同口径下会落入不同板块，导致"板块涨跌幅""板块资金流向"等统计在不同软件间不可比。

1. 分类粒度：4 类 vs 19 类
2. 权重：现货消费额加权 vs 等权算术平均
3. 覆盖：20 个精选品种 vs 57 个全覆盖

**因此"商品指数涨了 2%"这句话，在不指明编制方是谁时没有信息量。**

# 9. 品种产业链上下游图谱

## 9.0 阅读约定

- `→` 表示**物料流方向**（上游 → 下游）
- 「成本传导」一栏说明**价格影响方向**，以及传导是否顺畅
- 关键判断：**成本传导是否顺畅，取决于下游需求强弱**。需求强时上游涨价可向下传导，下游企业利润不受损；需求弱时上游涨价被下游吸收，表现为**加工利润被压缩**。加工利润（而非单边价格）才是产业链交易的核心变量。
- 本节为产业逻辑描述，**不含具体产能、比例、成本数字**——这类数字变动快，且本文无法核实到可引用的程度。

## 9.1 黑色系

```
铁矿石(i, DCE) ─┐
                 ├→ 高炉铁水 → 粗钢 → 螺纹钢(rb, SHFE)
焦煤(jm, DCE) → 焦炭(j, DCE) ─┘              热轧卷板(hc, SHFE)
                                              线材(wr, SHFE)
辅料（旁支，非主链）：
  锰矿 + 电力 → 锰硅(SM, CZCE) ─┐
  兰炭 + 电力 → 硅铁(SF, CZCE) ─┴→ 炼钢脱氧/合金化
```

**结构说明：**
- 焦煤经炼焦转化为焦炭，焦炭与铁矿石在高炉中还原为铁水，铁水转炉炼钢后轧制为螺纹钢（建筑用）、热卷（板材，制造业用）、线材
- 硅铁、锰硅是**炼钢辅料**，属于旁支而非主链，其成本主要受**电价**与矿石价格驱动，与钢材需求相关但传导链条更长

**成本传导方向：** 铁矿/焦煤 → 焦炭 → 钢材，**自上游向下游**。
- 上游原料上涨 → 钢厂成本上升
- 若终端（地产、基建、制造业）需求强 → 钢价跟涨，钢厂利润维持
- 若终端需求弱 → 钢价涨不动，**钢厂利润被挤压** → 钢厂主动减产 → **需求负反馈回上游**，焦炭铁矿转跌

**核心可交易变量：**钢厂利润（螺纹/热卷 相对 铁矿+焦炭 的价差）、焦化利润（焦炭 相对 焦煤 的价差）。这是黑色系跨品种套利的基础结构。

## 9.2 油脂油料

```
大豆 ── 压榨 ──┬→ 豆粕(m, DCE)  ── 饲料蛋白 → 生猪(lh)/鸡蛋(jd)
               └→ 豆油(y, DCE)  ── 食用油/工业

油菜籽(RS, CZCE) ── 压榨 ──┬→ 菜籽粕(RM, CZCE)
                            └→ 菜籽油(OI, CZCE)

棕榈油(p, DCE)：进口为主，无国内压榨环节，直接受产地（马来/印尼）产量与生柴政策驱动

玉米(c, DCE) ──┬→ 玉米淀粉(cs, DCE)（深加工）
                └→ 饲料能量 → 生猪(lh)/鸡蛋(jd)
```

**结构说明：**
- **豆一（a）与豆二（b）不是同一个东西**：豆一为国产非转基因食用大豆，豆二为进口转基因压榨用大豆。二者定价逻辑与政策敏感度不同，不可当作同一品种的不同月份看待
- 大豆压榨是**一进两出**：一份大豆同时产出豆粕与豆油，二者是**联产品**而非上下游关系

**成本传导方向：**大豆 → 豆粕 + 豆油，**上游成本同时影响两个下游**。
- 关键恒等式（概念，非精确公式）：`压榨利润 ≈ 豆粕价×出粕率 + 豆油价×出油率 − 大豆成本 − 加工费`
- **联产品的相互挤压**：豆粕与豆油共享同一份原料成本。若豆粕需求强而豆油弱，压榨厂增开机 → 豆油被动增产 → 豆油承压。这是**油粕比**交易的基础

**替代关系（横向，非纵向）：**
- 蛋白粕内部：豆粕 ↔ 菜粕（饲料配方可部分替换）
- 油脂内部：豆油 ↔ 菜油 ↔ 棕榈油（食用与工业用途可部分替换，棕榈油受温度影响存在季节性）
- **替代关系意味着价差有边界**：价差扩大到替代成本之上会触发实际替换，形成均值回归压力

**向下游传导：**豆粕（蛋白）+ 玉米（能量）构成饲料成本主体 → 生猪、鸡蛋养殖成本。但**养殖利润由猪价/蛋价与饲料成本共同决定**，且养殖周期（母猪存栏 → 出栏约 10–12 个月）远长于饲料价格波动周期，**传导存在显著时滞且经常不顺畅**。

## 9.3 能源化工

### 聚酯链（最完整的一条化工链）
```
原油(sc, INE) → 石脑油 → 对二甲苯 PX(CZCE)
                                    │
                                    ├→ PTA(TA, CZCE) ──┐
                                    │                    ├→ 聚酯(PET)──┬→ 短纤(PF, CZCE)
乙烯 ─────────→ 乙二醇 MEG(eg, DCE) ─┘                    ├→ 瓶片(PR, CZCE)
                                                          └→ 长丝（未上市）
```
**成本传导：**原油 → PX → PTA → 聚酯，自上而下。可交易变量：**PTA 加工费**（PTA 相对 PX 的价差）、**聚酯利润**（短纤/瓶片 相对 PTA+MEG 的价差）。
乙二醇有煤制与油制两条工艺路线，成本曲线分裂，这使得 MEG 与原油的相关性弱于 PTA。

### 烯烃链
```
原油 → 石脑油 ─┐
天然气 → 丙烷  ─┼→ 丙烯(PL, CZCE) → 聚丙烯 PP(pp, DCE)
煤 → 甲醇(MA) ─┘（MTO/MTP路线）

乙烯 → 塑料 LLDPE(l, DCE)
电石法（煤→电石）或乙烯法 → PVC(v, DCE)
```
**结构说明：**丙烯（2025年7月22日在郑商所上市）是**石化与煤化工的承上启下枢纽**：上游连接原油、石脑油、煤炭、甲醇、丙烷多条路线，下游主要是聚丙烯【官方，郑商所丙烯上市相关报道】。
**多原料路线的含义：**同一化工品可由不同原料生产，**成本由边际生产路线决定**。原油涨价对 PP 的影响，取决于当时油制路线是否为边际产能。这使能化品的成本传导比黑色系复杂得多。

### 芳烃链
```
原油 → 石脑油/重整 → 纯苯 BZ(DCE, 2025-07-08上市)
纯苯 + 乙烯 → 苯乙烯 EB(eb, DCE)
```
**产业实证：**纯苯期货上市后，产业客户普遍采用"买入纯苯期货 + 卖出苯乙烯期货"锁定苯乙烯装置加工利润【官方，大商所数据与新华社报道】。这是产业链套保的标准范式——**交易的是加工利润，不是单边价格**。

### 其他
- **甲醇（MA, CZCE）**：煤/天然气 → 甲醇。下游分散：MTO 制烯烃、醋酸、甲醛、燃料。因下游多元，甲醇兼具能源属性与化工属性
- **尿素（UR, CZCE）**：煤/天然气 → 合成氨 → 尿素。下游为农业（约主体）+ 工业（复合肥、三聚氰胺、脱硝）。**农业需求有强季节性**（春耕、夏季追肥），且受出口政策直接影响
- **烧碱（SH, CZCE）与纯碱（SA, CZCE）名字像但完全不同**：
  - 纯碱（碳酸钠）→ **玻璃**（重质纯碱是浮法玻璃与光伏玻璃的主要原料）
  - 烧碱（氢氧化钠）→ **氧化铝**（这是化工链与有色链的真实交叉点）、造纸、印染
  - 二者上下游完全不同，**不可因名称相近而归为一类**
- **燃料油(fu)/低硫燃料油(lu)/石油沥青(bu)**：均为**炼厂产品**，随原油波动但受各自终端（船燃、道路施工）需求影响，沥青有明显的施工季节性

## 9.4 有色金属（必须说明：主要是平行关系，不是链式）

**这是与黑色系最大的结构差异。**

有色金属期货品种之间**大多不构成上下游关系**，而是**平行的宏观定价资产**：铜、锌、铅、镍、锡各自对应独立的矿产资源与冶炼体系，彼此不投入对方的生产过程。它们价格同向波动，主因是**共同暴露于同一组宏观变量**（美元、全球制造业周期、库存周期），而非产业链传导。

**真正存在链式关系的只有两条：**

```
链条一（铝系）：
铝土矿 → 氧化铝(ao, SHFE) → 电解铝(al, SHFE) ─┬→ 铝材（未上市）
                     ↑                          └→ 废铝/再生铝 → 铸造铝合金(ad, SHFE)
              烧碱(SH, CZCE) 为氧化铝主要辅料 ─┘
              电力为电解铝核心成本（未上市）

链条二（镍系）：
镍矿 → 镍铁/精炼镍(ni, SHFE) ─┐
铬铁 ─────────────────────────┼→ 不锈钢(ss, SHFE)
废不锈钢 ─────────────────────┘
```

**铸造铝合金（AD，2025年6月10日上市）的定位需要特别说明**：它主要以**再生铝（废铝）**为原料，因此并非严格意义上电解铝的下游，而是与电解铝形成**部分替代 + 部分成本关联**的关系。其与电解铝的价差（原铝-再生铝价差）反映的是再生铝供应与废铝回收体系的状况。【产业逻辑为【二手/常识】，具体交割标准以上期所合约文本为准】

**贵金属（黄金、白银）不属于工业产业链范畴**：主要由实际利率、美元、避险需求驱动。白银兼具工业属性（光伏、电子），因此与纯粹货币属性的黄金存在分化，金银比是常见的观察指标。

**成本传导方向：**
- 铝系：铝土矿 → 氧化铝 → 电解铝，链条较短且清晰；**电力与烧碱是重要的外部成本输入**
- 镍系：镍与铬是不锈钢的成本项，但不锈钢中废钢比例可调，**替代弹性削弱了传导刚性**

## 9.5 新能源金属

```
硅石 + 还原剂 + 电力 → 工业硅(si, GFEX) ─┬→ 多晶硅(ps, GFEX) → 硅片 → 电池片 → 组件（均未上市）
                                          ├→ 有机硅（未上市）
                                          └→ 铝合金添加剂

锂辉石 / 锂云母 / 盐湖卤水 → 碳酸锂(lc, GFEX) → 正极材料 → 锂电池（均未上市）

铂(pt, GFEX) / 钯(pd, GFEX)：汽车尾气催化、氢能（电解槽与燃料电池催化剂）、首饰、工业
```

**成本传导方向：**
- **工业硅 → 多晶硅**是 GFEX 内部唯一的真实上下游链条，且是国内商品期货中**最新形成的完整产业链**（多晶硅 2024年12月上市后才闭合）。工业硅是多晶硅的直接原料，成本传导方向自上而下；但多晶硅价格更多由**光伏装机需求与硅料产能周期**主导，工业硅成本更多起到**价格底部支撑**作用而非定价决定作用
- **工业硅本身是高耗电品种**，电价（尤其西南丰枯水期电价差异）造成显著的**季节性成本曲线**
- **碳酸锂无国内上下游期货品种配对**：上游锂矿、下游正极材料与电池均未上市，因此碳酸锂是一个"孤立节点"，其定价高度依赖现货与产业信息，缺少期货化的对冲对手盘
- **铂、钯的产业逻辑与新能源金属板块内其他品种差异极大**：主要用于汽车尾气催化（约占铂需求 60%、钯 80% 的绿色发展领域应用【官方，广期所上市报道】），需求受汽车产量、排放标准、以及铂钯之间的相互替代（配方可调）驱动。**广期所将其归入"新能源金属板块"是交易所自身的产品线叙事，不代表其价格驱动逻辑与工业硅/碳酸锂相似。**

## 9.6 不属于任何实物产业链的品种

- **集装箱运价指数（欧线，EC，INE）**：标的为运价指数而非实物商品，无实物交割，无上下游。其价格由航运运力、贸易量、地缘（如红海航线）驱动
- **各类天气指数、商品指数（GFEX）**：指数类合约
