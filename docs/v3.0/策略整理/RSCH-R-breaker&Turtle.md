# R-Breaker 与 Turtle：运行逻辑、变种，及与《回调再入场策略编目 v3》的对应

配套文档：`回调再入场策略编目_v3.md`（下称"编目"）。本文只写逻辑，不含参数与代码。

---

## 一、定性

| | 入场性质 | 是否属于编目定义的"回调再入场" |
|---|---|---|
| **Turtle** | 纯突破（在新极值处成交） | 否。违反 0.3 第 (2) 条：入场前不存在反向回撤 |
| **R-Breaker** | 空仓时纯突破；反转线只在**持仓时**生效 | 否。反转分支赌的是反转，违反 0.3 第 (3) 条 |

最值得记住的一句：

> **R-Breaker 的反转线与编目 A 类回调入场在 K 线形态上无法区分，区别完全由趋势过滤器提供——而 R-Breaker 没有趋势过滤器。**

"冲高、回落、穿越某价位"这个形状，配顺势过滤就是回调再入场，不配过滤就是失败突破反手。形态相同，赌注相反。这一点决定了后文所有映射结论。

## 二、R-Breaker 的运行逻辑

用**上一个交易日**的最高、最低、收盘价投射出六条水平线，当日固定不动，次日整套重算。自上而下：

```
突破买 › 观察卖 › 反转卖 › 反转买 › 观察买 › 突破卖
```

**趋势模式（空仓时生效）**
价格向上穿越最高那条 → 做多；向下穿越最低那条 → 做空。

**反转模式（持仓时生效）**
持多单时，当日最高价先触及"观察卖"，随后回落跌破"反转卖" → 平多并反手做空；持空单对称。

**两个设计要点**

1. **"观察价"的作用是武装（arming）**。它把一个静态价格变成"必须先走过一段路才生效"的条件，用于排除开盘即贴着该价位来回震荡的情形。
2. **线距非对称**。昨日下影长（多方承接强）会把突破买价抬高，要求更强的确认才追多。这是它区别于对称通道系统的地方。

**收盘强制平仓。**

## 三、Turtle 的运行逻辑

入场基于 Donchian 通道突破，两套系统并行：短周期的系统一（带过滤器）与长周期的系统二（不带过滤器）。

| 环节 | 规则 |
|---|---|
| **入场** | 价格超越前 N 日的最高价（或跌破最低价）即成交，不等收盘 |
| **过滤器（仅系统一）** | 若上一次突破本会是盈利的，则跳过本次信号；判定与是否真的交易过无关。因跳过而错过大行情时，由更长周期的突破作为 failsafe 兜底 |
| **加仓** | 顺势每隔固定波动率间隔加一单位，直至上限 |
| **止损** | 入场价 ± 固定倍数的 N（N 即 20 日 ATR）；加仓后所有单位的止损统一上移到距最新单位同样的距离 |
| **止损（Whipsaw 版）** | 更紧的止损，被打掉后价格回到原入场价即重新入场 |
| **止盈** | 反向的、更短周期的通道突破——多单以 N 日新低离场 |
| **敞口上限** | 四层：单品种 / 强相关组 / 弱相关组 / 单方向 |
| **权益反馈** | 每回撤 10%，名义账户规模下调 20%，直至权益修复至年初水平 |
| **横截面选择** | 同组多个信号同时出现时，买最强的、卖最弱的 |

## 四、R-Breaker 是 day trade 专属吗

不是。真正约束它的是三个结构性条件，"日内"只是其中最自然的实现：

1. 需要一个**已收盘、能产出固定 OHLC 的参照周期**；
2. 需要**周期末强制平仓**——否则线一换，持仓的参照系就断了；
3. 参照周期的振幅须远大于交易成本。

把"日"换成"周"或任何有明确起止的会话，逻辑完全不变。真正的麻烦在于 24/7 市场（加密、外汇现货）没有天然会话边界，起算点是人为选定的——这与编目 A1 对 VWAP 的注解（"仅在日内或有明确起算点时有意义"）是同一个问题。

## 五、变种

### R-Breaker 家族

共性：**用已收盘周期的 OHLC 投射当日价位**。

- Pivot Points，及其 Camarilla / Woodie / DeMark 分支
- **Dual Thrust**（Michael Chalek）：只保留突破分支，用前 N 日四价构造振幅，从**今日开盘价**上下投射
- 菲阿里四价
- 开盘区间突破 ORB（Toby Crabel）
- ACD（Mark Fisher）
- R-Levels、R-Table（Saidenberg 本人的同族作品）

R-Breaker 自身的常见改造：加日线级趋势过滤（只做顺势方向的突破）、时段过滤、用 ATR 替代昨日振幅定线距、反手改为只平不反。

### Turtle 家族

- 系统一 / 系统二本身即内建变种
- Whipsaw 止损版
- **Turtle Soup / Turtle Soup Plus One**（Raschke & Connors）：专做通道突破失败的**反向**策略
- 现代后裔：时间序列动量（编目出处 [6]）。主要改动是把"单点价格突破"换成平滑信号，降低对单一价格的敏感度；并用波动率目标替代固定单位制

## 六、与编目的模块对应

### R-Breaker

| 模块 | 对应 | 说明 |
|---|---|---|
| Entry | **无** | 空仓时只有突破，不满足 0.3(2) |
| 反手开出的新仓 | **形状像 A2/A3，逻辑不是** | 价位型、静止锚、可事先挂单；但锚来自**上一周期区间投影**，既非本段结构（A2）也非价格坐标先验（A3）。加一个日线趋势过滤后即成为合法的 A 类入场——但需要新开一格锚 |
| TP | 无固定止盈 | 靠反手或收盘平仓收尾 |
| SL | **C1 的滞后锚版本** | 结构失效，但结构取自昨日而非本段 |
| CD | **D1 日历子变体**（精确命中） | 编目第 627 行已预留此格 |

### Turtle

| 模块 | 对应 | 匹配度 |
|---|---|---|
| Entry | 无 | 纯突破，是编目的**补集** |
| TP：反向通道突破 | **B3，但缺子变体** | B3 现有子变体的锚是"持仓期最高价"（仓位参照）与"均线"。唐奇安离场的锚是**滚动窗口极值，与入场时点无关**——所有持仓者的离场线在同一价位 |
| SL：入场价 ± k×N | **C2，精确命中** | Turtle 很可能是这条逻辑在系统化交易中的原型 |
| SL：Whipsaw 版 | **D2 的反例**（见 §7.5） | |
| CD：上次盈利则跳过 | **D4，但符号相反**（见 §7.4） | |
| CD：回撤后调降规模 | **D4 软冷却子变体，精确命中** | 解除条件是权益修复 |
| CD：四层单位上限 | **D5，精确命中** | D5 的"波动率预算"子变体即 Turtle 单位制 |
| 买最强卖最弱 | **无** | 横截面**排序**；D5 只做门控不做排序 |

## 七、这次映射暴露的六处缺口

### 7.1 B/C/D 与"回调"入场完全正交

Turtle 是纯突破系统，却在 B3 / C2 / D4 / D5 上精确落位。这说明编目中真正专属于回调的只有 A 模块，B/C/D 是通用的趋势跟踪离场与门控层。

**建议**：在 0.x 明确写出这条正交性。它既是编目的价值（可移植），也是当前标题的误导来源。

### 7.2 锚的分类缺一格：滞后周期锚

测试二的三行（移动 / 结构 / 绝对）覆盖不了 Pivot / R-Breaker / Dual Thrust / ORB 这一整族。其行为是：**段内静止（像绝对锚）、段间整体重画（像结构锚）**，来源是上一个已收盘周期的 OHLC 投影。

用编目自己的判别法即可确认它独立：重画本段行情的 H/L，它不变（≠A2）；换一个品种不能沿用先验网格，必须由该品种自身历史给出（≠A3）。

**建议新增测试二第四行**

| 锚类型 | 锚的位置 | 回调期间的行为 | 横盘回调时 |
|---|---|---|---|
| 滞后周期锚 | 上一已收盘周期的 H/L/C 投影 | 段内静止，跨周期整体平移 | 可能永不触发；但每个新周期重新给一次机会 |

### 7.3 B3 缺"市场参照的追踪"子变体

编目在 C1↔C2、B3↔C3 都把"参照系"当作最重要的分界轴，B3 内部却没用同一把尺子。Chandelier 是仓位参照（锚在持仓期最高价，因人而异），唐奇安离场是市场参照（同一品种所有持仓者同价）。这是实质差异，应独立成子变体。

### 7.4 D4 的判词要收窄

现行表述："对全自动执行的系统，D4 缺乏统计依据。"

准确表述应为：**以自身盈亏为条件的门控，在单笔收益 iid 假设下无价值；而 Turtle 的过滤器正是对该假设的定向否定**（赌连续突破结果之间存在负序列相关）。

因此 D4 应分两型：

| 型 | 依据 | 代表 | 可证伪性 |
|---|---|---|---|
| 行为型 | 关于**执行者** | Coval–Shumway（编目出处 [12]） | 需交易者层面数据 |
| 市场型 | 关于**收益序列相关性** | Turtle 系统一过滤器 | 可直接用影子交易检验 |

另需注意：Turtle 这条门控的 E 是"盈利"、R 是"更长周期突破"（市场结构，属 D2）。它是 **E∈D4 / R∈D2 的复合体**，正好实证了 D.0 中"E 与 R 是两个独立自由度"的论断。

### 7.5 D2 需要写入一条反对意见

D2 的前提是"止损意味着本次判定已被证伪，必须等待新的独立观测"。Turtle 的 Whipsaw 明确否定这一点：紧止损被打掉不算证伪，回到原价立即重进。

这不是执行细节，是对 D2 底层假设的正面反驳。两者的分歧点可以精确表述为：**止损被触发，究竟是"假设被证伪"还是"噪声导致的执行损耗"？** 答案取决于止损距离相对于噪声尺度的位置——止损越紧，D2 的前提越不成立。

### 7.6 C4 缺"会话边界强制离场"子变体

编目的 C4 是有条件的（无进展才走），R-Breaker 及一切日内策略用的是**无条件到点平仓**。二者的失效模式完全不同，应分列。

## 八、一个可以直接兑现的对偶

**同一套锚分类能同时索引"回调入场"与"突破入场"，区别只是价格从哪一侧穿越锚。**

- 回调 = 价格回到锚附近且未有效穿越
- 突破 = 价格离开锚

| 锚类型 | 回调入场（现编目 A） | 突破入场（平行编目） |
|---|---|---|
| 移动锚 | 均线回踩（A1） | 均线突破 / 交叉 |
| 结构锚 | 比例回撤（A2） | **唐奇安通道突破（Turtle）** |
| 绝对锚 | 关口承接（A3） | 关口突破后加速 |
| 滞后周期锚 | *（现编目缺）* | **Pivot / R-Breaker / Dual Thrust** |

写一本平行的"突破入场编目"边际成本几乎为零，且两本共用同一套 B/C/D。注意编目 A3 已经指出"同一份委托单数据同时预测在关口反转与穿过关口后加速"——那条方向性缺口，本质上就是这张表同一行的左右两列。

## 九、一条批判性补充：焦点机制的衰减

有从业者评述认为，这类日内水平线系统早期的有效性来自池内与屏幕前大量交易者同时盯着同一组价位，属自我实现；使用者增多后，这些价位反而变成陷阱，优势消退。

这对编目 A3 引用 Schelling 焦点论证（出处 [10]）是一个直接的经验证据：**焦点机制成立的条件（参与者协调）同时也是它可被前置的原因。** 编目 A3 已写"关口越拥挤越容易被前置"，R-Breaker 正是这句话的实证案例，建议补入 A3 的已知失效模式。
